# 方案 01：个人博客系统（Blog）—— 真实项目实现手册

> 复杂度：⭐⭐　适合初学巩固，重点练手守卫、管道、模块共享、全局中间件。
> 本文是一份**可直接照做的实现手册**：每一步都给出目标、命令/操作、完整文件代码、关键解释、验收标准。最终交付一个能连真实数据库、用环境变量配置、带 JWT 鉴权的全栈博客项目。

## 0. 技术栈与最终目标

| 层 | 技术 |
| --- | --- |
| 后端 | NestJS 11、TypeORM、SQLite（文件数据库）、JWT、class-validator、@nestjs/config |
| 前端 | React 18 + Vite + TS + Axios |
| 共享 | pnpm workspace monorepo |
| 配置 | `.env` 环境变量 + `@nestjs/config` |

**最终目标**：访客可浏览/搜索文章；作者注册登录（JWT）后可发布、编辑、删除自己的文章。所有敏感配置（JWT 密钥、数据库路径、端口）来自 `.env`。

**目录结构（server）**

```

├── main.ts                         # 启动入口：全局管道/过滤器、注册中间件
├── app.module.ts                   # 根模块：装配 Config/TypeOrm/各业务模块
```

### 2.3 在 `app.module.ts` 注册 ConfigModule 与 TypeOrmModule

重写 `server/src/app.module.ts`：

```ts
import { Module } from '@nestjs/common';
import { ConfigModule } from '@nestjs/config';
import { TypeOrmModule } from '@nestjs/typeorm';
import * as path from 'node:path';
import configuration from './config/configuration';
import { validationSchema } from './config/validation';
import { UsersModule } from './modules/users/users.module';
import { AuthModule } from './modules/auth/auth.module';
import { ArticlesModule } from './modules/articles/articles.module';

@Module({
  imports: [
    // 全局配置：读取 .env，启用校验
    ConfigModule.forRoot({
      isGlobal: true,            // 任意模块均可注入 ConfigService
      load: [configuration],
      validationSchema,
    }),
    // 连接真实 SQLite 数据库（文件型）
    TypeOrmModule.forRootAsync({
      useFactory: (configService: ConfigService) => ({
        type: 'sqlite',
        database: path.resolve(process.cwd(), configService.get<string>('database.path')),
        entities: [__dirname + '/**/*.entity{.ts,.js}'],
        synchronize: true,       // 开发期自动建表；生产请改为 false 并用迁移
        autoLoadEntities: true,
      }),
      inject: [ConfigService],
    }),
    UsersModule,
    AuthModule,
    ArticlesModule,
  ],
})
export class AppModule {}
```

> 解释：
> - `ConfigModule.forRoot({ isGlobal: true })`：让 `ConfigService` 全局可用，业务模块无需再 import。
> - `TypeOrmModule.forRootAsync`：异步读取配置，数据库路径来自 `ConfigService`。`type: 'sqlite'` + `database` 指向文件，这就是"真实数据库"——`blog.db` 会在启动时自动创建并持久化。
> - `synchronize: true` 仅适合开发；上线应设 `false` 并使用 `typeorm migration:run`。

## 3. 全局日志中间件（知识点：中间件）

文件：`server/src/common/middleware/logger/logger.middleware.ts`

```ts
import { Request, Response, NextFunction } from 'express';

// 函数式中间件：记录每个请求的 HTTP 方法与响应耗时
export function logger_funMidderware(
  req: Request,
  res: Response,
  next: NextFunction,
) {
  const before = Date.now();
  // 必须在响应真正结束（finish）时计算耗时，否则拿到的会是 0
  res.on('finish', () => {
    const cost = Date.now() - before;
    console.log(`[${new Date().toISOString()}] ${req.method} ${req.originalUrl} - ${cost}ms`);
  });
  // 中间件只能调用一次 next()，否则会触发 ERR_HTTP_HEADERS_SENT
  next();
}
```

在 `main.ts` 注册（见第 7 节）。

> 易错点回顾：把 `next()` 放在耗时计算前、或调用两次 `next()`，都会导致耗时为 0 或 `Cannot set headers after they are sent`。务必用 `res.on('finish')` + 单次 `next()`。

### 5.4 策略 `server/src/modules/auth/jwt.strategy.ts`

```ts
import { Injectable } from '@nestjs/common';
import { PassportStrategy } from '@nestjs/passport';
import { ExtractJwt, Strategy } from 'passport-jwt';
import { ConfigService } from '@nestjs/config';

@Injectable()
export class JwtStrategy extends PassportStrategy(Strategy) {
  constructor(configService: ConfigService) {
    super({
      jwtFromRequest: ExtractJwt.fromAuthHeaderAsBearerToken(),
      secretOrKey: configService.get<string>('jwt.secret'),
    });
  }

  // 校验通过后，把 payload 挂到 req.user 上
  async validate(payload: { sub: number; username: string }) {
    return { userId: payload.sub, username: payload.username };
  }
}
```

### 5.5 服务 `server/src/modules/auth/auth.service.ts`

```ts
import { Injectable, UnauthorizedException } from '@nestjs/common';
import { JwtService } from '@nestjs/jwt';
import * as bcrypt from 'bcrypt';
import { UsersService } from '../users/users.service';

@Injectable()
export class AuthService {
  constructor(
    private readonly users: UsersService,
    private readonly jwt: JwtService,
  ) {}

  async register(username: string, password: string) {
    const exists = await this.users.findByUsername(username);
    if (exists) throw new UnauthorizedException('username taken');
    const passwordHash = await bcrypt.hash(password, 10);
    const user = await this.users.create({ username, passwordHash });
    return this.signToken(user.id, user.username);
  }

  async login(username: string, password: string) {
    const user = await this.users.findByUsername(username);
    if (!user) throw new UnauthorizedException('invalid credentials');
    const ok = await bcrypt.compare(password, user.passwordHash);
    if (!ok) throw new UnauthorizedException('invalid credentials');
    return this.signToken(user.id, user.username);
  }

  private signToken(userId: number, username: string) {
    return { access_token: this.jwt.sign({ sub: userId, username }) };
  }
}
```

### 6.4 服务 `server/src/modules/articles/articles.service.ts`

```ts
import { Injectable, NotFoundException, ForbiddenException } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { Article } from './article.entity';
import { CreateArticleDto, UpdateArticleDto } from './article.dto';

@Injectable()
export class ArticlesService {
  constructor(
    @InjectRepository(Article)
    private readonly repo: Repository<Article>,
  ) {}

  async list(page = 1, category?: string, keyword?: string) {
    const qb = this.repo.createQueryBuilder('a');
    if (category) qb.where('a.category = :category', { category });
    if (keyword) qb.andWhere('a.title LIKE :kw OR a.content LIKE :kw', { kw: `%${keyword}%` });
    qb.orderBy('a.createdAt', 'DESC').skip((page - 1) * 10).take(10);
    const [items, total] = await qb.getManyAndCount();
    return { items, total, page, pageSize: 10 };
  }

  findOne(id: number) {
    return this.repo.findOne({ where: { id } });
  }

  create(dto: CreateArticleDto, authorId: number) {
    return this.repo.save(this.repo.create({ ...dto, authorId }));
  }

  async update(id: number, dto: UpdateArticleDto, userId: number) {
    const article = await this.repo.findOne({ where: { id } });
    if (!article) throw new NotFoundException('article not found');
    if (article.authorId !== userId) throw new ForbiddenException('not your article');
    return this.repo.save({ ...article, ...dto });
  }

  async remove(id: number, userId: number) {
    const article = await this.repo.findOne({ where: { id } });
    if (!article) throw new NotFoundException('article not found');
    if (article.authorId !== userId) throw new ForbiddenException('not your article');
    return this.repo.remove(article);
  }
}
```

### 6.5 控制器 `server/src/modules/articles/articles.controller.ts`

```ts
import { Body, Controller, Delete, Get, Param, ParseIntPipe, Patch, Post, Query, UseGuards } from '@nestjs/common';
import { ArticlesService } from './articles.service';
import { CreateArticleDto, UpdateArticleDto, ArticleQueryDto } from './article.dto';
import { JwtAuthGuard } from '../common/guards/jwt-auth.guard';
import { CurrentUser } from '../common/decorators/current-user.decorator';

@Controller('articles')
export class ArticlesController {
  constructor(private readonly svc: ArticlesService) {}

  // 公开：分页 + 分类/关键字筛选
  @Get()
  list(@Query() q: ArticleQueryDto) {
    return this.svc.list(q.page, q.category, q.keyword);
  }

  // 公开：详情，:id 非数字自动 400（ParseIntPipe）
  @Get(':id')
  detail(@Param('id', ParseIntPipe) id: number) {
    return this.svc.findOne(id);
  }

  // 需登录：发布
  @UseGuards(JwtAuthGuard)
  @Post()
  create(@Body() dto: CreateArticleDto, @CurrentUser() user: any) {
    return this.svc.create(dto, user.userId);
  }

  // 需登录 + 仅作者：编辑
  @UseGuards(JwtAuthGuard)
  @Patch(':id')
  update(@Param('id', ParseIntPipe) id: number, @Body() dto: UpdateArticleDto, @CurrentUser() user: any) {
    return this.svc.update(id, dto, user.userId);
  }

  // 需登录 + 仅作者：删除
  @UseGuards(JwtAuthGuard)
  @Delete(':id')
  remove(@Param('id', ParseIntPipe) id: number, @CurrentUser() user: any) {
    return this.svc.remove(id, user.userId);
  }
}
```

## 7. 统一异常过滤器 + 启动装配

### 7.1 过滤器 `server/src/common/filters/http-exception.filter.ts`

```ts
import { ExceptionFilter, Catch, ArgumentsHost, HttpException, HttpStatus } from '@nestjs/common';
import { Response } from 'express';

// 捕获所有 HTTP 异常，返回统一结构 { code, message, data }
@Catch(HttpException)
export class HttpExceptionFilter implements ExceptionFilter {
  catch(exception: HttpException, host: ArgumentsHost) {
    const res = host.switchToHttp().getResponse<Response>();
    const status = exception.getStatus?.() ?? HttpStatus.INTERNAL_SERVER_ERROR;
    const body = exception.getResponse();
    const message = typeof body === 'string' ? body : (body as any).message ?? exception.message;
    res.status(status).json({ code: status, message, data: null });
  }
}
```

### 7.2 重写 `main.ts`

```ts
import { NestFactory } from '@nestjs/core';
import { ValidationPipe } from '@nestjs/common';
import { AppModule } from './app.module';
import { logger_funMidderware } from './common/middleware/logger/logger.middleware';
import { HttpExceptionFilter } from './common/filters/http-exception.filter';
import { ConfigService } from '@nestjs/config';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  const config = app.get(ConfigService);

  // 全局校验管道：自动校验 DTO，失败返回 400
  app.useGlobalPipes(new ValidationPipe({ transform: true, whitelist: true }));
  // 全局异常过滤器：统一错误结构
  app.useGlobalFilters(new HttpExceptionFilter());
  // 全局日志中间件（受 LOG_REQUESTS 开关控制）
  if (config.get<boolean>('logRequests')) {
    app.use(logger_funMidderware);
  }

  await app.listen(config.get<number>('port') ?? 5001);
}
bootstrap();
```

> 解释：所有横切关注点（校验、异常、日志）在入口集中注册，业务模块保持干净。

`packages/web/src/api/client.ts`：

```ts
import axios from 'axios';

export const api = axios.create({ baseURL: 'http://localhost:5001' });

// 请求拦截器：自动附带 JWT
api.interceptors.request.use((cfg) => {
  const token = localStorage.getItem('token');
  if (token) cfg.headers.Authorization = `Bearer ${token}`;
  return cfg;
});

// 响应拦截器：401 跳登录
api.interceptors.response.use(
  (r) => r,
  (err) => {
    if (err.response?.status === 401) {
      localStorage.removeItem('token');
      window.location.href = '/login';
    }
    return Promise.reject(err);
  },
);
```

页面要点：
- 列表页：调 `GET /articles?page=&category=`，渲染分页 + 标签筛选。
- 详情页：`GET /articles/:id`。
- 登录/注册页：调 `POST /auth/login|register`，存 `token`。
- 编辑器页：登录后 `POST /articles` 发文章，`PATCH/DELETE` 编辑/删除。

## 10. NestJS 知识点映射

- **全局中间件**：`logger_funMidderware` 记录请求耗时（`res.on('finish')`）。
- **守卫**：`JwtAuthGuard` 校验 token，保护写接口。
- **管道**：`ParseIntPipe` 解析 `:id`；`ValidationPipe` + DTO 校验。
- **异常过滤器**：统一错误响应结构。
- **模块共享**：`UsersModule` 用 `@Global` + `exports` 共享 `UsersService`。
- **配置**：`@nestjs/config` + `.env` + `Joi` 校验，密钥/路径不硬编码。
- **数据库**：TypeORM + SQLite 文件库，实体映射真实表。
