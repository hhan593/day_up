## ⚠️ 依赖安装规范（必读）

本项目是 pnpm workspace monorepo。**pnpm 默认禁止在 workspace 根目录直接 `pnpm add`**（会报 `ERR_PNPM_ADDING_TO_ROOT`），因此**不能在仓库根 `f:/project/blog` 直接装依赖**。

各子包当前的 `package.json` 现状：

| 包 | 是否有 package.json | 依赖应装到 |
| --- | --- | --- |
| `apps/web` | ✅ 有 | `apps/web`（cd 进去 `pnpm add`） |
| `apps/server` | ❌ **没有** | 见下方说明 |
| `libs/common` | ✅ 有 | `libs/common`（如需） |

**关键问题：`apps/server` 目前没有自己的 `package.json`，但 pnpm 又不允许在根目录装依赖。** 因此必须二选一：

### 方案 A（推荐）：给 `apps/server` 补一个 `package.json`

在 `apps/server/` 下创建最小 `package.json`：

```json
{
  "name": "server",
  "version": "0.0.1",
  "private": true,
  "dependencies": {},
  "devDependencies": {}
}
```

之后所有后端依赖都 cd 进 `apps/server` 安装：

```bash
cd f:/project/blog/apps/server
pnpm add @nestjs/jwt bcryptjs class-validator class-transformer
pnpm add -D @types/bcryptjs
```

### 方案 B：显式装到根（仅当确认要共享给所有包时）

若某依赖确实是全 workspace 共享（如 `typescript`、`eslint`），用 `-w` 显式声明：

```bash
cd f:/project/blog
pnpm add -w <pkg>      # 显式装到根 package.json
```

> ⚠️ 本项目当前所有运行期依赖都集中在**根 `package.json`**（如 `mysql2`、`typeorm`、`@nestjs/typeorm`），这是历史遗留。新加的后端依赖**建议按方案 A 装到 `apps/server`**，避免根目录继续膨胀；装完后用 `pnpm install` 重新链接。

**通用规则**：

- 给前端装 → `cd apps/web && pnpm add <pkg>`
- 给后端装 → 先确保 `apps/server/package.json` 存在，再 `cd apps/server && pnpm add <pkg>`
- 给共享库装 → `cd libs/common && pnpm add <pkg>`
- 全局/共享工具且确需在根 → `pnpm add -w <pkg>`
- **任何时候都不在仓库根直接 `pnpm add` 而不带 `-w`**

## 步骤 1.4 创建 UsersService

新建 `apps/server/src/users/users.service.ts`：

```ts
import {
  ConflictException,
  Injectable,
  NotFoundException,
} from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import * as bcrypt from 'bcryptjs';
import { User } from './user.entity';
import { CreateUserDto } from './dto/create-user.dto';

@Injectable()
export class UsersService {
  constructor(
    @InjectRepository(User)
    private readonly usersRepository: Repository<User>,
  ) {}

  async create(dto: CreateUserDto): Promise<User> {
    const exists = await this.usersRepository.findOne({
      where: { username: dto.username },
    });
    if (exists) {
      throw new ConflictException('username already exists');
    }
    const hashed = await bcrypt.hash(dto.password, 10);
    const user = this.usersRepository.create({
      username: dto.username,
      password: hashed,
      nickname: dto.nickname,
    });
    return this.usersRepository.save(user);
  }

  async findByUsername(username: string): Promise<User | null> {
    return this.usersRepository.findOne({ where: { username } });
  }

  async findOne(id: number): Promise<User> {
    const user = await this.usersRepository.findOne({ where: { id } });
    if (!user) throw new NotFoundException(`User #${id} not found`);
    return user;
  }
}
```

## 步骤 2.4 实现 AuthService

新建 `apps/server/src/auth/auth.service.ts`：

```ts
import { BadRequestException, Injectable } from '@nestjs/common';
import { JwtService } from '@nestjs/jwt';
import * as bcrypt from 'bcryptjs';
import { UsersService } from '../users/users.service';
import { CreateUserDto } from '../users/dto/create-user.dto';
import { LoginDto } from './dto/login.dto';

@Injectable()
export class AuthService {
  constructor(
    private readonly usersService: UsersService,
    private readonly jwtService: JwtService,
  ) {}

  async register(dto: CreateUserDto) {
    const user = await this.usersService.create(dto);
    return this.signToken(user.id, user.username);
  }

  async validateUser(username: string, password: string) {
    const user = await this.usersService.findByUsername(username);
    if (!user) return null;
    const ok = await bcrypt.compare(password, user.password);
    return ok ? user : null;
  }

  async login(dto: LoginDto) {
    const user = await this.validateUser(dto.username, dto.password);
    if (!user) throw new BadRequestException('invalid credentials');
    return this.signToken(user.id, user.username);
  }

  private signToken(userId: number, username: string) {
    return { access_token: this.jwtService.sign({ sub: userId, username }) };
  }
}
```

## 步骤 2.5 实现 JWT 策略（Passport）

新建 `apps/server/src/auth/jwt.strategy.ts`：

```ts
import { Injectable, UnauthorizedException } from '@nestjs/common';
import { PassportStrategy } from '@nestjs/passport';
import { ExtractJwt, Strategy } from 'passport-jwt';
import { ConfigService } from '@nestjs/config';

@Injectable()
export class JwtStrategy extends PassportStrategy(Strategy) {
  constructor(config: ConfigService) {
    super({
      jwtFromRequest: ExtractJwt.fromAuthHeaderAsBearerToken(),
      secretOrKey: config.get<string>('JWT_SECRET'),
    });
  }

  async validate(payload: { sub: number; username: string }) {
    if (!payload?.sub) throw new UnauthorizedException();
    return { userId: payload.sub, username: payload.username };
  }
}
```

## 步骤 3.3 ArticlesService（分页 + 作者注入）

`apps/server/src/articles/articles.service.ts`：

```ts
import { Injectable, NotFoundException, UnauthorizedException } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { Article } from './article.entity';
import { CreateArticleDto, UpdateArticleDto, ArticleQueryDto } from './dto/create-article.dto';

@Injectable()
export class ArticlesService {
  constructor(
    @InjectRepository(Article)
    private readonly repo: Repository<Article>,
  ) {}

  async create(dto: CreateArticleDto, authorId: number): Promise<Article> {
    const a = this.repo.create({ ...dto, authorId, published: dto.published ?? false });
    return this.repo.save(a);
  }

  async findAll(q: ArticleQueryDto) {
    const page = Math.max(1, Number(q.page) || 1);
    const pageSize = Math.min(100, Math.max(1, Number(q.pageSize) || 20));
    const [items, total] = await this.repo
      .createQueryBuilder('a')
      .where(q.keyword ? 'a.title LIKE :kw' : '1=1', { kw: `%${q.keyword}%` })
      .orderBy('a.createdAt', 'DESC')
      .skip((page - 1) * pageSize)
      .take(pageSize)
      .getManyAndCount();
    return { items, total, page, pageSize };
  }

  async findOne(id: number): Promise<Article> {
    const a = await this.repo.findOne({ where: { id } });
    if (!a) throw new NotFoundException(`Article #${id} not found`);
    return a;
  }

  async update(id: number, dto: UpdateArticleDto, userId: number): Promise<Article> {
    const a = await this.findOne(id);
    if (a.authorId !== userId) throw new UnauthorizedException('not your article');
    Object.assign(a, dto);
    return this.repo.save(a);
  }

  async remove(id: number, userId: number): Promise<void> {
    const a = await this.findOne(id);
    if (a.authorId !== userId) throw new UnauthorizedException('not your article');
    await this.repo.remove(a);
  }
}
```

## 步骤 3.4 ArticlesController（写操作受 JWT 保护）

`apps/server/src/articles/articles.controller.ts`：

```ts
import {
  Body, Controller, Delete, Get, Param, ParseIntPipe, Post, Put, Query, UseGuards,
} from '@nestjs/common';
import { AuthGuard } from '@nestjs/passport';
import { ArticlesService } from './articles.service';
import { CreateArticleDto, UpdateArticleDto, ArticleQueryDto } from './dto/create-article.dto';
import { CurrentUser } from '../auth/current-user.decorator';

@Controller('articles')
export class ArticlesController {
  constructor(private readonly svc: ArticlesService) {}

  @UseGuards(AuthGuard('jwt'))
  @Post()
  create(@Body() dto: CreateArticleDto, @CurrentUser() user: { userId: number }) {
    return this.svc.create(dto, user.userId);
  }

  @Get()
  findAll(@Query() q: ArticleQueryDto) {
    return this.svc.findAll(q);
  }

  @Get(':id')
  findOne(@Param('id', ParseIntPipe) id: number) {
    return this.svc.findOne(id);
  }

  @UseGuards(AuthGuard('jwt'))
  @Put(':id')
  update(@Param('id', ParseIntPipe) id: number, @Body() dto: UpdateArticleDto,
         @CurrentUser() user: { userId: number }) {
    return this.svc.update(id, dto, user.userId);
  }

  @UseGuards(AuthGuard('jwt'))
  @Delete(':id')
  remove(@Param('id', ParseIntPipe) id: number, @CurrentUser() user: { userId: number }) {
    return this.svc.remove(id, user.userId);
  }
}
```

## 步骤 5.3 登录页 + 文章列表（示例片段）

`apps/web/src/App.tsx` 最小改造示例：

```tsx
import { useEffect, useState } from 'react';
import { api } from './api/client';

export default function App() {
  const [token, setToken] = useState(localStorage.getItem('token') || '');
  const [articles, setArticles] = useState<any[]>([]);

  const login = async () => {
    const { data } = await api.post('/auth/login', {
      username: 'alice', password: 'secret1',
    });
    localStorage.setItem('token', data.access_token);
    setToken(data.access_token);
  };

  const load = async () => {
    const { data } = await api.get('/articles');
    setArticles(data.items);
  };

  useEffect(() => { if (token) load(); }, [token]);

  return (
    <div>
      <h1>Nest Blog</h1>
      <button onClick={login}>登录</button>
      <ul>{articles.map((a) => <li key={a.id}>{a.title}</li>)}</ul>
    </div>
  );
}
```

> 实际项目建议拆分成 `pages/`、`components/`，并配合 `react-router-dom` 做路由。Vite 已配置 `/api` → 后端代理，无需手写完整 URL。

# 阶段六：生产化收尾

## 步骤 6.1 关闭 synchronize，启用迁移

编辑 `.env`：

```env
DB_SYNCHRONIZE=false
```

生成并运行迁移：

```bash
pnpm --filter server exec typeorm-ts-node-commonjs migration:generate -d ./src/migrations/data-source.ts
pnpm --filter server exec typeorm-ts-node-commonjs migration:run -d ./src/migrations/data-source.ts
```

> 需先新建 `apps/server/src/migrations/data-source.ts` 导出 `DataSource`（与 `app.module.ts` 中 forRoot 配置保持一致）。

## 步骤 6.2 配置校验（可选）

在 `ConfigModule.forRoot` 增加 `validationSchema`（Joi/zod），启动期校验必填 `DB_*` / `JWT_SECRET`。

## 步骤 6.3 补齐 server 的 package.json（重要前置）

`apps/server` **当前没有 `package.json`**，但 pnpm 禁止在根目录直接装依赖，因此**务必先创建** `apps/server/package.json`（内容见开头「依赖安装规范·方案 A`）。否则所有后端依赖（`@nestjs/jwt`、`bcryptjs` 等）和上面的迁移命令都无处安放。

推荐内容：

```json
{
  "name": "server",
  "version": "0.0.1",
  "private": true,
  "scripts": {
    "start": "nest start",
    "build": "nest build",
    "start:dev": "nest start --watch"
  },
  "dependencies": {},
  "devDependencies": {}
}
```

创建后，`pnpm --filter server` / `pnpm dev:server` 才会真正指向独立子包，迁移命令（`步骤 6.1`）才能生效。
