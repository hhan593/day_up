# 方案 01：个人博客系统（Blog）

> 复杂度：⭐⭐　适合初学巩固，重点练手守卫、管道、模块共享、全局中间件。

## 1. 项目目标

一个最小可用的个人博客：访客可浏览文章、按分类/标签筛选；作者登录后可发布、编辑、删除自己的文章。后端覆盖本项目已学的中介软件、守卫、管道、模块共享等知识点。

## 2. 功能清单

- **公开端**
  - 文章列表（分页、按分类/标签筛选）
  - 文章详情
  - 文章搜索（关键字）
- **作者端（需登录）**
  - 注册 / 登录（JWT）
  - 发布文章（标题、正文、分类、标签）
  - 编辑 / 删除自己的文章
- **横切关注点**
  - 全局日志中间件记录请求耗时
  - JWT 守卫保护写接口
  - `ParseIntPipe` / DTO 校验管道
  - 统一异常过滤器返回标准错误体

## 3. 技术栈

| 层 | 技术 |
| --- | --- |
| 后端 | NestJS 10、TypeORM、SQLite、JWT、class-validator |
| 前端 | Vue 3 + Vite + TS（或 React 18 + Vite + TS） |
| 共享 | pnpm workspace monorepo |

## 5. 数据库设计

- **User**：id, username, passwordHash, role, createdAt
- **Article**：id, title, content, category, tags(JSON), authorId, createdAt, updatedAt

## 6. API 设计（示例）

| 方法 | 路径 | 守卫 | 说明 |
| --- | --- | --- | --- |
| POST | /auth/register | - | 注册 |
| POST | /auth/login | - | 登录，返回 token |
| GET | /articles?page=&category= | - | 列表 |
| GET | /articles/:id | - | 详情（ParseIntPipe） |
| POST | /articles | JwtAuthGuard | 发布 |
| PATCH | /articles/:id | JwtAuthGuard | 编辑（仅作者） |
| DELETE | /articles/:id | JwtAuthGuard | 删除（仅作者） |

## 7. NestJS 知识点映射

- **全局中间件**：`logger.middleware` 记录请求耗时（复用 `02-中间件` 文档）
- **守卫**：`JwtAuthGuard` 校验 token，保护写接口（复用 `03-守卫`）
- **管道**：`ParseIntPipe` 解析 `:id`；`ValidationPipe` + DTO 校验（复用 `04-管道`）
- **异常过滤器**：统一错误响应（复用 `05-过滤器`）
- **模块共享**：`UsersModule` 导出 `UserService`，`AuthModule` / `ArticlesModule` 导入（复用 `09-模块共享`）

## 8. 前端要点

- 路由：公开页（列表/详情）、登录页、编辑器页
- Axios 拦截器自动附带 JWT，统一处理 401 跳转登录
- 列表分页、标签筛选组件

## 9. 详细实现步骤（按优先级分步）

> 每一步都给出「目标 → 关键命令 → 要新建/改动的文件 → 注意点」。建议严格按顺序推进，每步完成后再进入下一步。

### 步骤 0：环境与 monorepo 初始化（P0 前置）

- **目标**：搭好 pnpm workspace 骨架，后端可 `pnpm dev` 启动。
- **命令**：
  ```bash
  mkdir nest-fullstack && cd nest-fullstack
  pnpm init
  # 根目录新建 pnpm-workspace.yaml，写入 packages: ['packages/*']
  pnpm create @nestjs/scope server   # 在 packages/server 生成 NestJS 骨架
  # 或手动：nest new packages/server
  cd packages/server && pnpm i
  pnpm add @nestjs/config class-validator class-transformer
  ```
- **文件**：`pnpm-workspace.yaml`、`packages/server/package.json`。
- **注意**：`tsconfig.json` 确认 `strict: true`；沿用本项目 `eslint.config.mjs`。

### 步骤 1：全局日志中间件（知识点：中间件）

- **目标**：所有请求打印耗时，复用本项目「函数式中间件」思路。
- **文件**：`src/common/middleware/logger.middleware.ts`、`src/app.module.ts`。
  ```ts
  // logger.middleware.ts
  import { Injectable, NestMiddleware } from '@nestjs/common';
  @Injectable()
  export class LoggerMiddleware implements NestMiddleware {
    use(req: Request, res: Response, next: () => void) {
      const start = Date.now();
      res.on('finish', () => console.log(`${req.method} ${req.url} ${Date.now() - start}ms`));
      next();
    }
  }
  // app.module.ts：configure(consumer) { consumer.apply(LoggerMiddleware).forRoutes('*'); }
  ```
- **验收**：启动后访问任意接口，控制台出现耗时日志。

### 步骤 2：UsersModule + AuthModule（知识点：守卫 / JWT / 模块共享）

- **目标**：注册/登录拿到 JWT；`UsersService` 共享给 Auth。
- **命令**：`pnpm add @nestjs/jwt @nestjs/passport passport passport-jwt bcrypt`
- **文件**：
  - `src/modules/users/users.entity.ts`（`User` 实体，密码用 `bcrypt` 哈希）
  - `src/modules/users/users.module.ts` → **`exports: [UsersService]`**（共享关键）
  - `src/modules/auth/auth.service.ts`（校验密码、`jwtService.sign` 签发 token）
  - `src/modules/auth/jwt-auth.guard.ts`（校验 `Authorization` 头）
- **注意**：`AuthModule` 需 `imports: [UsersModule, JwtModule.register({ secret })]`。

### 步骤 3：ArticlesModule CRUD（知识点：管道 / 模块共享）

- **目标**：文章增删改查；写接口挂 `JwtAuthGuard`；`:id` 用 `ParseIntPipe`；入参用 `ValidationPipe` + DTO。
- **文件**：`articles/article.entity.ts`、`articles/article.dto.ts`（`@IsString`/`@IsArray`）、`articles/articles.controller.ts`。
- **关键点**：
  - 写接口：`@UseGuards(JwtAuthGuard)`；编辑/删除时比对 `article.authorId === req.user.id`（防越权）。
  - `GET /articles/:id`：`@Param('id', ParseIntPipe)` 非数字自动 400。
  - 全局在 `main.ts` 注册 `app.useGlobalPipes(new ValidationPipe({ transform: true }))`。

### 步骤 4：统一异常过滤器（知识点：过滤器协作）

- **目标**：所有异常返回标准 `{ code, message, data }` 体。
- **文件**：`src/common/filters/http-exception.filter.ts`，`main.ts` 中 `app.useGlobalFilters(new HttpExceptionFilter())`。
- **验收**：故意访问错误接口，响应体结构统一。

### 步骤 5：前端（Vue/React）

- **目标**：列表/详情/登录/编辑器闭环。
- **要点**：Axios 拦截器附带 JWT；401 跳登录；列表分页 + 标签筛选组件。

### 步骤 6：联调 + README

- **目标**：端到端跑通「浏览→登录→发文章→编辑→删除」，补 README 与 `.env.example`。
