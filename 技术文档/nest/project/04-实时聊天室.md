# 方案 04：实时聊天室（Realtime Chat）

> 复杂度：⭐⭐⭐⭐　挑战进阶，重点练手 WebSocket 网关、守卫、RxJS、共享模块，并打通 REST + 实时双通道。

## 1. 项目目标

一个实时聊天室：用户登录后进入房间，实时收发消息、查看在线成员；服务端用 WebSocket 网关推送，REST 接口负责历史消息与房间管理。综合本项目守卫、共享模块、RxJS 等知识点，并引入网关层（架构图中「控制器→服务」之外的实时通道）。

## 2. 功能清单

- 用户注册 / 登录（JWT）
- 创建 / 加入 / 离开房间
- 实时收发消息（WebSocket）
- 在线成员列表（实时推送）
- 历史消息分页（REST）
- 私聊（点对点）

## 3. 技术栈

| 层 | 技术 |
| --- | --- |
| 后端 | NestJS 10、@nestjs/websockets、TypeORM + PostgreSQL、JWT、RxJS |
| 前端 | React 18 + Vite + TS（或 Vue 3 + Vite + TS） + socket.io-client |
| 共享 | pnpm workspace monorepo |

## 5. 数据库设计

- **User**：id, username, passwordHash
- **Room**：id, name, ownerId
- **Message**：id, roomId, senderId, content, createdAt
- **RoomMember**：roomId, userId（在线状态内存维护）

## 6. API / 事件设计

**REST**
| 方法 | 路径 | 守卫 | 说明 |
| --- | --- | --- | --- |
| POST | /rooms | JwtAuthGuard | 建房间 |
| GET | /rooms/:id/messages?page= | JwtAuthGuard | 历史消息 |

**WebSocket 事件（chat.gateway）**
| 事件 | 方向 | 说明 |
| --- | --- | --- |
| `join` | client→server | 加入房间 |
| `message` | client→server | 发消息（落库 + 广播） |
| `message` | server→client | 广播新消息 |
| `presence` | server→client | 在线成员变更 |

## 7. NestJS 知识点映射

- **网关守卫**：`WsJwtGuard` 在 `handleConnection` / `use` 阶段校验 token（复用 `03-守卫` 的 `ExecutionContext` 切换思路）
- **共享模块**：`UsersModule` 导出 `UserService` 给 `ChatGateway` 取用户信息（复用 `09-模块共享`）
- **RxJS**：`PresenceService` 用 `Subject` / `BehaviorSubject` 管理在线状态流，房间变更实时推送给订阅者（复用 `12-RxJS`）
- **自定义装饰器**：`@User()` 在网关上下文取当前用户（复用 `06-装饰器`）
- **异常过滤器**：网关异常统一处理（复用 `05-过滤器`）

## 8. 前端要点

- socket.io-client 封装 hook（Vue `useChat` / React `useChat`）
- 消息列表虚拟滚动、在线成员侧栏
- 断线重连、JWT 鉴权握手

## 9. 详细实现步骤（按优先级分步）

> 本方案复杂度最高 ⭐⭐⭐⭐，建议完成 01~03 并学过 `12-RxJS` 后再做。重点：**WebSocket 网关、网关守卫、RxJS 在线状态流、REST/实时双通道**。

### 步骤 1：WebSocket 网关骨架 + WsJwtGuard（知识点：网关 / 守卫）

- **目标**：客户端可建立带 JWT 的 WS 连接；未登录被拒。
- **命令**：`pnpm add @nestjs/websockets @nestjs/platform-socket.io socket.io`
- **文件**：
  - `src/common/guards/ws-jwt.guard.ts`：实现 `CanActivate`，从 `client.handshake.auth.token` 取 JWT 校验（复用 `03-守卫` 的 `ExecutionContext` 切换思路）。
  - `src/modules/chat/chat.gateway.ts`：`@WebSocketGateway()`，`@UseGuards(WsJwtGuard)`，`handleConnection` 拒绝非法连接。

### 步骤 2：Auth + UsersModule 共享（知识点：模块共享）

- **目标**：`ChatGateway` 用共享的 `UserService` 取用户信息。
- **关键**：`UsersModule` 必须 `exports: [UsersService]`；`ChatModule` `imports: [UsersModule]`。注意避免网关与服务间的循环依赖（必要时用 `forwardRef` 或把共享逻辑下沉到独立 module）。

### 步骤 3：RoomsModule + MessagesModule（REST 历史）

- **目标**：房间 CRUD、历史消息分页（落库）。
- **文件**：`rooms/rooms.controller.ts`（`@UseGuards(JwtAuthGuard)` 建房间）、`messages/messages.service.ts`（`findByRoom(roomId, page)` 分页）。

### 步骤 4：ChatGateway 广播 + PresenceService（知识点：RxJS）

- **目标**：消息实时广播；在线成员实时推送。
- **文件**：
  - `chat.gateway.ts`：监听 `join`/`message`；收到消息 → 落库（`MessagesService`）→ `server.to(room).emit('message', payload)` 广播。
  - `src/modules/chat/presence.service.ts`：
    ```ts
    private online$ = new BehaviorSubject<Map<string, string>>(new Map());
    join(userId, socketId) { /* 更新 Map，online$.next */ }
    get online() { return this.online$.asObservable(); }
    ```
  - 成员变更时 `gateway` 订阅 `presence.online` 并 `emit('presence', members)`。

### 步骤 5：前端聊天 UI + socket hook

- **目标**：消息列表、在线成员侧栏、断线重连。
- **文件**：React `useChat` / Vue `useChat` hook 封装 `socket.io-client`；握手带 JWT（`auth: { token }`）。

### 步骤 6：私聊 + 联调压测

- **目标**：`private-message` 事件点对点发送（`socket.to(targetSocket).emit(...)`）；用多客户端压测广播与在线流稳定性。

> 完成 04 即打通「REST + WebSocket 双通道 + RxJS 流」，是本项目最综合的挑战。

## 10. 验收标准

- [ ] 未登录 WebSocket 连接被守卫拒绝
- [ ] 消息实时广播到同房间成员，并落库可分页拉取
- [ ] 成员上线/下线实时更新在线列表（RxJS 流）
- [ ] `UserService` 经共享模块被网关复用，无循环依赖
