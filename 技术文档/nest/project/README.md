# NestJS 全栈练手项目计划书

本目录收录 4 个适合练手的 NestJS 全栈项目方案，均采用 **pnpm workspace monorepo + TypeScript** 技术栈，前端可选 **Vue 3** 或 **React**，后端使用本项目所学的 NestJS 知识点（中间件、守卫、管道、异常过滤器、自定义装饰器、自定义提供者、模块共享、依赖注入等）。

## 方案一览

| 编号 | 方案 | 复杂度 | 覆盖核心知识点 | 适合人群 |
| --- | --- | --- | --- | --- |
| [01](./01-个人博客系统.md) | 个人博客系统 | ⭐⭐ | 守卫、管道、模块共享、全局中间件 | 初学巩固 |
| [02](./02-任务管理Todo.md) | 任务管理 Todo | ⭐⭐ | 自定义装饰器、DTO 校验、异常过滤、自定义提供者 | 初学巩固 |
| [03](./03-电商Demo.md) | 电商 Demo | ⭐⭐⭐ | 角色守卫、复杂管道、拦截器、事务/连接池 | 进阶提升 |
| [04](./04-实时聊天室.md) | 实时聊天室 | ⭐⭐⭐⭐ | WebSocket 网关、守卫、RxJS、共享模块 | 挑战进阶 |

## 优先级建议（推荐执行顺序）

> 按「先夯实基础、再挑战难点」的原则排序。前两个是必做的基础练手，后两个按兴趣/时间选做。

| 优先级 | 方案 | 理由 |
| --- | --- | --- |
| **P0（首选）** | 01 个人博客系统 | 知识点最均衡、最接近"最小可上线"闭环；能一次性串起中间件→守卫→管道→过滤器→模块共享这条主链路。建议所有人都先做完这个。 |
| **P1（强化）** | 02 任务管理 Todo | 在博客基础上引入本项目最特色的「自定义装饰器 `@User()`」「`useFactory` 自定义提供者」「异常过滤器协作」，是后续进阶项目的基石。做完 01 紧接着做 02。 |
| **P2（进阶）** | 03 电商 Demo | 引入角色守卫、复杂业务管道、拦截器、事务。适合已掌握 P0/P1、想练真实业务复杂度（下单事务、库存扣减）的同学。**建议先把 `11-架构图` 里的拦截器补齐理解再做**。 |
| **P3（挑战）** | 04 实时聊天室 | WebSocket 网关 + RxJS 流 + REST/实时双通道，复杂度最高、调试成本大。留作学完 RxJS（`12-RxJS`）、守卫、共享模块后的综合挑战。 |

**一句话路线**：`01 → 02 →（03 或 04）`。若时间有限，务必完成 01 + 02，已能覆盖本项目 80% 核心知识点。

## 通用技术约定（所有方案共用）

- **包管理**：pnpm（workspace 模式，根目录 `pnpm-workspace.yaml`）
- **语言**：全栈 TypeScript（`strict: true`）
- **后端**：NestJS 10+，RESTful 风格，统一响应包装
- **前端**：Vue 3（Vite + TS）或 React 18（Vite + TS），按需选择
- **数据库**：入门用 SQLite（TypeORM / Prisma），进阶用 PostgreSQL
- **鉴权**：JWT，配合本项目 `AuthGuard` / `RoleGuard` 思路
- **代码规范**：ESLint + Prettier，沿用本项目配置

## 目录骨架（monorepo）

```
nest-fullstack/
├── pnpm-workspace.yaml
├── package.json            # 根：scripts + 公共 devDeps
├── packages/
│   ├── server/             # NestJS 后端
│   │   ├── src/
│   │   │   ├── main.ts
│   │   │   ├── app.module.ts
│   │   │   ├── common/      # 守卫/管道/过滤器/装饰器（复用本项目）
│   │   │   └── modules/
│   │   └── package.json
│   └── web/                # Vue 或 React 前端
│       ├── src/
│       └── package.json
└── docs/                   # 各项目独立文档
```
