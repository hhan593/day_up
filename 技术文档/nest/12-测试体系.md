# 12. NestJS 测试体系（单元 / 集成 / E2E）

> 来源可信度：**官方文档确认 + 标准实践**（基于 NestJS 官方 Testing 章节、`@nestjs/testing`、`jest`/`vitest`、Supertest 公开 API）
> 关联：`07-testing/`（子主题）、本文档集 `10-认证鉴权实战.md`
> 本目录 `07-testing/` 是分散概念，**本文给出可落地的完整测试方案与分层策略**。

## 1. 测试金字塔

```
        ╱ E2E ╲          少：端到端验证关键链路（Supertest）
       ╱ 集成   ╲        中：模块间协作 + 真实 DB/Redis（Testcontainers）
      ╱  单元测试 ╲      多：Service/纯函数，依赖全部 mock
```

**比例建议**：单元 70% / 集成 20% / E2E 10%。

## 2. 单元测试（TestingModule + Mock）

Nest 提供 `Test.createTestingModule()`，可**覆盖（override）任意 provider**。

```ts
// user.service.spec.ts
import { Test, TestingModule } from '@nestjs/testing';
import { getRepositoryToken } from '@nestjs/typeorm';
import { UserService } from './user.service';
import { User } from './user.entity';
import { NotFoundException } from '@nestjs/common';

describe('UserService', () => {
  let service: UserService;
  let repo: any;

  // 模拟 Repository
  const mockRepo = {
    findOne: jest.fn(),
    find: jest.fn(),
    save: jest.fn(),
    delete: jest.fn(),
  };

  beforeEach(async () => {
    const module: TestingModule = await Test.createTestingModule({
      providers: [
        UserService,
        // 用 mock 替换真实 Repository
        { provide: getRepositoryToken(User), useValue: mockRepo },
      ],
    }).compile();

    service = module.get<UserService>(UserService);
    repo = module.get(getRepositoryToken(User));
  });

  afterEach(() => jest.clearAllMocks());

  it('should be defined', () => {
    expect(service).toBeDefined();
  });

  describe('findById', () => {
    it('返回用户', async () => {
      const user = { id: '1', email: 'a@b.com' };
      repo.findOne.mockResolvedValue(user);

      const result = await service.findById('1');

      expect(result).toEqual(user);
      expect(repo.findOne).toHaveBeenCalledWith({ where: { id: '1' } });
    });

    it('用户不存在时抛 NotFoundException', async () => {
      repo.findOne.mockResolvedValue(null);

      await expect(service.findById('999')).rejects.toThrow(NotFoundException);
    });
  });
});
```

**关键 API**：

- `Test.createTestingModule({ providers, controllers, imports })` — 建测试模块。
- `.overrideProvider(X).useValue(mock)` — 替换 provider。
- `.overrideGuard(JwtAuthGuard).useValue({ canActivate: () => true })` — 跳过守卫。
- `.overrideInterceptor(X).useValue(...)` — 替换拦截器。
- `module.get<T>(Token)` / `module.resolve<T>()`（scoped provider）。

### 覆盖守卫/中间件（测试 Controller）

```ts
const module = await Test.createTestingModule({
  controllers: [UserController],
  providers: [{ provide: UserService, useValue: mockUserService }],
})
  .overrideGuard(JwtAuthGuard)
  .useValue({ canActivate: (ctx) => {
      ctx.switchToHttp().getRequest().user = { userId: '1', roles: ['admin'] };
      return true;
    }})
  .compile();
```

## 3. 集成测试（真实依赖）

用 **Testcontainers** 起真实 Postgres/Redis，测真实 SQL 与缓存行为。

```bash
npm i -D @testcontainers/postgresql @testcontainers/redis
```

```ts
// test/setup-integration.ts
import { PostgreSqlContainer } from '@testcontainers/postgresql';
import { RedisContainer } from '@testcontainers/redis';

let pgContainer, redisContainer;

export async function setupContainers() {
  pgContainer = await new PostgreSqlContainer('postgres:16').start();
  redisContainer = await new RedisContainer('redis:7').start();

  process.env.DB_HOST = pgContainer.getHost();
  process.env.DB_PORT = String(pgContainer.getPort());
  process.env.DB_USER = pgContainer.getUsername();
  process.env.DB_PASS = pgContainer.getPassword();
  process.env.DB_NAME = pgContainer.getDatabase();
  process.env.REDIS_URL = redisContainer.getConnectionUrl();

  return { pgContainer, redisContainer };
}

export async function teardownContainers() {
  await pgContainer?.stop();
  await redisContainer?.stop();
}
```

```ts
// test/user.integration.spec.ts
import { Test } from '@nestjs/testing';
import { TypeOrmModule } from '@nestjs/typeorm';
import { setupContainers, teardownContainers } from './setup-integration';

describe('User Integration', () => {
  let app: INestApplication;

  beforeAll(async () => {
    await setupContainers();

    const module = await Test.createTestingModule({
      imports: [
        TypeOrmModule.forRoot({ type: 'postgres', autoLoadEntities: true, /* env */ }),
        UserModule,
      ],
    }).compile();

    app = module.createNestApplication();
    app.useGlobalPipes(new ValidationPipe({ whitelist: true }));
    await app.init();
  }, 60_000);       // 容器启动慢，加大超时

  afterAll(async () => {
    await app.close();
    await teardownContainers();
  });

  it('创建并查询用户', async () => {
    const created = await request(app.getHttpServer())
      .post('/users')
      .send({ email: 'test@example.com', password: 'Pass@123' })
      .expect(201);

    const found = await request(app.getHttpServer())
      .get(`/users/${created.body.id}`)
      .expect(200);

    expect(found.body.email).toBe('test@example.com');
  });
});
```

## 4. E2E 测试（Supertest）

```bash
npm i -D supertest @types/supertest
```

```ts
// test/auth.e2e-spec.ts
import { Test, TestingModule } from '@nestjs/testing';
import { INestApplication, ValidationPipe } from '@nestjs/common';
import * as request from 'supertest';
import { AppModule } from '../src/app.module';

describe('AuthController (e2e)', () => {
  let app: INestApplication;
  let accessToken: string;

  beforeAll(async () => {
    const moduleFixture: TestingModule = await Test.createTestingModule({
      imports: [AppModule],
    })
      .overrideProvider(MailService)
      .useValue({ send: jest.fn() })      // 不发真实邮件
      .compile();

    app = moduleFixture.createNestApplication();
    // ★ E2E 要应用与 main.ts 相同的全局配置
    app.useGlobalPipes(new ValidationPipe({ whitelist: true, transform: true }));
    await app.init();
  });

  afterAll(async () => await app.close());

  describe('/auth/login (POST)', () => {
    it('凭据正确时返回 token', async () => {
      const res = await request(app.getHttpServer())
        .post('/auth/login')
        .send({ email: 'admin@example.com', password: 'admin123' })
        .expect(200);

      expect(res.body.accessToken).toBeDefined();
      accessToken = res.body.accessToken;
    });

    it('密码错误返回 401', async () => {
      await request(app.getHttpServer())
        .post('/auth/login')
        .send({ email: 'admin@example.com', password: 'wrong' })
        .expect(401);
    });

    it('参数缺失返回 400（ValidationPipe）', async () => {
      await request(app.getHttpServer())
        .post('/auth/login')
        .send({ email: 'not-an-email' })
        .expect(400);
    });
  });

  describe('受保护路由', () => {
    it('无 token 返回 401', () => {
      return request(app.getHttpServer()).get('/users/profile').expect(401);
    });

    it('带 token 返回数据', async () => {
      const res = await request(app.getHttpServer())
        .get('/users/profile')
        .set('Authorization', `Bearer ${accessToken}`)
        .expect(200);

      expect(res.body.email).toBe('admin@example.com');
    });
  });
});
```

## 5. 常用 Mock 技巧

```ts
// ① Mock 整个模块
jest.mock('../src/redis/redis.module', () => ({
  RedisModule: class {},
}));

// ② Mock Service（部分方法）
const mailService = {
  send: jest.fn().mockResolvedValue(undefined),
  sendBulk: jest.fn(),
};

// ③ Mock 时间（测 TTL / 定时任务）
jest.useFakeTimers().setSystemTime(new Date('2026-01-01'));
// ... 测试 ...
jest.useRealTimers();

// ④ Mock 外部 HTTP（nock）
import * as nock from 'nock';
nock('https://api.example.com').get('/user/1').reply(200, { name: 'alice' });

// ⑤ 验证调用参数
expect(mailService.send).toHaveBeenCalledWith(
  expect.objectContaining({ to: 'a@b.com' }),
);
```

## 6. 数据库测试策略

| 策略 | 做法 | 适用 |
|------|------|------|
| **每次清空** | `beforeEach` 里 `TRUNCATE` | 简单、用例独立 |
| **事务回滚** | 每测试包事务，结束 rollback | 快，需共享连接 |
| **工厂 + 种子** | 用 factory 造数据 | 复杂关联 |
| **容器** | Testcontainers | 测真实 SQL 行为 |

```ts
// 事务回滚模式
let queryRunner: QueryRunner;

beforeEach(async () => {
  queryRunner = dataSource.createQueryRunner();
  await queryRunner.startTransaction();
});

afterEach(async () => {
  await queryRunner.rollbackTransaction();
  await queryRunner.release();
});
```

## 10. 常见坑

| 坑 | 解决 |
|----|------|
| 测试间数据污染 | 每个用例后清空/回滚 |
| 端口占用 | E2E 用 `app.init()` 而非 `app.listen()`，Supertest 直接用 `app.getHttpServer()` |
| 异步未等待 | 所有异步用 `await` / `expect(...).resolves` |
| 定时器挂住进程 | 用 `jest.useFakeTimers()`，或测试结束 `app.close()` |
| 覆盖率虚高 | 排除 DTO/entity/main.ts，聚焦 service/controller |
| E2E 全局管道缺失 | 测试模块要手动 `useGlobalPipes` 等，与 main.ts 保持一致 |

## 11. 一句话总结

> Nest 测试三层：**单元**用 `Test.createTestingModule()` + `overrideProvider/Guard` 全 mock；**集成**用 Testcontainers 起真实 DB/Redis 测 SQL 与缓存；**E2E** 用 Supertest 打真实 HTTP（记得应用与 `main.ts` 一致的全局管道）。数据隔离靠 TRUNCATE 或事务回滚，CI 配覆盖率门禁 + 服务容器。
