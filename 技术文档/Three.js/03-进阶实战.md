# 03 进阶实战：着色器 · 后期 · 粒子 · 性能

第六周起进入“自定义外观与大规模场景”阶段，是区分初级与中级开发者的分水岭。

## GLSL 着色器（⭐⭐⭐⭐）

- 顶点着色器控制“位置变换”，片元着色器控制“像素颜色”。
- 通过 `ShaderMaterial` 注入自定义效果；噪声函数、光照模型、后处理滤镜均在此实现。
- 推荐入门：《The Book of Shaders》。

```js
const material = new THREE.ShaderMaterial({
  vertexShader: `
    varying vec2 vUv;
    void main() {
      vUv = uv;
      gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
    }`,
  fragmentShader: `
    varying vec2 vUv;
    void main() {
      gl_FragColor = vec4(vUv.x, vUv.y, 0.5, 1.0);
    }`,
});
```

## 后期处理（EffectComposer）

用 `EffectComposer` 串联 `RenderPass` + 效果 Pass：

- `UnrealBloomPass`（辉光）
- `SSAO`（环境光遮蔽）
- 景深、运动模糊、色调映射

```js
const composer = new THREE.EffectComposer(renderer);
composer.addPass(new THREE.RenderPass(scene, camera));
composer.addPass(new THREE.UnrealBloomPass(
  new THREE.Vector2(window.innerWidth, window.innerHeight), 1.5, 0.4, 0.85
));
// 渲染时改用 composer.render() 替代 renderer.render()
```

## 粒子系统

- `Points` + `PointsMaterial` 实现星空、雪花、火焰。
- 大规模粒子优先用 `InstancedMesh` 或 GPU 计算着色器。

```js
const geo = new THREE.BufferGeometry();
const positions = new Float32Array(count * 3); // 填充坐标
geo.setAttribute('position', new THREE.BufferAttribute(positions, 3));
const points = new THREE.Points(geo, new THREE.PointsMaterial({ size: 0.05 }));
```

## 性能优化（⭐⭐⭐⭐）

- 减少 **draw call**：`InstancedMesh` 实例化、`BufferGeometryUtils.mergeGeometries` 合批。
- `LOD` 分级显示（远处用低模）。
- 纹理 / KTX2 压缩；谨慎使用动态数据。

```js
const mesh = new THREE.InstancedMesh(geometry, material, 10000);
// 用 setMatrixAt(i, matrix) 设置每个实例变换
```

## 动画系统

- `AnimationMixer` 播放骨骼/关键帧 `AnimationClip`（模型自带动画）。
- UI 补间用 `Tween.js` 或 `GSAP`。

```js
const mixer = new THREE.AnimationMixer(gltf.scene);
mixer.clipAction(gltf.animations[0]).play();
```

## 内存管理

切换场景/销毁对象务必 `dispose`，否则内存泄漏导致卡顿：

```js
function cleanScene() {
  scene.traverse((obj) => {
    if (obj.isMesh) { obj.geometry.dispose(); obj.material.dispose(); }
  });
  renderer.dispose();
  texture?.dispose();
}
```
