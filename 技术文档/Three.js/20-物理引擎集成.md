# 20. 物理引擎集成（Rapier / Cannon / Ammo）

> 来源可信度：**官方 API 名录确认 + 标准实践**（基于 threejs.org `Addons → PHYSICS` 分类：AmmoPhysics / JoltPhysics / RapierPhysics；API 名录经官网抓取确认。Rapier 为官方 addon 主推）
> 关联：`06-场景图与Object3D变换.md`、`12-动画系统.md`、`16-性能优化与调试.md`

## 1. 为什么需要物理引擎

Three.js 只负责**渲染**，不知道重力、碰撞、摩擦。需要物理效果（掉落、弹跳、堆叠、车辆、布料）时引入物理引擎。

**核心分工**：物理引擎算位置/旋转 → 每帧同步到 Three.js 的 mesh。

```
物理世界 (step) → 读取刚体位姿 → 写入 mesh.position/quaternion → 渲染
```

## 2. 引擎选型

| 引擎 | 语言 | 官方 addon | 特点 |
|------|------|-----------|------|
| **Rapier** | Rust → WASM | ✅ `RapierPhysics` | **推荐**，现代、快、API 友好 |
| Cannon-es | JS | ❌（社区） | 老牌、纯 JS、轻量，适合简单场景 |
| Ammo.js | C++ (Bullet) → WASM | ✅ `AmmoPhysics` | 功能全（软体/车辆），体积大 |
| Jolt | C++ → WASM | ✅ `JoltPhysics` | 新，性能强 |

**建议**：新项目用 **Rapier**（官方 addon + 活跃维护 + WASM 性能好）。

## 3. Rapier 基础（推荐）

```bash
npm i @dimforge/rapier3d-compat
```

> 用 `-compat` 版本：把 WASM 内联成 base64，无需额外配置打包器。

```js
import RAPIER from '@dimforge/rapier3d-compat';

await RAPIER.init();     // ★ 必须先初始化 WASM

// ---- 创建物理世界 ----
const gravity = { x: 0, y: -9.81, z: 0 };
const world = new RAPIER.World(gravity);
```

## 4. 完整例子：掉落的箱子堆叠（Rapier + Three.js）

```js
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';
import RAPIER from '@dimforge/rapier3d-compat';

await RAPIER.init();

// ================= Three.js 部分 =================
const scene = new THREE.Scene();
scene.background = new THREE.Color(0x88bbdd);

const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 100);
camera.position.set(8, 6, 12);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;
document.body.appendChild(renderer.domElement);

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;
controls.target.set(0, 1, 0);

scene.add(new THREE.HemisphereLight(0xffffff, 0x444444, 0.6));
const dir = new THREE.DirectionalLight(0xffffff, 2);
dir.position.set(6, 12, 8);
dir.castShadow = true;
dir.shadow.mapSize.set(2048, 2048);
dir.shadow.camera.left = -10; dir.shadow.camera.right = 10;
dir.shadow.camera.top = 10;   dir.shadow.camera.bottom = -10;
scene.add(dir);

// ================= 物理世界 =================
const world = new RAPIER.World({ x: 0, y: -9.81, z: 0 });

// 保存 mesh ↔ body 的配对，每帧同步
const objects = [];

function addMeshBody(mesh, body) {
  objects.push({ mesh, body });
}

// ---- 地面 ----
const groundMesh = new THREE.Mesh(
  new THREE.PlaneGeometry(30, 30),
  new THREE.MeshStandardMaterial({ color: 0x556677, roughness: 0.9 })
);
groundMesh.rotation.x = -Math.PI / 2;
groundMesh.receiveShadow = true;
scene.add(groundMesh);

// 地面刚体：fixed（固定不动）
const groundBody = world.createRigidBody(
  RAPIER.RigidBodyDesc.fixed().setTranslation(0, 0, 0)
);
world.createCollider(
  RAPIER.ColliderDesc.cuboid(15, 0.1, 15).setTranslation(0, -0.1, 0),
  groundBody
);

// ---- 一堆箱子 ----
const boxGeo = new THREE.BoxGeometry(1, 1, 1);
const boxMat = new THREE.MeshStandardMaterial({ color: 0xe08a3c, roughness: 0.4 });
const colors = [0xe08a3c, 0x3ca0e0, 0x8ae03c, 0xe03c8a];

for (let i = 0; i < 30; i++) {
  const x = (Math.random() - 0.5) * 3;
  const y = 2 + i * 1.1;
  const z = (Math.random() - 0.5) * 3;

  const mesh = new THREE.Mesh(boxGeo, new THREE.MeshStandardMaterial({
    color: colors[i % colors.length], roughness: 0.4
  }));
  mesh.castShadow = true;
  mesh.receiveShadow = true;
  scene.add(mesh);

  // 动态刚体
  const body = world.createRigidBody(
    RAPIER.RigidBodyDesc.dynamic().setTranslation(x, y, z)
  );
  // 碰撞体：半边长 0.5（因为 BoxGeometry 边长 1）
  world.createCollider(
    RAPIER.ColliderDesc.cuboid(0.5, 0.5, 0.5)
      .setRestitution(0.3)      // 弹性
      .setFriction(0.7),        // 摩擦
    body
  );

  addMeshBody(mesh, body);
}

// ================= 渲染循环 =================
const clock = new THREE.Clock();
const fixedTimeStep = 1 / 60;

renderer.setAnimationLoop(() => {
  // ① 推进物理世界
  world.step();

  // ② 把物理位姿同步到 mesh
  for (const { mesh, body } of objects) {
    const t = body.translation();      // {x,y,z}
    const r = body.rotation();         // {x,y,z,w} 四元数
    mesh.position.set(t.x, t.y, t.z);
    mesh.quaternion.set(r.x, r.y, r.z, r.w);
  }

  controls.update();
  renderer.render(scene, camera);
});

// 点击：从上空丢一个新球
addEventListener('click', () => {
  const radius = 0.4;
  const mesh = new THREE.Mesh(
    new THREE.SphereGeometry(radius, 32, 32),
    new THREE.MeshStandardMaterial({ color: 0xff3333, roughness: 0.2, metalness: 0.3 })
  );
  mesh.castShadow = true;
  scene.add(mesh);

  const body = world.createRigidBody(
    RAPIER.RigidBodyDesc.dynamic().setTranslation(
      (Math.random() - 0.5) * 4, 12, (Math.random() - 0.5) * 4
    )
  );
  world.createCollider(
    RAPIER.ColliderDesc.ball(radius).setRestitution(0.7),
    body
  );
  addMeshBody(mesh, body);
});
```

## 5. Rapier 核心概念

| 概念 | 说明 | API |
|------|------|-----|
| **World** | 物理世界，含重力 | `new RAPIER.World(gravity)` |
| **RigidBody** | 刚体 | `world.createRigidBody(RigidBodyDesc.xxx())` |
| **Collider** | 碰撞形状（挂在刚体上） | `world.createCollider(ColliderDesc.xxx(), body)` |

### RigidBody 类型

```js
RAPIER.RigidBodyDesc.fixed()      // 固定（地面、墙）
RAPIER.RigidBodyDesc.dynamic()    // 动态（受重力、可推）
RAPIER.RigidBodyDesc.kinematicPositionBased()  // 运动学（代码控制位置，推开别人但自己不受力）
RAPIER.RigidBodyDesc.kinematicVelocityBased()  // 运动学（按速度）
```

### 常用 Collider 形状

```js
RAPIER.ColliderDesc.cuboid(hx, hy, hz)    // 盒子（半边长！）
RAPIER.ColliderDesc.ball(r)               // 球
RAPIER.ColliderDesc.cylinder(hh, r)       // 圆柱
RAPIER.ColliderDesc.capsule(hh, r)        // 胶囊（角色常用）
RAPIER.ColliderDesc.cone(hh, r)           // 圆锥
RAPIER.ColliderDesc.trimesh(vertices, indices)  // 三角网格（静态复杂地形）
RAPIER.ColliderDesc.heightfield(nrows, ncols, heights, scale)  // 高度场（地形）
```

> ⚠️ `cuboid` 参数是**半边长**（half-extents），不是全尺寸。`BoxGeometry(1,1,1)` → `cuboid(0.5, 0.5, 0.5)`。

### 常用设置

```js
const body = world.createRigidBody(
  RAPIER.RigidBodyDesc.dynamic()
    .setTranslation(0, 5, 0)
    .setRotation({ x: 0, y: 0, z: 0, w: 1 })
    .setLinearDamping(0.5)        // 线性阻尼（空气阻力）
    .setAngularDamping(0.5)       // 角阻尼
    .setCanSleep(true)            // 静止后休眠（省性能）
);

world.createCollider(
  RAPIER.ColliderDesc.ball(1)
    .setRestitution(0.8)          // 弹性 0-1
    .setFriction(0.5)             // 摩擦
    .setDensity(2.0)              // 密度（影响质量）
    .setSensor(false),            // true = 传感器（只检测不碰撞）
  body
);

// 施加力/冲量
body.applyImpulse({ x: 0, y: 5, z: 0 }, true);
body.addForce({ x: 10, y: 0, z: 0 }, true);
body.setLinvel({ x: 0, y: 0, z: -5 }, true);   // 直接设速度

// 读取状态
const pos = body.translation();
const rot = body.rotation();
const vel = body.linvel();
```

## 6. 碰撞事件与射线检测

```js
// ---- 碰撞事件（需 EventQueue）----
const eventQueue = new RAPIER.EventQueue(true);

renderer.setAnimationLoop(() => {
  world.step(eventQueue);

  eventQueue.drainCollisionEvents((h1, h2, started) => {
    if (started) console.log('碰撞开始', h1, h2);
    else console.log('碰撞结束', h1, h2);
  });

  // ...
});

// 创建 collider 时启用事件
world.createCollider(
  RAPIER.ColliderDesc.ball(0.5).setActiveEvents(RAPIER.ActiveEvents.COLLISION_EVENTS),
  body
);

// ---- 物理射线检测（拾取/射击）----
const ray = new RAPIER.Ray({ x: 0, y: 10, z: 0 }, { x: 0, y: -1, z: 0 });
const hit = world.castRay(ray, 100, true);   // maxToi, solid
if (hit) {
  console.log('击中距离:', hit.timeOfImpact);
  const hitCollider = hit.collider;
  const hitBody = hitCollider.parent();
}
```

## 7. 固定步长（重要）

物理引擎需**固定时间步**才稳定。用累加器模式：

```js
const fixedTimeStep = 1 / 60;
let accumulator = 0;

renderer.setAnimationLoop(() => {
  const dt = Math.min(clock.getDelta(), 0.1);   // 限制最大 dt 防"死亡螺旋"
  accumulator += dt;

  while (accumulator >= fixedTimeStep) {
    world.step();                // Rapier 默认步长即 1/60
    accumulator -= fixedTimeStep;
  }

  // 同步位姿（可选插值让画面更平滑）
  syncMeshes();
  renderer.render(scene, camera);
});
```

## 8. 官方 addon 方式（RapierPhysics）

Three.js 提供封装好的 addon，自动管理 mesh ↔ body 同步：

```js
import RapierPhysics from 'three/addons/physics/RapierPhysics.js';

const physics = await RapierPhysics();
physics.addScene(scene);          // 把整个 scene 的网格变成碰撞体

// 添加动态物体
physics.add(mesh, { mass: 1, restitution: 0.5 });

// 渲染循环
renderer.setAnimationLoop(() => {
  physics.step();                 // 内部推进并自动同步
  renderer.render(scene, camera);
});
```

> 适合快速原型；需要精细控制（关节、传感器、事件）时直接用 Rapier API。

## 9. 性能与常见坑

| 问题 | 解决 |
|------|------|
| 物体穿模（高速穿透） | 开启 CCD：`RigidBodyDesc.dynamic().setCcdEnabled(true)` |
| 抖动/不稳定 | 用固定步长；增大密度差；避免极小碰撞体（< 0.1） |
| 帧率下降 | 减少动态刚体；静态物体用 `fixed`；启用 `setCanSleep` |
| 物体陷入地下 | 检查 collider 半尺寸与 mesh 是否匹配 |
| trimesh 动态体很慢 | trimesh 只用于静态；动态用凸包/基本形状组合 |
| WASM 加载失败 | 用 `-compat` 版或配置打包器处理 .wasm |

## 10. 一句话总结

> 物理引擎负责算力学位姿、Three.js 只渲染。用 **Rapier**（WASM，官方 addon）：`World` + `RigidBody`（fixed/dynamic/kinematic）+ `Collider`（cuboid/ball/capsule，注意**半尺寸**）；每帧 `world.step()` 后把 `translation()`/`rotation()` 同步到 mesh；用**固定时间步**保稳定，用 EventQueue 收碰撞事件、`castRay` 做物理拾取。
