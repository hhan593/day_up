# 01 基础入门：三大对象与场景图

一切 Three.js 程序都围绕“场景 + 相机 + 渲染器”展开，理解它们是第一周的核心。

## Scene 场景（容器）

所有 3D 对象的“舞台”，采用**场景图（Scene Graph）**树状结构管理。可添加 `fog` 雾效、背景色/贴图。

```js
const scene = new THREE.Scene();
```

## Camera 相机（视角）

- `PerspectiveCamera`（透视，近大远小）最常用。
- `OrthographicCamera`（正交，无透视，适合 2.5D / 地图）。
- 需设置 `aspect`，并在窗口 `resize` 时调用 `updateProjectionMatrix()`。

```js
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
```

## Renderer 渲染器（引擎）

- `WebGLRenderer({ antialias: true })` 是默认后端。
- 新项目可直接用 `WebGPURenderer`（自动 fallback WebGL2）。
- 开启 `shadowMap.enabled` 与合理设置 `pixelRatio`。

```js
const renderer = new THREE.WebGLRenderer({ antialias: true });
```

## 坐标系（右手系）

Three.js 使用**右手坐标系**：X 向右、Y 向上、Z 向屏幕外。物体默认绕自身原点旋转，注意 `pivot` 与 `group` 的使用。

## Geometry + Material = Mesh

- 几何体定义“形状”，材质定义“外观”，二者组合成可渲染的 `Mesh`。
- 内置几何体：`BoxGeometry` / `SphereGeometry` / `CylinderGeometry` / `TorusGeometry` / `PlaneGeometry` 等。

```js
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshPhongMaterial({ color: 0x00ff00, shininess: 100 });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);
```

## 动画循环

用 `requestAnimationFrame`（非 `setInterval`）驱动逐帧渲染；WebXR 下改用 `renderer.setAnimationLoop()`。

```js
function animate() {
  requestAnimationFrame(animate);
  renderer.render(scene, camera);
}
animate();
```
