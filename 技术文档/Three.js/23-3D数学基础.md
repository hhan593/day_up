# 23. 3D 数学基础：向量、矩阵、四元数与变换链

> 来源可信度：**官方源码 JSDoc 逐字核对**（`src/math/Vector3.js`、`src/math/Matrix4.js`、`src/math/Quaternion.js`、`src/math/Euler.js`，mrdoob/three.js dev 分支）+ MDN WebGL 官方教程（Model View Projection 篇）
> 配套可运行示例：`threejs` 项目 `examples/23-math/`（`npm run dev` 后访问 `/examples/index.html`）
> 关联：`06-场景图与Object3D变换.md`、`07-相机与坐标系.md`、`14-着色器GLSL与ShaderMaterial.md`

## 1. 为什么必须懂数学

Three.js 的价值是**替你做矩阵运算**：`mesh.position` 一改，引擎自动更新世界矩阵并传给 GPU。但以下场景绕不开底层：

- **着色器**：GLSL 里 `projectionMatrix * modelViewMatrix * vec4(position, 1.0)` 每个矩阵都要自己理解（见 `14`）；
- **调试**："为什么模型转反了 / 法线错了 / 子对象跟随错位"——全部是矩阵顺序或变换链问题；
- **性能**：批量对象用一次 `Matrix4` 合并计算，避免逐对象 `Object3D` 开销（见 `16`）。

## 2. 向量 Vector3：方向与长度

向量 = **方向 + 长度**（起点默认在原点）。位置只是"从原点出发的向量"。

### 2.1 两个核心运算

| 运算 | 公式 | 几何意义 | 图形学用途 |
|------|------|---------|-----------|
| **点积** `a·b` | `ax*bx + ay*by + az*bz`，等于 `|a||b|cosθ` | 夹角与投影 | **光照**（法线与光线方向夹角）、背向剔除 |
| **叉积** `a×b` | 结果向量垂直于 a、b 所在平面，长度 `|a||b|sinθ` | 求垂直方向 | **求平面法线**、构建正交基、判断绕向 |

点积最常用的图形学公式——Lambert 漫反射：

```js
// 表面法线 N 与光线方向 L 的点积 = 光照强度（0~1）
const intensity = Math.max(normal.dot(lightDir), 0);
```

叉积的**方向**遵循右手定则（Three.js 使用右手坐标系，见 `07`）：`new THREE.Vector3(1,0,0).cross(new THREE.Vector3(0,1,0))` → `(0,0,1)`（x 叉 y 得 z）。

### 2.2 官方 API 速查（源码核实）

```js
const a = new THREE.Vector3(1, 0, 0);
const b = new THREE.Vector3(0, 1, 0);

// 链式调用：多数可变方法返回 this
a.add(b).multiplyScalar(2).normalize();

// 高频方法（全部存在于官方源码）
a.dot(b);                        // 点积 → 0
a.cross(b);                      // a = a×b（修改自身）
a.crossVectors(b, c);            // a = b×c
a.addScaledVector(v, s);         // a += v*s（累加位移的最省写法）
a.length();  a.normalize();      // 模长 / 归一化
a.distanceTo(b);                 // 两点距离（内部即 |a-b|）
a.lerp(b, alpha);                // 线性插值，alpha∈[0,1]
a.lerpVectors(v1, v2, alpha);    // a = lerp(v1, v2, alpha)
a.applyMatrix4(m);               // 矩阵变换
a.applyQuaternion(q);            // 四元数旋转
a.project(camera);               // 世界坐标 → NDC（-1~1），用于"3D 投到 2D 屏幕"
a.unproject(camera);             // NDC → 世界坐标，用于"屏幕点反投回 3D"（Raycaster 基础）
a.applyAxisAngle(axis, angle);   // 绕任意轴旋转
a.angleTo(b);                    // 两向量夹角（弧度）
a.clone();  a.copy(v);           // 复制（⚠️ 直接赋值 = 引用共享，常见坑）
```

> ⚠️ **新手第一大坑**：`v2.position.copy(v1.position)` 才是复制；`v2.position = v1.position` 是引用赋值，之后动一个动两个。

## 3. 矩阵 Matrix4：变换的复合

平移、旋转、缩放都可以写成一个 4×4 矩阵；**矩阵相乘 = 变换复合**。这就是为什么 WebGL 用 4×4 而不是 3×3：平移需要第 4 列（齐次坐标 w）。

### 3.1 TRS：位置、旋转、缩放的合成

一个 Object3D 的局部变换 = **T(平移) · R(旋转) · S(缩放)**，Three.js 内部用 `Matrix4.compose` 一步合成（源码核实签名）：

```js
const m = new THREE.Matrix4();
m.compose(position, quaternion, scale);   // T*R*S 一次合成
// 反向拆解
m.decompose(position, quaternion, scale);
```

`Object3D.matrix` 就是这个 compose 的结果；`matrixWorld` 再乘上所有祖先的矩阵（见 `06`）。

### 3.2 乘法顺序：A·B ≠ B·A

矩阵乘法不满足交换律——**先施加的变换在右侧**：

```js
const m = new THREE.Matrix4();
m.multiply(other);        // m = m * other（other 的变换先施加）
m.premultiply(other);     // m = other * m（other 的变换后施加）
```

直觉示例：`T·R`（右边的 R 先施加：**先旋转、后平移**）= 物体在平移后的位置**原地自转**；`R·T`（**先平移、后旋转**）= 整个物体被"甩着"**绕世界原点公转**。**顶点变换顺序 = 矩阵从右往左读**（示例见 `examples/23-math/02`）。

### 3.3 列主序存储

`Matrix4.elements` 是 **16 长度的一维数组，列主序（column-major）**——这是 OpenGL/GLSL 的约定，与数学书上的行书写法互为转置。构造函数 `new Matrix4(n11, n12, ...)` 的参数却是**行主序书写**（官方源码注释明确说明）。手动调 GPU 数据时才需要关心；日常用 API 即可。

### 3.4 官方 API 速查（源码核实）

```js
m.makeTranslation(x, y, z);              // 构造平移矩阵
m.makeRotationX/Y/Z(theta);              // 绕单轴旋转（弧度）
m.makeRotationAxis(axis, angle);         // 绕任意轴旋转
m.makeRotationFromEuler(euler);          // 欧拉角 → 旋转矩阵
m.makeRotationFromQuaternion(q);
m.makeScale(x, y, z);
m.lookAt(eye, target, up);               // 构造"看向目标"的旋转矩阵（相机基础）
m.setPosition(x, y, z);                  // 只改平移列，保留旋转缩放
m.invert();  m.transpose();  m.determinant();
m.getMaxScaleOnAxis();                   // 最大缩放轴（判断整体尺度）
m.multiplyMatrices(a, b);                // m = a*b
m.premultiply(m2);                       // m = m2*m
m.extractBasis(xAxis, yAxis, zAxis);     // 取三个基向量（本地轴向）
m.makeBasis(xAxis, yAxis, zAxis);        // 用三个基向量构造矩阵
m.decompose(pos, quat, scale);           // 拆回 TRS
m.toArray() / m.fromArray(arr);          // elements 序列化
```

## 4. 变换链：一个顶点到屏幕的旅程

WebGL/Three.js 渲染时，每个顶点要经过一条**固定的矩阵链**（MDN 官方教程称 Model View Projection）：

```
局部坐标(模型空间)
   │  modelMatrix（Object3D.matrixWorld：层级变换的累积）
   ▼
世界坐标(场景空间)          ← raycaster、碰撞检测在这一层
   │  viewMatrix（相机世界矩阵的逆 = camera.matrixWorldInverse）
   ▼
观察坐标(相机空间)          ← 相机在原点看向 -z
   │  projectionMatrix（透视/正交投影）
   ▼
裁剪坐标(clip space, -w~w)
   │  透视除法 ÷w（GPU 自动）
   ▼
NDC 标准设备空间(-1~1)
   │  视口变换（GPU 自动，对应 renderer.setSize）
   ▼
屏幕像素坐标
```

Three.js 在着色器里注入的内置 uniform 与上表的对应（`ShaderMaterial` 可直接用）：

| GLSL uniform | 含义 | 手写等价 |
|---|---|---|
| `modelMatrix` | 局部 → 世界 | `mesh.matrixWorld` |
| `viewMatrix` | 世界 → 相机 | `camera.matrixWorldInverse` |
| `modelViewMatrix` | 局部 → 相机 | `viewMatrix * modelMatrix`（已合并，省一次乘法） |
| `projectionMatrix` | 相机 → 裁剪 | `camera.projectionMatrix` |
| `normalMatrix` | 模型法线 → 视图空间（3×3） | `modelViewMatrix` 逆的转置，**应对非均匀缩放** |

> 💡 **为什么法线要单独的 normalMatrix**：非均匀缩放会扭曲法线方向（把球压扁后，法线不再垂直于表面）。正确变换法线 = 用「模型矩阵逆的转置」。Three.js 自动提供，但自己写着色器时必须记得用它而不是直接乘 modelMatrix。

完整链在顶点着色器里就一行（`14` 章的第一个例子）：

```glsl
gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
```

## 5. 欧拉角 Euler：直观但有死锁

`Object3D.rotation` 是 `Euler` 类型：三个轴角 + **旋转顺序**。默认顺序 `'XYZ'`（先绕 X，再 Y，再 Z——从右往左施加矩阵），可选 `'YXZ' 'ZXY' ...` 六种（源码 `Euler.js` 核实）。

**万向节死锁（Gimbal Lock）**：当中间轴旋转 ±90° 时，第一轴与第三轴的旋转轴重合，丢失一个自由度。经典复现：默认 XYZ 顺序下，`rotation.x = -90°` 后再改 `rotation.y` 和 `rotation.z`，物体只会绕同一根轴转。

**实用对策**：

```js
// FPS 相机（yaw 先于 pitch）：用 YXZ 顺序避免死锁
camera.rotation.order = 'YXZ';
camera.rotation.y = yaw;    // 左右看
camera.rotation.x = pitch;  // 上下看

// 3D 建模导入的模型若旋转异常，检查欧拉顺序是否与 DCC 软件（Blender 默认 XYZ）一致
```

需要连续、任意方向的旋转动画时，直接换四元数。

## 6. 四元数 Quaternion：无死锁的旋转

四元数用 4 个数 `(x, y, z, w)` 表示旋转：一个**旋转轴 + 角度**的紧凑编码。相比欧拉角：**无万向节死锁、插值平滑、可稳定连乘**。相比旋转矩阵：数值误差不会漂移变形（矩阵连乘会逐渐"歪斜"，四元数重归一化即可恢复）。

`Object3D.quaternion` 与 `rotation` **自动同步**（改任一个，另一个跟着变，本质是同一旋转的两种表示）。

### 6.1 官方 API 速查（源码逐字核实）

```js
const q = new THREE.Quaternion();

q.setFromAxisAngle(new THREE.Vector3(0, 1, 0), Math.PI / 2); // 绕 Y 轴转 90°
q.setFromEuler(new THREE.Euler(0, Math.PI / 4, 0));          // 欧拉角 → 四元数
q.setFromUnitVectors(vFrom, vTo);                            // ★ "从 A 朝向 B"：箭头/导弹瞄准
q.setFromRotationMatrix(m);

q.multiply(q2);          // q = q * q2（先施加 q2，同矩阵规则）
q.premultiply(q2);       // q = q2 * q
q.invert();              // 逆旋转
q.slerp(qb, t);          // 球面插值：this → qb，t∈[0,1]（平滑转身）
q.slerpQuaternions(qa, qb, t);   // 实例方法：this = slerp(qa, qb, t)
q.clone(); q.copy(); q.identity(); q.dot(q2);
q.angleTo(q2);           // 两旋转的夹角
q.rotateTowards(q2, step);      // 朝目标旋转最多 step 弧度（帧循环友好）
```

> ⚠️ 注意：`slerpQuaternions(qa, qb, t)` 是**实例方法**（把结果写入自身），官方源码中静态的批量版本是 `Quaternion.slerpFlat(...)`。

### 6.2 经典示例：平滑转向目标

```js
// 每帧：角色从当前朝向平滑转向目标点
const targetDir = new THREE.Vector3().subVectors(targetPos, mesh.position).normalize();
const currentDir = new THREE.Vector3(0, 0, 1).applyQuaternion(mesh.quaternion);
const targetQ = new THREE.Quaternion().setFromUnitVectors(currentDir, targetDir);

// rotateTowards 限制每帧最大转角，比 slerp 直接给 t 更可控
mesh.quaternion.rotateTowards(targetQ, delta * turnSpeed); // turnSpeed: rad/s
```

### 6.3 欧拉角 vs 四元数选型

| 场景 | 推荐 | 原因 |
|------|------|------|
| 摆放场景物体、编辑器调整 | `rotation`（Euler） | 三个数值直观可读 |
| FPS / 轨道相机 | Euler（`'YXZ'`）或四元数累乘 | 角度有限，不触发死锁即可 |
| 角色朝向、导弹追踪、IK | `Quaternion` + `setFromUnitVectors` | 任意方向旋转无死锁 |
| 动画插值（转身、镜头运镜） | `slerp` / `rotateTowards` | 欧拉插值路径怪异 |
| glTF 动画 | 四元数（文件内部即如此存储） | 行业标准 |

## 7. GLSL 侧的对应（写给 `14` 章铺垫）

```glsl
uniform mat4 modelMatrix;    // mat4: 4x4 矩阵，与 Matrix4.elements 同为列主序
uniform mat3 normalMatrix;

vec3 worldPos = (modelMatrix * vec4(position, 1.0)).xyz;  // vec4→vec3 取 xyz
vec3 n = normalize(normalMatrix * normal);                // 法线记得归一化（插值会破坏长度）
```

`Matrix4` 传给 GLSL 时**无需转置**——Three.js 两者都是列主序，直接 `uniforms: { uMat: { value: matrix } }`。

## 8. 常见坑清单

| 现象 | 原因 | 解法 |
|------|------|------|
| 改了 position/rotation 但画面没变 | `matrixAutoUpdate = false` 时不会自动重算 | 手动 `updateMatrix()` 或恢复默认 |
| 两物体"绑在一起"动 | Vector/Matrix 用 `=` 赋值成引用 | 用 `.copy()` / `.clone()` |
| 绕错轴旋转 / 公转不自转 | 矩阵乘法顺序理解反了 | 记住"先施加的在右"；增量旋转绕**自身轴**用 `multiply`，绕**世界轴**用 `premultiply` |
| 非均匀缩放后光照错乱 | 法线被缩放扭曲 | 着色器用 `normalMatrix`，别用 modelMatrix 变法线 |
| 连续旋转后模型越来越歪 | 矩阵连乘累积误差 | 用四元数存旋转，必要时 `normalize()` |
| `rotation.x = 90°` 后 y/z 轴乱转 | 欧拉角万向节死锁 | `rotation.order = 'YXZ'` 或改用四元数 |
| 父物体缩放 2x，子物体尺寸异常 | 子物体继承父的全部变换（见 `06`） | `getWorldScale()` 取真实缩放 |
| 插值动画在拐角处"抄近路"穿模 | Euler lerp 是分量插值 | 用 `Quaternion.slerp` |
