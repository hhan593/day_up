# 10. 光照与阴影

> 来源可信度：**官方 API 名录确认 + 标准实践**（基于 threejs.org `Lights/` 分类：AmbientLight / DirectionalLight / PointLight / SpotLight / HemisphereLight / RectAreaLight / LightProbe / IESSpotLight；API 名录经官网抓取确认）
> 关联：`09-材质与纹理详解.md`

## 1. 光源类型

| 光源 | 说明 | 投影 | 开销 |
|------|------|------|------|
| `AmbientLight` | 均匀环境光，无方向 | ❌ | 极低 |
| `HemisphereLight` | 天空色↔地面色渐变 | ❌ | 极低 |
| `DirectionalLight` | 平行光（太阳） | ✅ | 低 |
| `PointLight` | 点光源（灯泡） | ✅ | 中 |
| `SpotLight` | 聚光灯（舞台灯） | ✅ | 高 |
| `RectAreaLight` | 面光源（灯箱） | ❌ | 高（需 `RectAreaLightUniformsLib`） |
| `LightProbe` | 球谐环境光 | ❌ | 低 |

## 2. 各光源用法

```js
// 环境光：整体提亮，防止死黑
scene.add(new THREE.AmbientLight(0xffffff, 0.4));

// 半球光：天空蓝 + 地面棕，比 Ambient 自然
const hemi = new THREE.HemisphereLight(0x88bbff, 0x443322, 0.6);
scene.add(hemi);

// 平行光：太阳，方向由 position → target(默认原点)
const sun = new THREE.DirectionalLight(0xffffff, 2);
sun.position.set(10, 20, 10);
scene.add(sun);

// 点光源：距离衰减
const point = new THREE.PointLight(0xff8800, 10, 50, 2); // 颜色,强度,距离,衰减
point.position.set(0, 5, 0);
scene.add(point);

// 聚光灯：锥形
const spot = new THREE.SpotLight(0xffffff, 100);
spot.position.set(0, 10, 0);
spot.angle = Math.PI / 6;      // 锥角
spot.penumbra = 0.3;           // 边缘柔化 0-1
spot.decay = 2;
spot.distance = 50;
spot.target.position.set(0, 0, 0);
scene.add(spot);
scene.add(spot.target);        // ★ target 必须加进场景才生效
```

## 3. 阴影：三个开关缺一不可

```js
renderer.shadowMap.enabled = true;                 // ① 渲染器
renderer.shadowMap.type = THREE.PCFSoftShadowMap;  // 柔和阴影

sun.castShadow = true;                             // ② 光源
sun.shadow.mapSize.set(2048, 2048);                // 阴影贴图分辨率
sun.shadow.camera.near = 1;
sun.shadow.camera.far = 100;
sun.shadow.camera.left = -20;                      // 阴影相机范围（正交）
sun.shadow.camera.right = 20;
sun.shadow.camera.top = 20;
sun.shadow.camera.bottom = -20;
sun.shadow.bias = -0.0005;                         // 消除阴影粉刺
sun.shadow.normalBias = 0.02;

mesh.castShadow = true;                            // ③ 投射阴影的物体
ground.receiveShadow = true;                       // 接收阴影的物体
```

**阴影类型**：`BasicShadowMap`（硬/快）、`PCFShadowMap`（默认）、`PCFSoftShadowMap`（软，常用）、`VSMShadowMap`（最软，易漏光）。

## 4. 完整例子：阴影 + 多光源场景

```js
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x1a1a2e);

const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 200);
camera.position.set(8, 8, 12);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
renderer.shadowMap.enabled = true;                       // ①
renderer.shadowMap.type = THREE.PCFSoftShadowMap;
renderer.toneMapping = THREE.ACESFilmicToneMapping;      // 电影级色调映射
renderer.toneMappingExposure = 1.1;
document.body.appendChild(renderer.domElement);

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;
controls.target.set(0, 1, 0);

// 地面（接收阴影）
const ground = new THREE.Mesh(
  new THREE.PlaneGeometry(40, 40),
  new THREE.MeshStandardMaterial({ color: 0x555566, roughness: 0.9 })
);
ground.rotation.x = -Math.PI / 2;
ground.receiveShadow = true;                             // ③
scene.add(ground);

// 主光：平行光 + 阴影
const sun = new THREE.DirectionalLight(0xffffff, 2.5);
sun.position.set(10, 15, 8);
sun.castShadow = true;                                   // ②
sun.shadow.mapSize.set(2048, 2048);
sun.shadow.camera.left = -15;
sun.shadow.camera.right = 15;
sun.shadow.camera.top = 15;
sun.shadow.camera.bottom = -15;
sun.shadow.camera.far = 60;
sun.shadow.bias = -0.0005;
scene.add(sun);

// 补光：半球光防死黑
scene.add(new THREE.HemisphereLight(0x8899ff, 0x222233, 0.5));

// 氛围：橙色点光
const point = new THREE.PointLight(0xff7733, 30, 30, 2);
point.position.set(-5, 3, -3);
scene.add(point);

// 物体
const sphere = new THREE.Mesh(
  new THREE.SphereGeometry(1.2, 48, 48),
  new THREE.MeshStandardMaterial({ color: 0xee5533, roughness: 0.3, metalness: 0.2 })
);
sphere.position.set(0, 1.2, 0);
sphere.castShadow = true;
scene.add(sphere);

const box = new THREE.Mesh(
  new THREE.BoxGeometry(2, 2, 2),
  new THREE.MeshStandardMaterial({ color: 0x33aaee, roughness: 0.5 })
);
box.position.set(4, 1, 2);
box.castShadow = true;
box.receiveShadow = true;
scene.add(box);

// 阴影调试助手（开发期用）
// scene.add(new THREE.DirectionalLightHelper(sun));
// scene.add(new THREE.CameraHelper(sun.shadow.camera));

const clock = new THREE.Clock();
renderer.setAnimationLoop(() => {
  const t = clock.getElapsedTime();
  sphere.position.y = 1.2 + Math.sin(t * 2) * 0.5;   // 弹跳，看阴影变化
  point.position.x = Math.cos(t) * 6;
  point.position.z = Math.sin(t) * 6;
  controls.update();
  renderer.render(scene, camera);
});
```

## 5. 色调映射与曝光

```js
renderer.toneMapping = THREE.ACESFilmicToneMapping;  // 推荐
renderer.toneMappingExposure = 1.0;
// 其他：ReinhardToneMapping / AgXToneMapping / NeutralToneMapping / CineonToneMapping
```

> 用了 `MeshStandardMaterial` + 强光源后，画面容易过曝。开 ACES 色调映射 + 调 exposure 解决。

## 6. 光照性能

- **光源越多越慢**：每个光源都会增加 shader 复杂度。实时场景建议 ≤ 4 个动态光。
- **阴影是最大开销**：点光/聚光的阴影需渲染 6 面/1 面立方体贴图。
- 优化手段：
  - 静态阴影：只渲染一次后 `light.shadow.autoUpdate = false`（或 `needsUpdate = true` 手动刷新）。
  - 用 `AmbientLight`/`HemisphereLight` 替代多个补光。
  - 烘焙光照到 `aoMap`/`lightMap`。

```js
// 静态场景：阴影只算一次
renderer.shadowMap.autoUpdate = false;
renderer.shadowMap.needsUpdate = true;   // 需要时手动刷新
```

## 7. 常见坑

| 现象 | 原因 | 解决 |
|------|------|------|
| 阴影完全不显示 | 三个开关没开全 | 检查 renderer/light/mesh |
| 阴影锯齿严重 | `mapSize` 太小或相机范围太大 | 提高 mapSize / 收紧 shadow.camera |
| 表面出现条纹（shadow acne） | 深度精度 | 调 `shadow.bias`（负的小值）/ `normalBias` |
| 阴影缺失（远处） | `shadow.camera.far` 太小 | 扩大阴影相机范围 |
| 金属物体全黑 | 没有 `envMap` | 设 `scene.environment`（见 09） |
| 画面过曝 | 光强过大 | 开 ACES + 降 intensity |

## 8. 一句话总结

> 阴影三开关（renderer/light/mesh）+ 阴影相机范围 + bias 调精度；用 ACES 色调映射防过曝；主光平行光、补光半球光，动态光控制在 4 个以内；静态场景关 `shadowMap.autoUpdate`。
