## 1. 先测量，再优化

```js
console.log(renderer.info);

// renderer.info.render = {
//   calls:    draw call 次数,
//   triangles: 三角形数,
//   points, lines, frame
// }
// renderer.info.memory = { geometries, textures }
// renderer.info.programs = 着色器程序数
```

**核心指标**：

| 指标 | 健康值 | 说明 |
|------|--------|------|
| `render.calls` | < 100（移动端 < 50） | **最重要**，draw call 是主要瓶颈 |
| `render.triangles` | < 100万（PC） | 三角形数 |
| `memory.geometries` / `textures` | 稳定不增长 | 增长说明泄漏 |
| `programs` | 稳定 | 材质种类数 |

## 2. 减少 Draw Call（最重要）

### 2.1 InstancedMesh（同一几何体大量重复）

```js
const count = 10000;
const mesh = new THREE.InstancedMesh(geometry, material, count);

const dummy = new THREE.Object3D();
for (let i = 0; i < count; i++) {
  dummy.position.set(
    Math.random() * 100 - 50,
    Math.random() * 100 - 50,
    Math.random() * 100 - 50
  );
  dummy.rotation.set(Math.random() * Math.PI, Math.random() * Math.PI, 0);
  dummy.scale.setScalar(Math.random() * 0.5 + 0.5);
  dummy.updateMatrix();
  mesh.setMatrixAt(i, dummy.matrix);

  // 每个实例单独颜色
  mesh.setColorAt(i, new THREE.Color().setHSL(Math.random(), 1, 0.5));
}
mesh.instanceMatrix.needsUpdate = true;
mesh.instanceColor.needsUpdate = true;
scene.add(mesh);
```

**1 个 draw call 渲染 10000 个物体**。适合：森林、人群、粒子、星域。

### 2.2 完整例子：InstancedMesh 星域 + 逐实例动画

```js
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(60, innerWidth / innerHeight, 0.1, 2000);
camera.position.z = 200;

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;

const COUNT = 20000;
const geometry = new THREE.BoxGeometry(0.5, 0.5, 0.5);
const material = new THREE.MeshStandardMaterial({ roughness: 0.4, metalness: 0.6 });
const stars = new THREE.InstancedMesh(geometry, material, COUNT);

const dummy = new THREE.Object3D();
const speeds = new Float32Array(COUNT);

for (let i = 0; i < COUNT; i++) {
  const r = 100 + Math.random() * 300;
  const theta = Math.random() * Math.PI * 2;
  const phi = Math.acos(Math.random() * 2 - 1);
  dummy.position.set(
    r * Math.sin(phi) * Math.cos(theta),
    r * Math.cos(phi) * 0.3,
    r * Math.sin(phi) * Math.sin(theta)
  );
  dummy.scale.setScalar(Math.random() * 2 + 0.5);
  dummy.updateMatrix();
  stars.setMatrixAt(i, dummy.matrix);
  stars.setColorAt(i, new THREE.Color().setHSL(Math.random() * 0.15 + 0.55, 0.8, 0.6));
  speeds[i] = 0.0005 + Math.random() * 0.002;
}
scene.add(stars);

scene.add(new THREE.AmbientLight(0xffffff, 0.8));
const light = new THREE.DirectionalLight(0xffffff, 2);
light.position.set(1, 1, 1);
scene.add(light);

// 逐帧更新（旋转整个星系即可，避免逐实例矩阵更新）
renderer.setAnimationLoop(() => {
  stars.rotation.y += 0.0005;
  controls.update();
  renderer.render(scene, camera);
});

// 监控
setInterval(() => {
  console.log('draw calls:', renderer.info.render.calls);  // 应该是 1
}, 3000);
```

## 3. 几何体与纹理优化

```js
// ① 降低分段数
new THREE.SphereGeometry(1, 32, 32);   // 而非 128,128

// ② 简化网格
import { SimplifyModifier } from 'three/addons/modifiers/SimplifyModifier.js';
const simplified = new SimplifyModifier().modify(geometry, vertexCount);

// ③ 纹理：用 2 的幂尺寸 + 压缩格式
tex.generateMipmaps = true;
tex.minFilter = THREE.LinearMipmapLinearFilter;
tex.anisotropy = renderer.capabilities.getMaxAnisotropy();  // 斜视更清晰

// KTX2 压缩纹理（GPU 原生压缩，体积小、解码快）
import { KTX2Loader } from 'three/addons/loaders/KTX2Loader.js';
const ktx2 = new KTX2Loader().setTranscoderPath('/basis/').detectSupport(renderer);
ktx2.load('/tex/compressed.ktx2', (t) => { material.map = t; });

// ④ DRACO 几何压缩
import { DRACOLoader } from 'three/addons/loaders/DRACOLoader.js';
const draco = new DRACOLoader().setDecoderPath('/draco/');
gltfLoader.setDRACOLoader(draco);
```

## 4. 渲染器设置

```js
// 像素比：移动端限制，避免高清屏渲染 3x 像素
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));

// 关闭不需要的特性
renderer.shadowMap.autoUpdate = false;    // 静态阴影只算一次
renderer.shadowMap.needsUpdate = true;    // 需要时手动刷新

// 按需渲染（静止场景不渲染，省电）
renderer.render(scene, camera);           // 只在需要时调用
// 或：controls.addEventListener('change', () => needsRender = true);

// 剔除
mesh.frustumCulled = true;                // 默认开
mesh.matrixAutoUpdate = false;            // 静态物体
mesh.updateMatrix();
```

## 5. 内存管理（防泄漏）

```js
// 移除物体时**必须**释放 GPU 资源
function disposeObject(obj) {
  obj.traverse((child) => {
    if (child.isMesh) {
      child.geometry.dispose();
      // 材质可能是数组
      const mats = Array.isArray(child.material) ? child.material : [child.material];
      mats.forEach((m) => {
        // 释放材质上的所有纹理
        for (const key in m) {
          const v = m[key];
          if (v && v.isTexture) v.dispose();
        }
        m.dispose();
      });
    }
  });
  obj.parent?.remove(obj);
}

scene.remove(mesh);
disposeObject(mesh);
```

**常见泄漏源**：忘记 `dispose()` 的 geometry/material/texture、未移除的事件监听、数组里残留的对象引用。

## 7. 性能清单

| 优化项 | 收益 |
|--------|------|
| 合并/实例化几何体 | ⭐⭐⭐ 大幅降 draw call |
| 限制像素比 ≤ 2 | ⭐⭐⭐ 移动端尤其明显 |
| 压缩纹理（KTX2）+ DRACO | ⭐⭐ 减小体积与显存 |
| 静态物体关 `matrixAutoUpdate` | ⭐⭐ |
| 静态阴影关 `autoUpdate` | ⭐⭐ |
| 减少实时光源 ≤ 4 | ⭐⭐ |
| LOD | ⭐⭐ 大场景 |
| 降低几何体分段 | ⭐ |
| 按需渲染 | ⭐⭐ 静止场景 |

## 8. 一句话总结

> 优化先看 `renderer.info.render.calls`；用 `InstancedMesh`/`BatchedMesh`/`mergeGeometries` 降 draw call；像素比限 2；纹理用 KTX2、几何用 DRACO；静态物体关 `matrixAutoUpdate` 与阴影 `autoUpdate`；移除物体务必 `dispose()` 防泄漏。
