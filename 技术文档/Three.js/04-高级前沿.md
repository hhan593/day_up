# 04 高级前沿：WebGPU · TSL · WebXR · 工程化

面向追求“生产级 / 沉浸式 / 现代工作流”的开发者，也是 2025–2026 的技术重心。

## WebGPURenderer（推荐渲染器）

- r171（2025）起生产可用、r182 起推荐。
- 零配置导入 `import { WebGPURenderer } from 'three/webgpu'`，不支持时自动 fallback WebGL2。
- 曼德布洛特测试相较 WebGL2 帧率提升约 320%。

```js
import { WebGPURenderer } from 'three/webgpu';
const renderer = new WebGPURenderer();
await renderer.init();
```

## TSL 着色语言（跨后端）

- Three Shading Language 用节点图描述着色逻辑，**一次编写同时编译到 GLSL 与 WGSL**。
- 配合 `NodeMaterial`，是未来自定义着色器的首选方式。

```js
import { MeshBasicNodeMaterial } from 'three/webgpu';
const material = new MeshBasicNodeMaterial();
// 通过 TSL 节点 API 描述着色逻辑，自动编译到双后端
```

## WebXR（VR/AR）

- 用 `VRButton` 与 `renderer.xr.enabled = true` 接入头显/手机 AR。
- 同一份场景可同时适配桌面与 XR 设备。
- 推荐 Nick Lever 的 WebXR 课程。

```js
import { VRButton } from 'three/addons/webxr/VRButton.js';
document.body.appendChild(VRButton.createButton(renderer));
renderer.xr.enabled = true;
renderer.setAnimationLoop(() => renderer.render(scene, camera));
```

## 物理引擎

- `cannon-es`（轻量，推荐）、`Ammo.js`（功能全）为刚体/碰撞提供真实物理。
- 与 `InstancedMesh` 结合做大规模模拟。

```js
import * as CANNON from 'cannon-es';
const world = new CANNON.World();
world.gravity.set(0, -9.82, 0);
```

## React Three Fiber（现代工作流）

- 熟悉 React 的开发者用 R3F 声明式组织 3D 场景。
- 配合 `Drei` 复用组件库，极大提升工程化效率。

```jsx
import { Canvas } from '@react-three/fiber';
import { OrbitControls } from '@react-three/drei';
<Canvas><mesh><boxGeometry /><meshStandardMaterial /></mesh><OrbitControls /></Canvas>
```
