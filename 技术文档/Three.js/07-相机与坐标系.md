# 07. 相机、坐标系与投影

> 来源可信度：**官方 API 名录确认 + 标准实践**（基于 threejs.org `Cameras/` 分类：PerspectiveCamera / OrthographicCamera / CubeCamera / ArrayCamera；名录经官网抓取确认）
> 关联：`01-基础入门.md`、`06-场景图与Object3D变换.md`

## 1. 右手坐标系

Three.js 使用**右手坐标系**：

- **+X** 向右
- **+Y** 向上
- **+Z** 朝向屏幕外（朝向观察者）

默认相机看向 **-Z** 方向。所以 `camera.position.z = 5` 时，位于原点的物体在视野内。

```js
const axes = new THREE.AxesHelper(5);  // 红=X 绿=Y 蓝=Z
scene.add(axes);
```

## 2. 透视相机 PerspectiveCamera（最常用）

模拟人眼/真实镜头：**近大远小**。

```js
const camera = new THREE.PerspectiveCamera(
  75,                                   // fov 视场角（垂直方向，度）
  window.innerWidth / window.innerHeight, // aspect 宽高比
  0.1,                                  // near 近裁剪面
  1000                                  // far 远裁剪面
);
camera.position.set(0, 2, 5);
camera.lookAt(0, 0, 0);   // 看向原点
scene.add(camera);
```

参数要点：

| 参数 | 建议 |
|------|------|
| `fov` | 45-75 常用；越大视野越广、畸变越强 |
| `aspect` | 必须等于画布宽高比，否则画面拉伸 |
| `near`/`far` | 尽量收紧范围，比值过大会导致 **z-fighting**（深度精度不足） |

**改参数后必须调用**：

```js
camera.aspect = window.innerWidth / window.innerHeight;
camera.updateProjectionMatrix();
```

## 3. 正交相机 OrthographicCamera

无透视变形，物体大小与距离无关。适合 **2D、等距视角、CAD、建筑图纸**。

```js
const aspect = window.innerWidth / window.innerHeight;
const d = 10;
const camera = new THREE.OrthographicCamera(
  -d * aspect,  // left
   d * aspect,  // right
   d,           // top
  -d,           // bottom
  0.1,          // near
  1000          // far
);
camera.position.set(20, 20, 20);
camera.lookAt(0, 0, 0);
```

## 4. 完整例子：窗口自适应 + 双相机切换

```js
import * as THREE from 'three';

const scene = new THREE.Scene();
scene.add(new THREE.AxesHelper(3));

const box = new THREE.Mesh(
  new THREE.BoxGeometry(2, 2, 2),
  new THREE.MeshNormalMaterial()
);
scene.add(box);

const aspect = innerWidth / innerHeight;

// 透视相机
const persp = new THREE.PerspectiveCamera(60, aspect, 0.1, 100);
persp.position.set(4, 4, 6);
persp.lookAt(0, 0, 0);

// 正交相机
const d = 5;
const ortho = new THREE.OrthographicCamera(-d * aspect, d * aspect, d, -d, 0.1, 100);
ortho.position.set(6, 6, 6);
ortho.lookAt(0, 0, 0);

let camera = persp;

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

// 窗口 resize：两个相机都要更新
addEventListener('resize', () => {
  const a = innerWidth / innerHeight;
  persp.aspect = a;
  persp.updateProjectionMatrix();        // 必须！

  ortho.left = -d * a;
  ortho.right = d * a;
  ortho.top = d;
  ortho.bottom = -d;
  ortho.updateProjectionMatrix();        // 必须！

  renderer.setSize(innerWidth, innerHeight);
});

// 按空格切换相机
addEventListener('keydown', (e) => {
  if (e.code === 'Space') camera = camera === persp ? ortho : persp;
});

renderer.setAnimationLoop(() => {
  box.rotation.y += 0.01;
  renderer.render(scene, camera);
});
```

## 5. CubeCamera（环境反射）

渲染 6 个方向到立方体贴图，用于**真实反射**（镜子、金属球、车漆）。

```js
const cubeRT = new THREE.WebGLCubeRenderTarget(256, {
  generateMipmaps: true,
  minFilter: THREE.LinearMipmapLinearFilter
});
const cubeCamera = new THREE.CubeCamera(0.1, 1000, cubeRT);
scene.add(cubeCamera);

// 把球体材质设为反射环境
const sphere = new THREE.Mesh(
  new THREE.SphereGeometry(1, 32, 32),
  new THREE.MeshStandardMaterial({
    envMap: cubeRT.texture,
    metalness: 1,
    roughness: 0
  })
);
scene.add(sphere);

// 每帧（或按需）更新环境贴图
function animate() {
  sphere.visible = false;      // 避免把自己拍进去
  cubeCamera.update(renderer, scene);
  sphere.visible = true;
  renderer.render(scene, camera);
}
```

## 7. 视锥体裁剪（Frustum Culling）

Three.js 默认剔除视锥外的物体。自定义判断：

```js
const frustum = new THREE.Frustum();
const mat = new THREE.Matrix4().multiplyMatrices(
  camera.projectionMatrix, camera.matrixWorldInverse
);
frustum.setFromProjectionMatrix(mat);
console.log(frustum.containsPoint(mesh.position));  // true/false
```

也可关闭单体裁剪（如大范围粒子）：`mesh.frustumCulled = false;`

## 8. 一句话总结

> 右手系 +Y 上、默认看 -Z；`PerspectiveCamera(fov, aspect, near, far)` 近大远小，`OrthographicCamera` 无变形；改参数后必须 `updateProjectionMatrix()`。`CubeCamera` 做实时反射，`project()` 做世界→屏幕。
