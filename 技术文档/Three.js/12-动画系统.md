# 12. 动画系统

> 来源可信度：**官方 API 名录确认 + 标准实践**（基于 threejs.org `Animation/` 分类：AnimationMixer / AnimationClip / AnimationAction / KeyframeTrack / PropertyBinding；API 名录经官网抓取确认）
> 关联：`06-场景图与Object3D变换.md`、`17-模型加载与glTF生态.md`

## 1. 三种动画层次

| 层次 | 适用 | 实现 |
|------|------|------|
| 手动逐帧 | 简单旋转/移动 | 渲染循环里改属性 |
| 补间（Tween） | 属性平滑过渡 | 手写 lerp 或第三方库 |
| 骨骼/关键帧 | 模型自带动画 | `AnimationMixer` |

## 2. 渲染循环与时间

```js
const clock = new THREE.Clock();

renderer.setAnimationLoop(() => {
  const dt = clock.getDelta();        // 距上一帧秒数
  const t  = clock.getElapsedTime();  // 总时长

  mesh.rotation.y += dt * 0.5;        // ★ 用 dt 保证帧率无关
  mesh.position.y = Math.sin(t) * 2;  // 用 t 做周期运动

  renderer.render(scene, camera);
});
```

> **务必用 delta time**：直接 `rotation.y += 0.01` 在 144Hz 屏上会比 60Hz 快 2.4 倍。

## 3. 补间动画（自己实现）

```js
// 线性插值
function lerp(a, b, t) { return a + (b - a) * t; }

// 缓动函数
const easeOutCubic = t => 1 - Math.pow(1 - t, 3);
const easeInOutQuad = t => t < 0.5 ? 2 * t * t : 1 - Math.pow(-2 * t + 2, 2) / 2;

// 简单补间器
function tweenTo(obj, prop, from, to, duration, easing = easeOutCubic) {
  return new Promise(resolve => {
    const start = performance.now();
    function step(now) {
      const p = Math.min((now - start) / duration, 1);
      obj[prop] = lerp(from, to, easing(p));
      if (p < 1) requestAnimationFrame(step); else resolve();
    }
    requestAnimationFrame(step);
  });
}

// 用法
await tweenTo(mesh.position, 'y', 0, 5, 1000);
```

Three.js 内置 `MathUtils` 也有：

```js
THREE.MathUtils.lerp(a, b, t);
THREE.MathUtils.damp(x, y, lambda, dt);   // 帧率无关的平滑阻尼，推荐！
THREE.MathUtils.smoothstep(x, min, max);
THREE.MathUtils.clamp(v, min, max);
```

**`damp` 是相机跟随的标配**：

```js
camera.position.x = THREE.MathUtils.damp(camera.position.x, targetX, 4, dt);
```

## 4. 关键帧动画（KeyframeTrack）

手动创建动画片段：

```js
// 位置关键帧：时间数组 + 值数组
const positionTrack = new THREE.VectorKeyframeTrack(
  '.position',
  [0, 1, 2],                       // 时间（秒）
  [0,0,0,  0,3,0,  0,0,0]          // 每时刻 xyz
);

// 缩放
const scaleTrack = new THREE.VectorKeyframeTrack(
  '.scale', [0, 1], [1,1,1, 2,2,2]
);

// 颜色
const colorTrack = new THREE.ColorKeyframeTrack(
  '.material.color', [0, 1], [1,0,0, 0,0,1]
);

const clip = new THREE.AnimationClip('bounce', 2, [positionTrack, scaleTrack]);
const mixer = new THREE.AnimationMixer(mesh);
const action = mixer.clipAction(clip);
action.play();

// 每帧更新
function animate() {
  mixer.update(clock.getDelta());
  renderer.render(scene, camera);
}
```

**轨道类型**：`VectorKeyframeTrack`、`QuaternionKeyframeTrack`、`NumberKeyframeTrack`、`ColorKeyframeTrack`、`BooleanKeyframeTrack`、`StringKeyframeTrack`。

## 5. AnimationAction 控制

```js
action.play();
action.stop();
action.pause();

action.setLoop(THREE.LoopRepeat, 3);   // 重复 3 次
action.setLoop(THREE.LoopPingPong);    // 往复
action.setLoop(THREE.LoopOnce);        // 单次
action.clampWhenFinished = true;       // 播完停在最后一帧

action.timeScale = 0.5;                // 慢放
action.setEffectiveWeight(0.5);        // 权重（混合用）
action.fadeIn(0.5);                    // 淡入
action.fadeOut(0.5);                   // 淡出
action.crossFadeTo(otherAction, 0.5);  // 交叉淡入淡出
```

## 6. 完整例子：glTF 模型动画 + 状态切换

```js
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

let mixer, actions = {}, current;

new GLTFLoader().load('/models/character.glb', (gltf) => {
  const model = gltf.scene;
  scene.add(model);

  mixer = new THREE.AnimationMixer(model);

  // 假设模型有 idle / walk / run 三个动画
  gltf.animations.forEach((clip) => {
    actions[clip.name] = mixer.clipAction(clip);
  });

  current = actions['idle'];
  current.play();
});

// 切换动画（带过渡）
function playAction(name, duration = 0.3) {
  const next = actions[name];
  if (!next || next === current) return;
  next.reset().setEffectiveWeight(1).play();
  current.crossFadeTo(next, duration, true);
  current = next;
}

// 事件
addEventListener('keydown', (e) => {
  if (e.code === 'KeyW') playAction('walk');
  if (e.code === 'ShiftLeft') playAction('run');
});
addEventListener('keyup', () => playAction('idle'));

// 渲染循环
renderer.setAnimationLoop(() => {
  mixer?.update(clock.getDelta());
  renderer.render(scene, camera);
});
```

## 7. 监听动画事件

```js
mixer.addEventListener('finished', (e) => {
  console.log('动画播完:', e.action.getClip().name);
  playAction('idle');
});

mixer.addEventListener('loop', (e) => {
  console.log('循环了一次:', e.action.getClip().name);
});
```

## 8. 变形目标（Morph Targets）

用于表情、形变动画：

```js
// 几何体需有 morphAttributes
mesh.morphTargetInfluences[0] = 0.5;   // 0~1 控制形变权重
mesh.morphTargetDictionary             // 名字 → 索引 映射

// 平滑过渡
mesh.morphTargetInfluences[i] = THREE.MathUtils.damp(
  mesh.morphTargetInfluences[i], target, 5, dt
);
```

## 9. 一句话总结

> 动画三层：逐帧用 **delta time** 保证帧率无关；补间用 `MathUtils.lerp`/`damp`；模型动画用 `AnimationMixer` + `clipAction`，靠 `crossFadeTo` 做状态过渡、`setLoop` 控循环。变形动画用 `morphTargetInfluences`。
