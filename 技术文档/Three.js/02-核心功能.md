# 02 核心功能：光照 · 纹理 · 模型 · 交互

第二到第五周，让场景“有光、有质感、能加载真实模型、能点击”。

## 光照系统

| 光源 | 说明 | 要点 |
| --- | --- | --- |
| `AmbientLight` | 环境光，均匀照亮全部 | 无方向、不产生阴影；仅用于提亮暗部 |
| `DirectionalLight` | 平行光（如太阳） | 最常用主光；可投影，需设 `shadow.camera` |
| `PointLight` | 点光源，向四周发散 | 有距离衰减 `distance / decay` |
| `SpotLight` | 聚光灯，带锥角 | 可设 `angle / penumbra`，性能开销较高 |

**阴影三处开关**：渲染器 `shadowMap.enabled = true` + 光源 `castShadow = true` + 物体 `castShadow / receiveShadow = true`，三者同时开启才生效。

```js
renderer.shadowMap.enabled = true;
const dir = new THREE.DirectionalLight(0xffffff, 0.8);
dir.position.set(5, 10, 7);
dir.castShadow = true;
scene.add(dir);
```

## 材质与纹理

- **常用材质**：`MeshBasicMaterial`（不受光）、`MeshPhongMaterial`（高光塑料）、`MeshStandardMaterial`（PBR 物理正确，推荐）、`MeshPhysicalMaterial`（透射/清漆等高级 PBR）。
- **纹理贴图**：颜色贴图 `map`、法线 `normalMap`、凹凸 `bumpMap`、高光 `specularMap`、粗糙度/金属度、环境贴图（HDR）。用 `TextureLoader` 加载，注意 UV 映射。

```js
const loader = new THREE.TextureLoader();
const tex = loader.load('diffuse.jpg');
material.map = tex;
```

## 模型加载

- **glTF / GLB 是 Web 3D 推荐格式**。
- 配合 `DRACOLoader`（几何压缩）、`KTX2Loader`（Basis 纹理压缩）减小体积。
- `OBJLoader / FBXLoader` 用于其他来源。

```js
const draco = new THREE.DRACOLoader();
draco.setDecoderPath('/draco/');
const loader = new THREE.GLTFLoader();
loader.setDRACOLoader(draco);
loader.load('model.glb', (gltf) => scene.add(gltf.scene));
```

## 交互：射线检测

- `Raycaster` 从相机经鼠标发射射线，实现点击拾取（picking）。
- 结合 `OrbitControls`（设 `enableDamping` 更顺滑）做旋转/缩放/平移。

```js
const controls = new THREE.OrbitControls(camera, renderer.domElement);
controls.enableDamping = true; // 拖动有惯性，更流畅

const raycaster = new THREE.Raycaster();
const mouse = new THREE.Vector2();
window.addEventListener('click', (e) => {
  mouse.x = (e.clientX / window.innerWidth) * 2 - 1;
  mouse.y = -(e.clientY / window.innerHeight) * 2 + 1;
  raycaster.setFromCamera(mouse, camera);
  const hits = raycaster.intersectObjects(scene.children);
});
```
