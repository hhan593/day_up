📌 为什么学 Three.js

Three.js 是 WebGL 最流行的上层封装库，把“状态机式、难以上手”的底层图形 API 包装成开发者友好的接口，让网页能跑 3D。

它解决什么问题

原生 WebGL 需要手写着色器、管理缓冲区和渲染管线，门槛极高。Three.js 提供 Scene / Camera / Renderer 三件套、丰富的几何体/材质/光照，以及 GLTFLoader、EffectComposer、OrbitControls 等开箱即用能力。

典型应用场景

电商 3D 商品展示、数据可视化大屏、数字孪生、在线 3D 编辑器、虚拟展厅、网页小游戏，以及 VR/AR（WebXR）沉浸式体验。某品牌 3D 展示使转化率提升 45%、退货率降低 30%。

技术定位正在升级

从 r171（2025）起 WebGPURenderer 进入生产可用，r182 起作为推荐渲染器；TSL（Three Shading Language）让同一份着色器同时编译到 WebGL 与 WebGPU。Three.js 正从“3D 库”演变为“轻量级 3D 引擎”。

前置知识

需要扎实的 JavaScript（ES Module）、基础 HTML/CSS，以及对“线性代数/坐标变换”的直觉更好。图形学基础非必须，但理解渲染管线（顶点→光栅化→片元）会事半功倍。

01 基础入门：三大对象与场景图

一切 Three.js 程序都围绕“场景 + 相机 + 渲染器”展开，理解它们是第一周的核心。

Scene 场景 容器

所有 3D 对象的“舞台”，采用场景图（Scene Graph）树状结构管理。可添加 fog 雾效、背景色/贴图。

Camera 相机 视角

PerspectiveCamera（透视，近大远小）最常用；OrthographicCamera（正交，无透视，适合 2.5D / 地图）。需设置 aspect 并在 resize 时 updateProjectionMatrix()。

Renderer 渲染器 引擎

WebGLRenderer({antialias:true}) 是默认后端；新项目可直接用 WebGPURenderer（自动 fallback WebGL2）。开启 shadowMap.enabled 与设置 pixelRatio。

坐标系 右手系

Three.js 使用右手坐标系：X 向右、Y 向上、Z 向屏幕外。物体默认绕自身原点旋转，注意 pivot 与 group 的使用。

Geometry + Material = Mesh

几何体定义“形状”，材质定义“外观”，二者组合成可渲染的 Mesh。内置几何体：Box / Sphere / Cylinder / Torus / Plane 等。

动画循环 requestAnimationFrame

用 requestAnimationFrame（非 setInterval）驱动逐帧渲染；WebXR 下改用 renderer.setAnimationLoop()。

02 核心功能：光照 · 纹理 · 模型 · 交互

第二到第五周，让场景“有光、有质感、能加载真实模型、能点击”。

💡 光照系统

光源说明要点
AmbientLight环境光，均匀照亮全部无方向、不产生阴影；仅用于提亮暗部
DirectionalLight平行光（如太阳）最常用主光；可投影，需设 shadow.camera
PointLight点光源，向四周发散有距离衰减 distance / decay
SpotLight聚光灯，带锥角可设 angle / penumbra，性能开销较高

阴影：渲染器 shadowMap.enabled=true，光源 castShadow、物体 castShadow/receiveShadow 三处同时开启才生效。

🧱 材质与纹理

常用材质

MeshBasicMaterial（不受光）、MeshPhongMaterial（高光塑料）、MeshStandardMaterial（PBR 物理正确，推荐）、MeshPhysicalMaterial（透射/清漆等高级 PBR）。

纹理贴图

颜色贴图 map、法线 normalMap、凹凸 bumpMap、高光 specularMap、粗糙度/金属度、环境贴图（HDR）。用 TextureLoader 加载，注意 UV 映射。

模型加载

glTF/GLB 是 Web 3D 推荐格式。配合 DRACOLoader（几何压缩）、KTX2Loader（Basis 纹理压缩）减小体积；OBJLoader / FBXLoader 用于其他来源。

交互：射线检测

Raycaster 从相机经鼠标发射射线，实现点击拾取（picking）；结合 OrbitControls（设 enableDamping 更顺滑）做旋转/缩放/平移。

03 进阶实战：着色器 · 后期 · 粒子 · 性能

第六周起进入“自定义外观与大规模场景”阶段，是区分初级与中级开发者的分水岭。

GLSL 着色器 ⭐⭐⭐⭐

顶点着色器控制“位置变换”，片元着色器控制“像素颜色”。通过 ShaderMaterial 注入自定义效果；噪声函数、光照模型、后处理滤镜均在此实现。推荐《The Book of Shaders》。

后期处理 EffectComposer

用 EffectComposer 串联 RenderPass + 效果 Pass：UnrealBloomPass（辉光）、SSAO（环境光遮蔽）、景深、运动模糊、色调映射。

粒子系统

Points + PointsMaterial 实现星空、雪花、火焰；大规模粒子优先用 InstancedMesh 或 GPU 计算着色器。

性能优化 ⭐⭐⭐⭐

减少 draw call：InstancedMesh 实例化、BufferGeometryUtils.mergeGeometries 合批；LOD 分级显示；纹理/KTX2 压缩；谨慎使用动态数据。

动画系统

AnimationMixer 播放骨骼/关键帧 AnimationClip（模型自带动画）；UI 补间用 Tween.js 或 GSAP。

内存管理

切换场景/销毁对象务必 geometry.dispose()、material.dispose()、texture.dispose()、renderer.dispose()，否则内存泄漏导致卡顿。

04 高级前沿：WebGPU · TSL · WebXR · 工程化

面向追求“生产级 / 沉浸式 / 现代工作流”的开发者，也是 2025–2026 的技术重心。

WebGPURenderer 推荐渲染器

r171 起生产可用、r182 起推荐。零配置导入 import {WebGPURenderer} from 'three/webgpu'，不支持时自动 fallback WebGL2。曼德布洛特测试相较 WebGL2 帧率提升约 320%。

TSL 着色语言 跨后端

Three Shading Language 用节点图描述着色逻辑，一次编写同时编译到 GLSL 与 WGSL。配合 NodeMaterial，是未来自定义着色器的首选方式。

WebXR（VR/AR）

用 VRButton 与 renderer.xr.enabled=true 接入头显/手机 AR；同一份场景可同时适配桌面与 XR 设备。推荐 Nick Lever 的 WebXR 课程。

物理引擎

cannon-es（轻量，推荐）、Ammo.js（功能全）为刚体/碰撞提供真实物理；与 InstancedMesh 结合做大规模模拟。

React Three Fiber 现代工作流

熟悉 React 的开发者用 R3F 声明式组织 3D 场景，配合 Drei 复用组件库，极大提升工程化效率。

调试与可视化

lil-gui 实时调参、Stats 看 FPS、Three.js Editor 可视化搭建、Blender 建模导出 glTF；Chrome DevTools 分析内存。

⚠️ 常见坑与调试技巧

关键调试组合：lil-gui 实时改参数（位置/颜色）、Stats 监测 FPS/内存；遇到瓶颈可研读源码 src/renderers/WebGLRenderer.js。

内存泄漏

切换场景必须 dispose 几何体、材质、纹理与 renderer；scene.traverse 遍历释放 isMesh 资源。

跨设备适配

监听 resize：更新 camera.aspect + updateProjectionMatrix()、renderer.setSize；移动端处理触摸与 devicePixelRatio。

模型加载慢

用 DRACO 几何压缩 + KTX2/Basis 纹理压缩；低精度渐进加载、按需懒加载 3D 资源。

兼容 / 降级

检测设备能力，提供 WebGL2 fallback；WebGPURenderer 已内置自动回退，新项目可直接启用。
