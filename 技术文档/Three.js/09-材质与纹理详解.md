# 09. 材质与纹理详解

> 来源可信度：**官方 API 名录确认 + 标准实践**（基于 threejs.org `Materials/` 分类全部材质、`Textures/` 分类；API 名录经官网抓取确认）
> 关联：`08-几何体与BufferGeometry.md`、`10-光照与阴影.md`

## 1. 材质总览

| 材质 | 受光照 | 特点 | 适用场景 |
|------|--------|------|---------|
| `MeshBasicMaterial` | ❌ | 纯色/贴图，最快 | UI、线框、天空盒 |
| `MeshLambertMaterial` | ✅ 漫反射 | 便宜，无高光 | 低配设备、卡通 |
| `MeshPhongMaterial` | ✅ 高光 | 有 `shininess`/`specular` | 塑料、老项目 |
| `MeshStandardMaterial` | ✅ PBR | **推荐默认**，金属/粗糙度 | 真实感场景 |
| `MeshPhysicalMaterial` | ✅ 高级 PBR | 透射/清漆/虹彩/次表面 | 玻璃、车漆、玉石 |
| `MeshToonMaterial` | ✅ 阶梯 | 卡通分级着色 | 二次元风格 |
| `MeshNormalMaterial` | ❌ | 显示法线颜色（调试） | 调试法线 |
| `MeshDepthMaterial` | ❌ | 显示深度 | 深度图、阴影 |
| `MeshMatcapMaterial` | ❌ | 预烘焙光照，极快 | 移动端、雕像 |
| `ShaderMaterial` | 自定义 | 手写 GLSL（见 14） | 特效 |
| `SpriteMaterial` | ❌ | 永远面向相机的面片 | 标签、粒子 |
| `PointsMaterial` | ❌ | 点云 | 粒子系统 |

## 2. MeshStandardMaterial（PBR 主力）

```js
const mat = new THREE.MeshStandardMaterial({
  color: 0x445566,        // 基础色（会被贴图相乘）
  roughness: 0.5,         // 0=镜面 1=完全粗糙
  metalness: 0.8,         // 0=非金属（塑料/木） 1=金属
  map: colorTex,          // 颜色贴图
  normalMap: normalTex,   // 法线贴图（增加细节不增顶点）
  roughnessMap: roughTex, // 粗糙度贴图（灰度）
  metalnessMap: metalTex, // 金属度贴图
  aoMap: aoTex,           // 环境光遮蔽（需 uv2/uv1）
  emissive: 0xff0000,     // 自发光颜色
  emissiveIntensity: 1,
  envMap: envTexture,     // 环境反射贴图
  envMapIntensity: 1,
  transparent: true,
  opacity: 0.5,
  side: THREE.DoubleSide, // FrontSide(默认)/BackSide/DoubleSide
});
```

**metalness / roughness 直觉**：

- 金属（`metalness=1`）：颜色决定反射色，`roughness` 控制模糊程度。
- 非金属（`metalness=0`）：`color` 就是漫反射色。
- 常见错误：把金属设成 `metalness=1` 但没给 `envMap`，结果是**全黑**——金属没有漫反射，只反射环境。

## 3. 纹理加载

```js
const loader = new THREE.TextureLoader();
const tex = loader.load(
  '/textures/brick.jpg',
  () => console.log('loaded'),
  undefined,
  (err) => console.error(err)
);

// 重复平铺
tex.wrapS = tex.wrapT = THREE.RepeatWrapping;
tex.repeat.set(4, 4);

// 偏移与旋转
tex.offset.set(0.5, 0);
tex.rotation = Math.PI / 4;
tex.center.set(0.5, 0.5);

// 色彩空间：颜色贴图必须是 sRGB！
tex.colorSpace = THREE.SRGBColorSpace;
// 数据贴图（法线/粗糙度/AO）保持默认 NoColorSpace/LinearSRGBColorSpace
```

> ⚠️ 最常见坑：颜色贴图忘记设 `colorSpace = SRGBColorSpace`，画面会**发灰/发白**。法线/粗糙度贴图**不要**设 sRGB。

## 4. 完整例子：贴图地球 + 法线细节

```js
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 100);
camera.position.z = 4;

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;

const loader = new THREE.TextureLoader();

// 颜色贴图 → 必须 sRGB
const colorMap = loader.load('/earth/color.jpg');
colorMap.colorSpace = THREE.SRGBColorSpace;

// 法线 / 粗糙度 → 线性（不设 sRGB）
const normalMap = loader.load('/earth/normal.jpg');
const roughMap = loader.load('/earth/roughness.jpg');

const earth = new THREE.Mesh(
  new THREE.SphereGeometry(1, 64, 64),
  new THREE.MeshStandardMaterial({
    map: colorMap,
    normalMap: normalMap,
    roughnessMap: roughMap,
    metalness: 0.1,
    roughness: 1.0,
  })
);
scene.add(earth);

scene.add(new THREE.AmbientLight(0xffffff, 0.3));
const sun = new THREE.DirectionalLight(0xffffff, 2);
sun.position.set(5, 3, 5);
scene.add(sun);

renderer.setAnimationLoop(() => {
  earth.rotation.y += 0.002;
  controls.update();
  renderer.render(scene, camera);
});
```

## 5. 环境贴图（HDR / PMREM）

让 PBR 材质"活起来"的关键。

```js
import { RGBELoader } from 'three/addons/loaders/RGBELoader.js';

const pmrem = new THREE.PMREMGenerator(renderer);
pmrem.compileEquirectangularShader();

new RGBELoader().load('/hdr/studio.hdr', (tex) => {
  const envMap = pmrem.fromEquirectangular(tex).texture;
  scene.environment = envMap;   // 全局环境光（推荐）
  // scene.background = envMap; // 也可作背景
  tex.dispose();
  pmrem.dispose();
});
```

设 `scene.environment` 后，所有 `MeshStandardMaterial` 自动获得反射，**无需逐个设 envMap**。

无需 HDR 文件时，可用内置环境：

```js
import { RoomEnvironment } from 'three/addons/environments/RoomEnvironment.js';
const env = new THREE.PMREMGenerator(renderer).fromScene(new RoomEnvironment(), 0.04).texture;
scene.environment = env;
```

## 6. 透明与混合

```js
mat.transparent = true;
mat.opacity = 0.6;
mat.depthWrite = false;        // 透明物体常见问题：互相遮挡，关掉深度写入
mat.alphaMap = alphaTex;       // 用贴图灰度控制透明
mat.blending = THREE.AdditiveBlending;  // 叠加发光（粒子/光效）
mat.alphaTest = 0.5;           // 硬边裁剪（树叶/栅栏），比 transparent 更稳
```

**排序**：Three.js 按距离排序透明物体，仍可能出错。树叶这类用 `alphaTest` 而非 `transparent` 更可靠。

## 7. 常用贴图通道

| 通道 | 作用 | 颜色空间 |
|------|------|---------|
| `map` | 基础色 | **sRGB** |
| `emissiveMap` | 自发光 | sRGB |
| `normalMap` | 法线扰动 | 线性 |
| `roughnessMap` | 粗糙度 | 线性 |
| `metalnessMap` | 金属度 | 线性 |
| `aoMap` | 遮蔽（需第二套 UV） | 线性 |
| `displacementMap` | 顶点位移（需高分段的几何体） | 线性 |
| `alphaMap` | 透明度 | 线性 |

## 8. 一句话总结

> 默认用 `MeshStandardMaterial`，靠 `roughness`/`metalness` + 环境贴图（`scene.environment`）出真实感；颜色贴图设 `SRGBColorSpace`、数据贴图不设；透明优先 `alphaTest`，发光用 `AdditiveBlending`。金属必须配 `envMap` 否则发黑。
