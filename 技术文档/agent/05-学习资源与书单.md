## 一、推荐书籍

### 入门级

| 书名 | 作者 | 特点 | 适合 |
|---|---|---|---|
| **《大模型应用开发 动手做AI Agent》** | 黄佳（咖哥）| 中文、偏实战、手把手代码 | 入门代码小白 |
| **《Hands-On Large Language Models》** | Jay Alammar & Maarten Grootendorst | O'Reilly、可视化讲解、Jupyter Notebook | 英文读者、视觉学习者 |
| **《Building LLM Powered Applications》** | Valentina Alto | 系统介绍 LLM 应用开发 | 想系统入门的开发者 |

### 进阶级

| 书名 | 作者 | 特点 |
|---|---|---|
| **《LLM Engineer's Handbook》** | Paul Iusztin & Maxime Labonne | 工程实践导向，涵盖 RAG、微调、部署 |
| **《Designing Large Language Model Applications》** | 待出版 | O'Reilly，系统架构设计 |
| **《Prompt Engineering for LLMs》** | John Berryman & Albert Ziegler | 提示词工程深度解析 |

### 论文必读

| 论文 | 内容 | 重要性 |

| **Toolformer: Language Models Can Teach Themselves to Use Tools** | 工具调用原论文 | ⭐⭐⭐⭐⭐ |
| **LLM Powered Autonomous Agents** (Lilian Weng) | Agent 架构定义性文章 | ⭐⭐⭐⭐⭐ |
| **Chain-of-Thought Prompting Elicits Reasoning** | CoT 原论文 | ⭐⭐⭐⭐ |
| **Tree of Thoughts** | ToT 推理框架 | ⭐⭐⭐⭐ |
| **Reflexion: Language Agents with Verbal Reinforcement Learning** | 反思框架 | ⭐⭐⭐⭐ |
| **RAGAS: Automated Evaluation of Retrieval Augmented Generation** | RAG 评估框架 | ⭐⭐⭐⭐ |
| **GraphRAG** (微软) | 图谱增强 RAG | ⭐⭐⭐ |

## 六、系统学习计划（12周）

### 第1-2周：地基
- [ ] 完成《AI Agents for Beginners》前5章
- [ ] 学会调用 OpenAI / Claude API
- [ ] 实现第一个带工具调用的简单 Agent
- [ ] 学习 DeepLearning.AI：LangChain for LLM Application Development

### 第3-4周：LangChain 与 RAG
- [ ] LangChain 文档：LCEL、Chain、Agent、Memory
- [ ] 构建一个本地 RAG 系统（Chroma + LlamaIndex）
- [ ] 学习 DeepLearning.AI：Building Agentic RAG with LlamaIndex

### 第5-6周：LangGraph 进阶
- [ ] LangGraph 官方教程：StateGraph、条件路由
- [ ] 实现带检查点的可恢复 Agent
- [ ] 学习 DeepLearning.AI：AI Agents in LangGraph

### 第7-8周：多 Agent 系统
- [ ] CrewAI 官方教程：角色、任务、团队
- [ ] 实现研究+写作的两 Agent 流水线
- [ ] 学习 DeepLearning.AI：Multi AI Agent Systems with CrewAI

### 第9-10周：MCP 协议与工程化
- [ ] MCP 官方文档，开发一个自定义 MCP Server
- [ ] 接入 Cursor 或 Claude Desktop 测试
- [ ] 学习 LangSmith 可观测性，为自己的项目加入 Trace

### 第11-12周：评估与生产
- [ ] 为已有项目构建评估数据集
- [ ] 实现 LLM Judge 评估
- [ ] 用 FastAPI 封装 Agent，Docker 部署

## 七、面试高频问题

### 概念类
1. Agent 和普通 LLM 调用有什么区别？
2. RAG 和微调（Fine-tuning）各自适合什么场景？
3. LangGraph 和 LangChain 的关系是什么？
4. MCP 协议解决了什么问题？
5. ReAct 和 ReWOO 的区别是什么？

### 设计类
1. 如何设计一个多 Agent 的客服系统？
2. RAG 系统的检索质量不好，有哪些优化手段？
3. 如何控制 Agent 的成本？
4. Agent 在生产环境中如何保证安全性？
5. 如何评估一个 Agent 的质量？

### 代码类
1. 实现一个带记忆的对话 Agent
2. 用 LangGraph 实现一个带人工审核的工作流
3. 开发一个简单的 MCP Server
4. 实现一个 RAG 系统并评估其准确性
5. 实现工具调用的重试机制
