## 一、什么是 AI Agent？

AI Agent（智能体）是以大语言模型（LLM）为核心大脑，结合感知、规划、记忆与工具调用能力，能够**自主完成复杂多步骤任务**的智能系统。

### 核心公式

```
Agent = LLM + Planning（规划）+ Memory（记忆）+ Tools（工具）+ Action（行动）
```

| 组件 | 作用 |
|---|---|
| LLM | 理解意图、推理决策、生成输出 |
| Planning | 将复杂目标拆解为可执行子任务 |
| Memory | 短期上下文 + 长期知识存储 |
| Tools | 扩展 Agent 能力边界（API、代码执行、搜索等）|
| Action | 执行结果、与环境交互 |

### Agent 与普通 LLM 应用的区别

| 维度 | 普通 LLM 应用 | AI Agent |
|---|---|---|
| 执行模式 | 单次问答 | 多步骤循环执行 |
| 工具使用 | 无 / 有限 | 动态调用多种工具 |
| 自主性 | 被动响应 | 主动规划、自我修正 |
| 记忆 | 单次上下文 | 跨轮次持久记忆 |
| 典型产品 | ChatGPT 对话 | Cursor、Deep Research |

## 二、2025 年 Agent 技术六大趋势

### 1. 推理模型崛起（Planning 能力质变）
- OpenAI o 系列、DeepSeek R 系列：Chain-of-Thought 规模化落地
- Claude 3.5/4：代码执行与自我反省能力领先
- Agent 具备了"思考再行动"的能力

### 2. 真正成熟的 Agent 产品出现
- 2024：Cursor（代码 Agent）
- 2025：Deep Research（研究 Agent）
- 从"Demo 好看"到"生产可用"

### 3. 多智能体协作（Multi-Agent System）成主流
- 单 Agent 能力有限 → 多 Agent 各司其职
- Agent 间通过自然语言通信，接近"类人团队"
- 代表框架：AutoGen、CrewAI、LangGraph

### 4. 上下文工程（Context Engineering）兴起
- 提示词工程的升级版
- 系统性设计、管理、优化模型的上下文信息
- 关键要素：动态上下文装配、记忆压缩、信息优先级

### 5. 协议标准化（MCP / A2A / AG-UI）
- MCP（Anthropic）：Agent ↔ 工具的标准接口
- A2A（Google）：Agent ↔ Agent 的通信协议
- AG-UI（CopilotKit）：Agent ↔ 前端界面的交互规范

### 6. 独立 Agent 厂商窗口期
- 模型迭代放缓 → 应用层竞争加剧
- 垂直领域 Agent（法律、医疗、金融、代码）崛起

## 四、分层技术栈推荐

| 层级 | 职责 | 推荐方案 |
|---|---|---|
| **数据层** | 知识检索、RAG | LlamaIndex + 向量数据库（Chroma/Pinecone/Weaviate）|
| **协作层** | 多 Agent 任务分工 | CrewAI（结构化）/ AutoGen（对话式）|
| **编排层** | 工作流状态管理 | LangGraph（复杂流程）/ Swarm（简单多 Agent）|
| **组件层** | LLM 调用、工具集成 | LangChain + LangSmith |
| **可观测层** | 监控、评估、调试 | LangSmith / Langfuse |
| **协议层** | 标准化工具/Agent 通信 | MCP + A2A |

## 五、推荐学习路线

### 阶段一：地基（2-4 周）

```
Python 基础 → LLM API 调用 → Prompt Engineering
      ↓
Function Calling 基础 → 简单 Agent 实现
```

**核心技能：**
- Python 异步编程（async/await）
- OpenAI / Anthropic API 使用
- Prompt 设计：System Prompt、Few-shot、CoT
- Function Calling 实现基础工具调用

**推荐资源：**
- 微软 [Generative AI for Beginners](https://github.com/microsoft/generative-ai-for-beginners)（75k Stars）

---

### 阶段二：核心框架（4-6 周）

```
LangChain 基础 → Chain / Agent / Memory / Tools
      ↓
LangGraph → 状态图、条件路由、人工介入
      ↓
RAG 系统 → LlamaIndex + 向量数据库
```

**核心技能：**
- LangChain：Chain、Agent、Memory、Retriever
- LangGraph：StateGraph、节点/边/条件、检查点
- RAG：文档加载、分块、嵌入、检索、重排序
- 向量数据库：Chroma（本地）/ Pinecone（云端）

**推荐资源：**
- 微软 [AI Agents for Beginners](https://github.com/microsoft/ai-agents-for-beginners)
- [LLM Engineering 8周训练营](https://github.com/ed-donner/llm_engineering)

---

### 阶段三：多智能体与协议（3-4 周）

```
CrewAI / AutoGen 多 Agent 系统
      ↓
MCP 协议开发（Server / Client）
      ↓
A2A 协议（跨 Agent 通信）
```

**核心技能：**
- CrewAI：角色定义、任务分配、流程编排
- AutoGen：对话驱动的 Agent 协作、Human-in-the-loop
- MCP：自定义 MCP Server 开发
- A2A：Agent Card 定义、跨框架 Agent 通信

---

### 阶段四：工程化落地（持续）

```
LangSmith 可观测性 → Trace 分析 → 评估体系建立
      ↓
Prompt 版本管理 → A/B 测试 → 性能优化
      ↓
生产部署：Docker / K8s / 云平台
```

**核心技能：**
- LangSmith：Trace、评估、Prompt Hub
- 评估指标：准确率、工具选择精度、延迟、成本
- 部署：FastAPI + Docker + 监控告警

---

### 阶段五：进阶算法（深入提升）

| 方向 | 关键技术 |
|---|---|
| 推理框架 | ReAct、ReWOO、Tree of Thoughts、Reflexion |
| RAG 优化 | GraphRAG、HyDE、Self-RAG、Agentic RAG |
| 微调 | SFT、LoRA、QLoRA（微调专属 Agent 模型）|
| 强化学习 | PPO、DPO、GRPO（对齐与奖励优化）|
| 多 Agent 研究 | MetaGPT、AutoGPT、Stanford AI Town |

## 六、学习时间规划参考

| 阶段 | 建议时长 | 里程碑 |
|---|---|---|
| 地基 | 2-4 周 | 能独立实现一个带工具调用的简单 Agent |
| 核心框架 | 4-6 周 | 能用 LangGraph 搭建 RAG + Agent 应用 |
| 多 Agent | 3-4 周 | 能用 CrewAI/AutoGen 实现多 Agent 协作流水线 |
| 工程化 | 持续 | 生产级 Agent 上线，具备监控和评估能力 |
| 进阶算法 | 按需 | 论文复现、模型微调、强化学习 |
