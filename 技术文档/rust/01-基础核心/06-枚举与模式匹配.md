# 06 · 枚举与模式匹配（Enum & Match）

> 体系定位：枚举是 Rust 表达"有限可能"的强大工具，配合 `match` 做到**穷尽检查**——漏掉一种情况编译不过。
> 深入：`补充知识点/04-枚举与模式匹配.md`、`16-Option 与 Result 深度解析.md`。

---

## 1. 定义枚举

```rust
enum IpAddr {
    V4(u8, u8, u8, u8),     // 可携带不同类型/数量的数据
    V6(String),
}

let home = IpAddr::V4(127, 0, 0, 1);
let loopback = IpAddr::V6(String::from("::1"));
```

枚举变体可携带：无名元组字段、具名结构体字段、甚至无数据。比 C 的枚举强得多（C 枚举只是整数常量）。

---

## 2. 用 match 穷尽处理

```rust
fn describe(ip: &IpAddr) -> String {
    match ip {
        IpAddr::V4(a, b, c, d) => format!("IPv4 {a}.{b}.{c}.{d}"),
        IpAddr::V6(s) => format!("IPv6 {s}"),
        // 编译器要求覆盖所有变体，否则报错
    }
}
```

`match` 必须是**穷尽的（exhaustive）**：少写一个分支编译失败。这是 Rust 防止"忘了处理新情况"的核心机制（重构时给枚举加变体，所有 `match` 处都会报错提醒你）。

---

## 3. 通配与占位

```rust
let n = 3;
match n {
    1 => println!("one"),
    2 => println!("two"),
    other => println!("other: {other}"),  // 绑定到变量
    // _ => (),                            // 或用 _ 忽略
}
```

`_` 是通配但**不绑定**；`other` / `x` 会绑定值，可在分支内使用。

---

## 4. if let：只关心一种情况

```rust
if let IpAddr::V4(a, b, _, _) = home {
    println!("it's v4: {a}.{b}");
} else {
    println!("not v4");
}
```

当只匹配一种变体时，`if let` 比 `match` 简洁。还有 `while let`（循环到不匹配为止）。

---

## 5. 最常用的两个枚举

Rust 标准库两个枚举贯穿始终，务必熟记：

```rust
// Option<T>：可能有值，也可能没有（取代 null）
enum Option<T> { Some(T), None }

// Result<T, E>：可能成功，也可能失败
enum Result<T, E> { Ok(T), Err(E) }
```

详见 [10-错误处理Result与Option](./10-错误处理Result与Option.md) 与 `补充知识点/16-Option 与 Result 深度解析.md`。
