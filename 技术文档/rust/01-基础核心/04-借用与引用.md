# 04 · 借用与引用（References & Borrowing）

> 体系定位：解决"移动后原变量失效"带来的不便——**不拿走所有权，只借来用**。这是所有权系统的另一半。
> 详细深挖：`补充知识点/05-借用与引用.md`、`07-泛型Trait与生命周期知识手册.md`（生命周期）。

---

## 1. 引用：用值但不拥有

```rust
fn main() {
    let s1 = String::from("hello");
    let len = calculate_length(&s1);   // &s1 = 对 s1 的不可变引用（借用）
    println!("'{s1}' 的长度是 {len}"); // ✅ s1 仍然可用
}

fn calculate_length(s: &String) -> usize {  // s 是 &String，不拥有
    s.len()
}                                          // s 离开作用域，不 drop 原数据
```

`&` 创建引用（ borrowing），`&String` 类型是"指向 String 的指针，但不拥有它"。函数结束只释放指针，原 `String` 不受影响。

---

## 2. 不可变引用 vs 可变引用

| | 语法 | 规则 |
|---|---|---|
| 不可变借用 | `&T` | 可同时存在多个 |
| 可变借用 | `&mut T` | **同一时刻只能有 1 个**，且与不可变借用互斥 |

```rust
let mut s = String::from("hello");
let r1 = &mut s;     // ✅ 唯一的可变借用
r1.push_str(" world");
// let r2 = &mut s;  // ❌ 已存在 &mut，不能再借
println!("{r1}");
```

借用检查器在**编译期**强制：

- 任意时刻，要么有 **N 个 `&T`**（只读，可并发），要么有 **1 个 `&mut T`**（独占写）。
- 引用必须始终有效（不能指向已 drop 的数据）——这从源头消灭了**悬垂指针（dangling pointer）**。

```rust
let r;
{
    let x = 5;
    r = &x;     // ❌ x 即将销毁，r 会悬垂 → 编译拒绝
}
```

---

## 3. 为什么这套规则重要

这正是 Rust 敢宣称 **"fearless concurrency"（无畏并发）** 的根基：数据竞争（data race）本质就是"多线程同时读写同一数据且无同步"，而借用规则在编译期就禁止了它。多线程代码里只要能通过编译，就不可能有数据竞争（见 `17-concurrency-parallel.md`）。

---

## 4. 解引用与自动解引用

`*` 解引用取到指向的值：

```rust
let x = 5;
let y = &x;
assert_eq!(x, *y);   // *y = 5
```

方法调用时 Rust 会自动 `&` / `&mut` / `*` 多层，所以 `s.len()` 对 `&String` 也能直接调（无需 `(*s).len()`）。

---

## 5. 切片（Slice）：不持有所有权的视图

```rust
let s = String::from("hello world");
let hello = &s[0..5];        // &str，指向 s 的一段，不拥有
let arr = [1, 2, 3, 4];
let mid = &arr[1..3];        // &[i32]
```

字符串切片 `&str` 是 Rust 字符串字面量的类型，也是函数接收字符串参数的**推荐签名**：

```rust
fn first_word(s: &str) -> &str { ... }   // 接受 &String 和 &str 都能自动转
```
