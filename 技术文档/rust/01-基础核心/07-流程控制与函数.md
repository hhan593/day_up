# 07 · 流程控制与函数

> 体系定位：控制流与函数定义。Rust 的控制流是**表达式（expression）**——有返回值，这是它写法简洁的关键。
> 闭包（匿名函数）见 [11-迭代器与闭包](./11-迭代器与闭包.md)。

---

## 1. 表达式是主角

Rust 中大部分语法结构是**表达式**，会求值出值；只有少数（如 `let`、`fn`）是**语句（statement）**，无返回值（返回单元 `()`）。

```rust
let y = {
    let x = 3;
    x + 1          // 块（block）是表达式，最后一个表达式的值就是块的值（无分号！）
};                 // y = 4
```

> 关键陷阱：**表达式末尾加分号就变成语句，返回 `()`**。所以 `x + 1` 不加 `;`，它才是返回值。

---

## 2. if / else 是表达式

```rust
let n = 7;
let parity = if n % 2 == 0 { "even" } else { "odd" };  // 直接赋值
```

两个分支必须返回**同类型**。没有三元运算符 `? :`，用 `if/else` 表达式替代。

---

## 3. 循环

```rust
let mut i = 0;
loop {                       // 无限循环，用 break 退出
    i += 1;
    if i > 3 { break; }
}

while i < 10 { i += 1; }     // 条件循环

for n in 0..5 {              // 范围迭代，最常用
    println!("{n}");
}

let v = [10, 20, 30];
for x in v.iter() {          // 遍历集合
    println!("{x}");
}
```

循环也能返回值：

```rust
let result = loop {
    count += 1;
    if count == 10 { break count * 2; }  // break 带值
};
```

`continue` 跳过本次；循环可加 `label` 跳出多层：

```rust
'outer: for i in 0..3 {
    for j in 0..3 {
        if i + j == 3 { break 'outer; }
    }
}
```

---

## 4. 函数定义

```rust
fn add(a: i32, b: i32) -> i32 {   // 参数、返回值都需标注类型
    a + b                          // 隐式返回（最后表达式）
}

fn print_msg(msg: &str) {         // 无返回值标注时返回 ()
    println!("{msg}");
}
```

- 参数和返回类型**必须标注**（编译器不在签名上做推断，只在函数体内推断）。
- 隐式返回 = 最后一行表达式不加 `;`。也可 `return x;` 提前返回。
