# 02 · 变量、常量与标量类型

> 细节速查：`00-学习指南/02-Rust快速参考手册.md`；复合类型见 [05-结构体与方法](./05-结构体与方法.md)。

## 1. 变量默认不可变（immutable by default）

```rust
fn main() {
    let x = 5;
    // x = 6;          // ❌ 编译错误：cannot assign twice to immutable variable
    println!("{x}");
}
```

要可变，必须显式 `mut`：

```rust
let mut count = 0;
count += 1;         // ✅
```

**为什么默认不可变？** 这是 Rust "正确性优先" 哲学：大多数 bug 来自意外的状态变更。默认不可变让编译器帮你守住边界，且不可变数据可安全并发共享（见 `17-concurrency-parallel.md`）。

常量用 `const`（编译期确定，必须标注类型，命名全大写）：

```rust
const MAX_POINTS: u32 = 100_000;   // 数字可用下划线分隔，可读
```

`let` vs `const` vs `static`：

| | 绑定时机 | 类型标注 | 可重绑（shadow） |
|---|---|---|---|
| `let` | 运行期 | 可省略 | 可以 |
| `const` | 编译期 | 必须 | — |
| `static` | 编译期、有固定地址 | 必须 | — |

## 2. 标量类型（Scalar）

标量 = 单个值。Rust 内建四种：

### 整数

| 有符号 | 无符号 | 位宽 |
|--------|--------|------|
| `i8 i16 i32 i64 i128 isize` | `u8 u16 u32 u64 u128 usize` | 8/16/32/64/128/指针宽 |

- `isize` / `usize`：用于索引（如数组下标），宽度随平台（64 位系统上是 64 位）。
- 默认整数类型是 `i32`（综合性能最佳）。
- 溢出：debug 模式**直接 panic**；release 模式按补码回绕（见 `58-unsafe-audit-miri.md` 关于整数溢出的 UB 边界）。

### 浮点

```rust
let f1 = 2.0;      // f64（默认）
let f2: f32 = 3.0; // 显式 f32
```

### 布尔与字符

```rust
let t = true;          // bool
let c = 'z';           // char = Unicode 标量值，4 字节
let emoji = '😻';      // char 可存任意 Unicode，不只是 ASCII
```

> `char` 是 4 字节 Unicode 标量，与 C 的 1 字节 `char` 不同。

## 3. 类型推断与标注

编译器几乎总能推断，但函数签名、结构体字段**必须标注**：

```rust
fn area(width: u32, height: u32) -> u32 {  // 参数和返回值都要标注类型
    width * height
}
```

## 4. Shadowing（变量遮蔽）

```rust
let spaces = "   ";     // &str
let spaces = spaces.len();   // 重新绑定为 usize，合法！不是 mut
println!("{spaces}");   // 3
```

与 `mut` 的区别：shadowing 是**新建绑定**（可改变类型），`mut` 是改同一个绑定的值（类型不变）。
