# 11 · 迭代器与闭包

> 体系定位：Rust 函数式风格的两大支柱。迭代器链**惰性求值、零成本**，是写地道 Rust 的必备。
> 深入：`补充知识点/13-Rust闭包知识手册.md`、`14-Rust迭代器知识手册.md`。

---

## 1. 闭包（匿名函数）

```rust
let add_one = |x: i32| x + 1;        // 单参数可省类型标注
let sum = |a, b| a + b;
println!("{}", add_one(5));         // 6
```

闭包能**捕获环境变量**：

```rust
let factor = 3;
let scaled = |x| x * factor;         // 捕获 factor
println!("{}", scaled(4));          // 12
```

按捕获方式，闭包自动实现三种 trait 之一：
- `Fn`：只读借用捕获（可多次调用）
- `FnMut`：可变借用捕获
- `FnOnce`：拿走所有权（只能调一次）

编译器按用法自动选最宽松的那个。

---

## 2. 迭代器：惰性、链式

```rust
let v = vec![1, 2, 3, 4, 5];
let sum: i32 = v.iter()
    .filter(|&&x| x % 2 == 0)     // 保留偶数
    .map(|&x| x * x)              // 平方
    .sum();                       // 触发执行，sum = 4 + 16 = 20
```

- `iter()` 产生不可变引用迭代器；`iter_mut()` 可变；`into_iter()` 拿走所有权。
- 适配器（`filter`/`map`/`take`/`skip`...）**惰性**——只有 `sum`/`collect`/`for` 等"消费适配器"才真正运行。
- **零成本**：编译后等价于手写 `for` 循环，无额外分配。

---

## 3. collect 收集成集合

```rust
let v: Vec<i32> = (1..=5).map(|x| x * 2).collect();   // [2,4,6,8,10]
```

`collect()` 能收集成 `Vec`/`HashMap`/`String`/`Result<Vec,_>` 等，靠类型推断决定目标。

---

## 4. 迭代器与所有权

```rust
let v = vec![String::from("a"), String::from("b")];
let lens: Vec<usize> = v.into_iter().map(|s| s.len()).collect();
// into_iter 拿走 v 的所有权；之后 v 不可用
```
