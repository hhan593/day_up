# 05 · 结构体与方法（Struct & Impl）

> 体系定位：自定义复合类型。Rust 没有"类"，用**结构体 + impl 块**组织数据与行为。
> 专题深挖：`补充知识点/03-结构体语法.md`（更新语法/Copy）；枚举见 [06-枚举与模式匹配](./06-枚举与模式匹配.md)。

---

## 1. 定义与实例化

```rust
struct User {
    username: String,
    email: String,
    active: bool,
    sign_in_count: u64,
}

let mut u = User {
    email: String::from("a@b.com"),
    username: String::from("alice"),   // 字段顺序不必与定义一致
    active: true,
    sign_in_count: 1,
};
u.email = String::from("c@d.com");      // 结构体整体 mut 才可改字段
```

> 没有"字段级可变性"：要么整体 `mut`，要么全不可变。需要局部可变请用 `RefCell`（见 `补充知识点/15-智能指针知识手册.md`）。

## 2. 元组结构体与单元结构体

```rust
struct Point(i32, i32, i32);     // 元组结构体：无字段名，按位置访问
let p = Point(1, 2, 3);
println!("{}", p.0);

struct AlwaysEqual;              // 单元结构体：无字段，常用于 trait 标记
```

## 3. 方法（impl 块）

```rust
impl User {
    // 关联函数：无 &self，通常用于构造器（习惯命名 new）
    fn new(username: &str, email: &str) -> User {
        User {
            username: username.to_string(),
            email: email.to_string(),
            active: true,
            sign_in_count: 1,
        }
    }

    // 方法：第一个参数是 self（或 &self / &mut self）
    fn greet(&self) -> String {
        format!("hi {}, active={}", self.username, self.active)
    }

    fn increment(&mut self) {
        self.sign_in_count += 1;
    }
}

let mut u = User::new("bob", "b@x.com");  // 用关联函数构造
println!("{}", u.greet());
u.increment();
```

- `&self`：不可变借用自身（只读）。
- `&mut self`：可变借用（修改字段）。
- `self`（无引用）：拿走所有权（少见，多用于转换/消费自身）。
- `Self` 在 impl 内是类型别名，写 `-> Self` 比重复写 `User` 更稳。

## 4. 调试与打印

默认结构体不能 `println!` 打印，需派生 `Debug`：

```rust
#[derive(Debug)]          // 自动实现 Debug trait
struct User { ... }

println!("{:?}", u);      // 用 {:?} 或美化 {:#?}
```

常用派生宏：`Debug` / `Clone` / `Copy` / `PartialEq` / `Default`，见 `补充知识点/03-结构体语法.md`、`12-Rust_Trait知识手册.md`。
