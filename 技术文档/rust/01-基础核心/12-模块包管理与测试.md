## 1. 模块（mod）

```rust
mod network {
    pub fn connect() {        // pub = 对外可见
        println!("connecting...");
    }
    fn secret() {}            // 私有的，模块外不可见
}

mod client {
    pub mod auth {
        pub fn login() {}
    }
}

fn main() {
    network::connect();
    client::auth::login();
}
```

- `mod` 定义命名空间；`pub` 控制可见性（默认私有）。
- `use` 引入路径，避免重复写：`use crate::network::connect;`
- `crate` 指当前包根；`super` 指父模块；`self` 指当前模块。

## 2. 包与 crate

- **crate**：一个可编译单元（库 `lib.rs` 或二进制 `main.rs`）。
- **package**：含 `Cargo.toml` 的目录，可有 1 个 lib + 多个 bin。
- **workspace**：多个 package 共享 `target/` 与依赖（见 `20-cargo-advanced.md`、项目计划 `59-动手项目计划.md` 里的多 crate 例子）。

```toml
[dependencies]
serde = { version = "1", features = ["derive"] }
tokio = { version = "1", features = ["full"] }
```

## 3. 测试

```rust
// 在 src/lib.rs 或任意文件底部
pub fn add(a: i32, b: i32) -> i32 { a + b }

#[cfg(test)]                    // 仅测试构建时编译
mod tests {
    use super::*;
    #[test]
    fn it_adds() {
        assert_eq!(add(2, 2), 4);
    }
}
```

```bash
cargo test        # 运行所有测试
cargo test add    # 只跑名字含 add 的
```

- `#[test]` 标记测试函数。
- `assert_eq!` / `assert!` 做断言。
- 集成测试放 `tests/` 目录（独立 crate，只测公开 API）。

## 4. 文档注释

```rust
/// 计算两数之和（三斜线 = 文档，生成到 docs.rs 风格）
/// ```
/// assert_eq!(add(2, 3), 5);
/// ```
pub fn add(a: i32, b: i32) -> i32 { a + b }
```

`cargo doc --open` 生成文档；文档里的 `///` 示例可被 `cargo test` 当作测试运行（doctest）。
