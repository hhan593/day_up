## 项目 1 · CLI 待办清单（巩固基础）

**目标**：用纯标准库写一个命令行待办工具，支持 `add / list / done / remove`。

**知识点对应**：03 结构体 · 06 String · 08 错误处理 · 09 集合/迭代器 · 10 模块 · 11 测试 · 16 Option/Result

**骨架**（`p1-cli-todo/src/main.rs`）：

```rust
use std::collections::HashMap;
use std::io::{self, Write};

#[derive(Debug, Clone)]
struct Task {
    id: u32,
    title: String,
    done: bool,
}

struct Store {
    tasks: HashMap<u32, Task>,
    next_id: u32,
}

impl Store {
    fn new() -> Self {
        Store { tasks: HashMap::new(), next_id: 1 }
    }
    fn add(&mut self, title: &str) -> u32 {
        let id = self.next_id;
        self.next_id += 1;
        self.tasks.insert(id, Task { id, title: title.to_string(), done: false });
        id
    }
    fn list(&self) {
        for t in self.tasks.values() {
            println!("[{}] {} #{}", if t.done { "x" } else { " " }, t.title, t.id);
        }
    }
}

fn main() {
    let mut store = Store::new();
    loop {
        print!("> ");
        io::stdout().flush().ok();
        let mut line = String::new();
        if io::stdin().read_line(&mut line).is_err() { break; }
        let mut parts = line.trim().split_whitespace();
        match parts.next() {
            Some("add") => {
                let title = parts.collect::<Vec<_>>().join(" ");
                let id = store.add(&title);
                println!("added #{}", id);
            }
            Some("list") => store.list(),
            Some("quit") => break,
            _ => println!("commands: add <text> | list | quit"),
        }
    }
}
```

**验收标准**：
- [ ] `cargo run` 后能 `add` 多条、`list` 展示、`quit` 退出
- [ ] 用 `Result` 处理读写错误，不用 `unwrap()`（参考 08 错误处理）
- [ ] 给 `Store::add` 写一个单元测试（`cargo test` 通过，参考 11 测试）

**进阶挑战**：把数据持久化到 `tasks.json`（用 `serde_json`，对应 40 Serde）；加 `done/remove` 子命令。

## 项目 2 · 手写线程池（巩固并发）

**目标**：不用第三方库，自己实现一个固定大小的线程池，提交闭包任务并执行。

**知识点对应**：15 智能指针（Arc/Mutex） · 17 并发并行 · 43 Rayon（对比用）

**骨架思路**（`p2-thread-pool/src/main.rs`）：

```rust
use std::sync::mpsc;
use std::sync::{Arc, Mutex};
use std::thread;

type Job = Box<dyn FnOnce() + Send + 'static>;

struct Worker {
    _handle: thread::JoinHandle<()>,
}

struct ThreadPool {
    sender: mpsc::Sender<Job>,
    _workers: Vec<Worker>,
}

impl ThreadPool {
    fn new(size: usize) -> ThreadPool {
        let (sender, receiver) = mpsc::channel();
        let receiver = Arc::new(Mutex::new(receiver));
        let mut workers = Vec::with_capacity(size);
        for _ in 0..size {
            let rx = Arc::clone(&receiver);
            let handle = thread::spawn(move || {
                while let Ok(job) = rx.lock().unwrap().recv() {
                    job();
                }
            });
            workers.push(Worker { _handle: handle });
        }
        ThreadPool { sender, _workers }
    }
    fn execute<F: FnOnce() + Send + 'static>(&self, f: F) {
        self.sender.send(Box::new(f)).unwrap();
    }
}

fn main() {
    let pool = ThreadPool::new(4);
    for i in 0..8 {
        pool.execute(move || println!("task {} on {:?}", i, thread::current().id()));
    }
    thread::sleep(std::time::Duration::from_secs(1)); // 等待完成
}
```

**验收标准**：
- [ ] 4 个线程能并发跑完 8 个任务
- [ ] 用 `Arc<Mutex<Receiver>>` 安全共享接收端（理解 15/17）
- [ ] 对比：把任务换成 Rayon 的 `par_iter`（读 43），说说区别

**进阶挑战**：用 `condvar` 实现优雅关闭（drop 时让 worker 退出循环）；加任务返回值（`oneshot` channel）。

## 项目 3 · Axum Web API（巩固 Web/异步）

**目标**：用 axum 写一个带内存存储的 REST API：`GET /tasks`、`POST /tasks`、`GET /tasks/:id`。

**知识点对应**：22 axum · 18 async-await · 39 tokio 深度 · 44 tower 中间件

**`p3-axum-api/Cargo.toml`**：

```toml
[dependencies]
axum = "0.8"
tokio = { version = "1", features = ["full"] }
serde = { version = "1", features = ["derive"] }
serde_json = "1"
tower = "0.5"
tower-http = { version = "0.6", features = ["trace", "cors"] }
```

**`src/main.rs` 骨架**：

```rust
use axum::{
    extract::{Path, State},
    routing::{get, post},
    Json, Router,
};
use serde::{Deserialize, Serialize};
use std::collections::HashMap;
use std::sync::{Arc, Mutex};

#[derive(Clone, Serialize, Deserialize)]
struct Task { id: u32, title: String, done: bool }

#[derive(Clone, Default)]
struct AppState {
    tasks: Arc<Mutex<HashMap<u32, Task>>>,
    next_id: Arc<Mutex<u32>>,
}

async fn list_tasks(State(st): State<AppState>) -> Json<Vec<Task>> {
    let guard = st.tasks.lock().unwrap();
    Json(guard.values().cloned().collect())
}

async fn create_task(
    State(st): State<AppState>,
    Json(input): Json<Task>,
) -> Json<Task> {
    let mut id = st.next_id.lock().unwrap();
    let task = Task { id: *id, ..input };
    *id += 1;
    st.tasks.lock().unwrap().insert(task.id, task.clone());
    Json(task)
}

#[tokio::main]
async fn main() {
    let app = Router::new()
        .route("/tasks", get(list_tasks).post(create_task))
        .layer(tower_http::cors::CorsLayer::permissive()) // 来自 44 tower 中间件
        .with_state(AppState::default());

    let listener = tokio::net::TcpListener::bind("0.0.0.0:3000").await.unwrap();
    println!("listening on :3000");
    axum::serve(listener, app).await.unwrap();
}
```

**验收标准**：
- [ ] `cargo run` 后 `curl localhost:3000/tasks` 返回 `[]`
- [ ] `curl -X POST localhost:3000/tasks -d '{"id":0,"title":"hi","done":false}'` 能写入并 `GET` 读到
- [ ] 用 `tower_http::trace` 打印请求日志（中间件概念见 44）

**进阶挑战**：接真实数据库（读 36 sqlx / 46 Postgres）；加 JWT 鉴权（读 nest/10 思路迁移到 Rust 用 `jsonwebtoken`）。

## 项目 4 · Tokio 异步爬虫（巩固异步运行时）

**目标**：并发抓取多个 URL 的标题（`<title>`），用 `reqwest` + tokio 限流。

**知识点对应**：18 async-await · 39 tokio 深度 · 55 异步运行时选型 · 49 tracing

**`p4-tokio-crawler/Cargo.toml`**：

```toml
[dependencies]
tokio = { version = "1", features = ["full"] }
reqwest = { version = "0.12", features = ["json"] }
futures = "0.3"
tracing = "0.1"
tracing-subscriber = "0.3"
```

**`src/main.rs` 骨架**：

```rust
use reqwest::Client;
use tokio::task::JoinSet;

async fn fetch_title(client: &Client, url: &str) -> anyhow::Result<String> {
    let body = client.get(url).send().await?.text().await?;
    let title = body
        .split("<title>")
        .nth(1)
        .and_then(|s| s.split("</title>").next())
        .unwrap_or("(no title)")
        .to_string();
    Ok(title)
}

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    tracing_subscriber::fmt::init(); // 来自 49 tracing
    let urls = vec![
        "https://www.rust-lang.org",
        "https://docs.rs",
        "https://github.com",
    ];
    let client = Client::new();
    let mut set = JoinSet::new();
    for url in urls {
        let client = client.clone();
        set.spawn(async move {
            let t = fetch_title(&client, url).await;
            (url, t)
        });
    }
    while let Some(res) = set.join_next().await {
        if let Ok((url, Ok(title))) = res {
            tracing::info!(%url, %title, "fetched");
        }
    }
    Ok(())
}
```

**验收标准**：
- [ ] 3 个 URL 并发抓取，总耗时约等于最慢的一个（而非串行累加）
- [ ] 用 `tracing` 输出带字段的结构化日志（理解 49）
- [ ] 用 `Semaphore` 限流到最多 5 并发（读 39 tokio 深度）

**进阶挑战**：改成流式处理（`futures::stream` + `buffered(5)`）；加超时与重试（读 44 tower `Timeout`/`Retry`）。
