# 14 - 存储过程与存储函数

> 目标：掌握存储过程、存储函数的定义与调用，理解变量、流程控制、游标。

---

## 14.1 什么是存储过程

**存储过程（Stored Procedure）**是**预先编译好、存在数据库中的一段 SQL 集合**，可带参数、可含流程控制。

```sql
delimiter $$          -- 临时改变结束符，避免与内部 ; 冲突
create procedure p_student_count()
begin
    select count(*) from student;
end $$
delimiter ;           -- 恢复

-- 调用
call p_student_count();
```

> **为什么改 delimiter**：过程体内部有 `;`，不改结束符 MySQL 会提前截断。这是最常见的坑。

## 14.2 变量

### 系统变量

```sql
show variables like 'autocommit';
select @@autocommit;
set session autocommit = 0;    -- 会话级
set global autocommit = 0;     -- 全局级
```

### 用户定义变量（会话内有效，@前缀）

```sql
set @name = '张三';
set @age := 20;                 -- := 也可
select @name, @age;

select count(*) into @total from student;   -- 查询结果赋值
```

### 局部变量（begin...end 内，declare）

```sql
delimiter $$
create procedure p_test()
begin
    declare cnt int default 0;      -- 局部变量必须在最前面声明
    select count(*) into cnt from student;
    select cnt;
end $$
delimiter ;
```

| 类型 | 前缀 | 作用域 |
|------|------|--------|
| 用户变量 | `@name` | 当前会话 |
| 局部变量 | `declare name` | `begin...end` 内 |

## 14.3 流程控制

```sql
delimiter $$
create procedure p_check(score int)
begin
    -- IF
    if score >= 90 then
        select '优秀';
    elseif score >= 60 then
        select '及格';
    else
        select '不及格';
    end if;

    -- CASE
    case
        when score >= 90 then select 'A';
        when score >= 60 then select 'B';
        else select 'C';
    end case;
end $$
delimiter ;
```

### 循环

```sql
-- WHILE
delimiter $$
create procedure p_while()
begin
    declare i int default 1;
    while i <= 5 do
        select i;
        set i = i + 1;
    end while;
end $$
delimiter ;

-- REPEAT（先执行后判断）
repeat
    set i = i + 1;
until i > 5
end repeat;

-- LOOP + leave
label: loop
    set i = i + 1;
    if i > 5 then leave label; end if;
end loop label;
```

## 14.4 参数类型

| 类型 | 说明 |
|------|------|
| `in`（默认） | 输入参数 |
| `out` | 输出参数 |
| `inout` | 既输入又输出 |

```sql
delimiter $$
create procedure p_avg_score(out avg_score decimal(5,2))
begin
    select avg(score) into avg_score from student;
end $$
delimiter ;

call p_avg_score(@avg);
select @avg;
```

## 14.5 游标（Cursor）

游标用于**逐行处理**查询结果集：

```sql
delimiter $$
create procedure p_cursor()
begin
    declare done int default 0;
    declare s_name varchar(20);
    declare s_score decimal(5,2);
    -- 1. 声明游标
    declare cur cursor for select name, score from student;
    -- 2. 声明异常处理（无数据时置 done=1）
    declare continue handler for not found set done = 1;

    open cur;                       -- 3. 打开
    read_loop: loop
        fetch cur into s_name, s_score;   -- 4. 取一行
        if done = 1 then leave read_loop; end if;
        select concat(s_name, ':', s_score);
    end loop;
    close cur;                      -- 5. 关闭
end $$
delimiter ;
```

> 五步：`declare → open → fetch → close`，配 `handler` 处理结束。

## 14.6 存储函数

存储函数**必须有返回值**，可在 SQL 中直接调用：

```sql
delimiter $$
create function f_level(score int) returns varchar(10)
deterministic
begin
    declare result varchar(10);
    if score >= 90 then set result = '优秀';
    elseif score >= 60 then set result = '及格';
    else set result = '不及格';
    end if;
    return result;
end $$
delimiter ;

-- 在 SQL 中使用
select name, score, f_level(score) as 等级 from student;
```

> `deterministic` 表示「相同输入返回相同结果」，避免被拒绝创建（二进制日志要求）。

### 存储过程 vs 存储函数

| 对比 | 存储过程 | 存储函数 |
|------|---------|---------|
| 返回值 | 可无/多个（out） | **必须有且仅一个** |
| 调用方式 | `call p()` | 可在 SQL 中 `select f()` |
| 参数类型 | `in/out/inout` | 只有 `in` |
| 使用场景 | 复杂业务逻辑 | 计算/转换 |

## 14.7 优缺点

| 优点 | 缺点 |
|------|------|
| 减少网络传输 | **难调试、难维护** |
| 预编译，执行快 | 数据库迁移困难 |
| 复用、集中逻辑 | 高并发下 DB 压力大 |
| 权限控制 | 业务逻辑分散在 DB |

> **实战建议**：互联网项目**少用**存储过程，业务逻辑放应用层（Java）。但简单函数、批量数据处理仍有用武之地。

---

## 小结

- 存储过程用 `delimiter` 包裹，`call` 调用；存储函数必须 `return`。
- 局部变量 `declare`，用户变量 `@x`。
- 流程控制：`if` / `case` / `while` / `repeat` / `loop`。
- 参数：`in` / `out` / `inout`。
- 游标五步：declare → open → fetch → close + handler。
- 实战少用存储过程。
