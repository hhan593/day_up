# 08 - 多表查询

> 目标：掌握连接查询、自连接、子查询、UNION，理解笛卡尔积。

---

## 8.1 为什么需要多表查询

实际业务数据分散在多张表（如「部门表」+「员工表」），需要**关联查询**：

```text
tb_dept                  tb_emp
id | name               id | name | dept_id
1  | 研发部             1  | 张三 | 1
2  | 销售部             2  | 李四 | 1
                        3  | 王五 | 2
```

---

## 8.2 笛卡尔积

直接 `from a, b` 会得到**每行两两组合**的结果（a 行数 × b 行数）：

```sql
select * from tb_dept, tb_emp;   -- 2 × 3 = 6 行（多数是无效组合）
```

**解决**：加连接条件，过滤掉无效组合。

---

## 8.3 内连接 INNER JOIN

只返回**两张表都能匹配上**的记录。

```sql
-- 隐式内连接
select e.name, d.name as dept
from tb_emp e, tb_dept d
where e.dept_id = d.id;

-- 显式内连接（推荐）
select e.name, d.name as dept
from tb_emp e
inner join tb_dept d on e.dept_id = d.id;
```

---

## 8.4 外连接

### 左外连接 LEFT JOIN

返回**左表全部** + 右表匹配的记录（右表无匹配则显示 NULL）。

```sql
-- 查询所有部门及其员工（没有员工的部门也显示）
select d.name as dept, e.name as emp
from tb_dept d
left join tb_emp e on d.id = e.dept_id;
```

### 右外连接 RIGHT JOIN

返回**右表全部** + 左表匹配的记录。

```sql
select d.name as dept, e.name as emp
from tb_emp e
right join tb_dept d on e.dept_id = d.id;
```

> 左外和右外可以互相改写（交换表的位置）。实际开发 **LEFT JOIN 更常用**。

| 连接 | 结果 |
|------|------|
| `inner join` | 两表都匹配的行 |
| `left join` | 左表全部 + 右表匹配 |
| `right join` | 右表全部 + 左表匹配 |

### 案例：查询没有员工的部门

```sql
select d.name
from tb_dept d
left join tb_emp e on d.id = e.dept_id
where e.id is null;       -- 右表为 NULL 说明没匹配上
```

---

## 8.5 自连接

**一张表连接自己**，用于处理表内层级关系（如员工-经理）。

```sql
-- 查询员工及其经理姓名
select e.name as 员工, m.name as 经理
from tb_emp e
left join tb_emp m on e.manager_id = m.id;
```

> 自连接**必须起不同别名**（`e` 和 `m`），否则无法区分。

---

## 8.6 子查询

**嵌套在 SQL 中的 SELECT**，按返回结果分为：

### 标量子查询（返回单个值）

```sql
-- 查询工资高于平均工资的员工
select * from tb_emp
where salary > (select avg(salary) from tb_emp);
```

### 列子查询（返回一列多行）

```sql
-- 查询"研发部"和"销售部"的员工
select * from tb_emp
where dept_id in (select id from tb_dept where name in ('研发部','销售部'));
```

配合 `in` / `any` / `all`：

```sql
-- 高于任意一个销售员工资
where salary > any (select salary from tb_emp where dept_id = 2);
-- 高于所有销售员工资
where salary > all (select salary from tb_emp where dept_id = 2);
```

### 行子查询（返回一行多列）

```sql
select * from tb_emp
where (salary, dept_id) = (select max(salary), dept_id from tb_emp group by dept_id limit 1);
```

### 表子查询（返回多行多列，常作临时表）

```sql
select * from
    (select * from tb_emp where salary > 10000) as t
where t.dept_id = 1;
```

### EXISTS 子查询

```sql
-- 查询有员工的部门
select * from tb_dept d
where exists (select 1 from tb_emp e where e.dept_id = d.id);
```

> `EXISTS` 只关心子查询**有没有结果**，不关心具体值。

---

## 8.7 UNION 合并查询

```sql
-- union：合并并去重
select name from tb_emp where salary > 10000
union
select name from tb_emp where dept_id = 1;

-- union all：合并但不去重（性能更好）
select name from tb_emp where salary > 10000
union all
select name from tb_emp where dept_id = 1;
```

> 要求两边的**列数相同、类型兼容**。`union all` 不排序去重，性能优于 `union`。

---

## 8.8 综合案例

```sql
-- 表结构
create table tb_dept (id int primary key auto_increment, name varchar(20));
create table tb_emp (
    id int primary key auto_increment,
    name varchar(20),
    salary decimal(10,2),
    dept_id int,
    manager_id int
);

-- 1. 查询每个员工及其部门名（内连接）
select e.name, d.name as dept
from tb_emp e inner join tb_dept d on e.dept_id = d.id;

-- 2. 统计每个部门的平均工资
select d.name, avg(e.salary) as avg_salary
from tb_dept d left join tb_emp e on d.id = e.dept_id
group by d.id, d.name;

-- 3. 查询工资高于本部门平均工资的员工
select e.name, e.salary
from tb_emp e
where e.salary > (
    select avg(salary) from tb_emp
    where dept_id = e.dept_id
);

-- 4. 查询没有员工的部门
select d.name
from tb_dept d left join tb_emp e on d.id = e.dept_id
where e.id is null;
```

---

## 小结

- 多表查询要避免**笛卡尔积**，必须加连接条件。
- 内连接取交集，左/右外连接保留一侧全部。
- 自连接需起别名，处理层级关系。
- 子查询按返回结果分标量/列/行/表，`exists` 只判有无。
- `union all` 不去重，比 `union` 快。
