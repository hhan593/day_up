## 0.1 文档定位

| 目录 | 定位 |
|------|------|
| `../java_base/` | Java 语言基础（语法 / 面向对象 / 数组 / 集合） |
| **`./mysql/`（本目录）** | **数据库基础 + MySQL 进阶（SQL / 事务 / 索引 / 锁 / 集群）** |

## 0.4 如何使用本套文档

1. **第一阶段必须动手**：所有 SQL 都在 MySQL 客户端里敲一遍，不要只看。
2. **09/11/16/17 是重点**：事务、索引、锁、InnoDB 是面试核心，要理解原理而非死记。
3. **12 章配合 11 章**：先懂索引，再学优化，否则优化只是背结论。
4. 每篇末尾「小结」用于复习，「练习」用于检验。
