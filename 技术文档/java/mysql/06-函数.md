# 06 - 函数

> 目标：掌握字符串、数值、日期、流程四类常用函数。

---

## 6.1 字符串函数

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| `concat(s1,s2)` | 拼接 | `concat('a','b')` | `ab` |
| `lower(s)` / `upper(s)` | 转小写 / 大写 | `upper('abc')` | `ABC` |
| `length(s)` | 字节长度 | `length('张三')` | 6（utf8mb4 下 3×2） |
| `char_length(s)` | 字符长度 | `char_length('张三')` | 2 |
| `substring(s,start,len)` | 截取 | `substring('hello',2,3)` | `ell` |
| `replace(s,from,to)` | 替换 | `replace('abc','b','x')` | `axc` |
| `trim(s)` | 去首尾空格 | `trim(' a ')` | `a` |
| `lpad(s,n,pad)` / `rpad` | 左/右填充 | `lpad('1',3,'0')` | `001` |

```sql
select concat(name, '(', gender, ')') as info from student;
select char_length('hello') as 字符数, length('hello') as 字节数;   -- 5, 5
select char_length('张三');   -- 2（字符数）
select substring('13800138000', 1, 3) as 号段;   -- 138
```

> **易错点**：MySQL 的 `substring` 起始位置从 **1** 开始（不是 0）。`length` 是字节数，中文要用 `char_length`。

### 案例：手机号脱敏

```sql
select concat(
    substring(phone, 1, 3), '****', substring(phone, 8, 4)
) as 脱敏手机号
from student where phone is not null;
-- 13800138000 → 138****8000
```

## 6.2 数值函数

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| `ceil(x)` | 向上取整 | `ceil(1.1)` | 2 |
| `floor(x)` | 向下取整 | `floor(1.9)` | 1 |
| `round(x,y)` | 四舍五入（y 位小数） | `round(3.456,2)` | 3.46 |
| `mod(x,y)` | 取模 | `mod(7,3)` | 1 |
| `abs(x)` | 绝对值 | `abs(-5)` | 5 |
| `rand()` | 0~1 随机 | `rand()` | 0.37… |
| `truncate(x,y)` | 直接截断 y 位 | `truncate(3.456,2)` | 3.45 |
| `greatest/least` | 最大/最小值 | `greatest(1,5,3)` | 5 |

```sql
select round(3.456, 2);                    -- 3.46
select floor(rand() * 100) + 1;            -- 1~100 随机整数
```

## 6.3 日期时间函数

| 函数 | 作用 | 示例 |
|------|------|------|
| `now()` / `sysdate()` | 当前日期时间 | `2026-09-18 10:30:00` |
| `curdate()` / `curtime()` | 当前日期 / 时间 | `2026-09-18` / `10:30:00` |
| `year(d)` / `month(d)` / `day(d)` | 年 / 月 / 日 | `year('2026-09-18')` → 2026 |
| `date_add(d, interval n unit)` | 日期加 | `date_add(now(), interval 7 day)` |
| `date_sub(d, interval n unit)` | 日期减 | `date_sub(now(), interval 1 month)` |
| `datediff(d1,d2)` | 相差天数 | `datediff('2026-09-20','2026-09-18')` → 2 |
| `date_format(d,fmt)` | 格式化 | `date_format(now(),'%Y-%m-%d')` |
| `str_to_date(s,fmt)` | 字符串转日期 | `str_to_date('2026-09-18','%Y-%m-%d')` |

```sql
select now(), curdate(), curtime();
select year(now()), month(now()), day(now());
select date_add(now(), interval 30 day) as 一个月后;
select datediff('2026-12-31', now()) as 剩余天数;
select date_format(now(), '%Y年%m月%d日 %H:%i:%s') as 格式化;

-- 查询本周新增用户
select * from tb_user
where create_time >= date_sub(curdate(), interval weekday(curdate()) day);
```

> **易错点**：`%Y` 是 4 位年，`%y` 是 2 位；`%m` 月，`%d` 日，`%H` 时（24 小时），`%i` 分，`%s` 秒。

## 6.4 流程函数

| 函数 | 作用 |
|------|------|
| `if(cond, a, b)` | 条件为真返回 a，否则 b |
| `ifnull(v1, v2)` | v1 为 NULL 返回 v2，否则 v1 |
| `nullif(v1, v2)` | v1 = v2 返回 NULL，否则 v1 |
| `case when ... then ... else ... end` | 多分支 |

```sql
-- if：成绩是否及格
select name, if(score >= 60, '及格', '不及格') as 结果 from student;

-- ifnull：手机号为 NULL 时显示"未填写"
select name, ifnull(phone, '未填写') as 手机号 from student;

-- case when：成绩等级
select name, score,
    case
        when score >= 90 then '优秀'
        when score >= 80 then '良好'
        when score >= 60 then '及格'
        else '不及格'
    end as 等级
from student;
```

> `case when` 是 SQL 中最常用的流程控制，报表统计、条件分类必用。

---

## 6.5 综合案例

```sql
-- 统计各班及格率与优秀率
select class,
    count(*) as 总人数,
    sum(if(score >= 60, 1, 0)) as 及格人数,
    round(sum(if(score >= 60, 1, 0)) / count(*) * 100, 2) as 及格率,
    round(sum(if(score >= 90, 1, 0)) / count(*) * 100, 2) as 优秀率
from student
group by class;
```

## 小结

- 字符串：`concat` / `substring` / `char_length` / `lpad`（脱敏常用）。
- 数值：`round` / `ceil` / `floor` / `mod` / `rand`。
- 日期：`date_add` / `datediff` / `date_format`（**`substring` 和日期都从 1 开始**）。
- 流程：`if` / `ifnull` / `case when`。
