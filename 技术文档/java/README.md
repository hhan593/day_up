## 学习路径

1. **语言基础**（01-06）：语法、OOP、集合、泛型、异常。
2. **并发与 JVM**（07-12）：并发、虚拟线程、JMM、反射注解。
3. **框架**（13-19）：Spring Boot/Core、MyBatis、JPA、JDBC、测试、调优。
4. **进阶生态**（20-25）：设计模式、并发集合、Stream、Redis、微服务、面试。
5. **云原生现代栈**（26-30）：WebFlux、Kafka、GraalVM、K8s、可观测性。
