## 怎么用这个目录

1. **出事时查**：线上故障直接翻 01 / 08 / 10。
2. **写代码前查**：涉及事务（03）、缓存（04）、幂等（05）、线程池（09）先看清单再动手。
3. **面试深聊**：面试官问「你遇到过什么线上问题」，这些就是答案素材——重点讲**排查过程**，不是背概念。
