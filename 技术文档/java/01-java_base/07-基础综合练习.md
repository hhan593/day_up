## 7.1 数字加密

**需求**：输入 4 位整数，按规则加密：每位 +5 后对 10 取余，再反转。

```java
import java.util.Scanner;

public class Encrypt {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("输入 4 位密码：");
        int password = sc.nextInt();

        int[] digits = new int[4];
        for (int i = 3; i >= 0; i--) {
            digits[i] = password % 10;
            password /= 10;
        }

        // 每位 +5 对 10 取余
        for (int i = 0; i < digits.length; i++) {
            digits[i] = (digits[i] + 5) % 10;
        }

        // 反转（第 0 位与第 3 位、第 1 位与第 2 位交换）
        for (int i = 0, j = digits.length - 1; i < j; i++, j--) {
            int tmp = digits[i];
            digits[i] = digits[j];
            digits[j] = tmp;
        }

        int result = 0;
        for (int d : digits) {
            result = result * 10 + d;
        }
        System.out.println("加密结果：" + result);
        sc.close();
    }
}
```

## 7.2 评委打分

**需求**：6 位评委打分（0-100），去掉一个最高分、一个最低分，求平均分。

```java
public class ScoreDemo {
    public static void main(String[] args) {
        int[] scores = {88, 95, 72, 90, 85, 100};

        int max = scores[0];
        int min = scores[0];
        int sum = 0;
        for (int s : scores) {
            if (s > max) max = s;
            if (s < min) min = s;
            sum += s;
        }

        // 去掉一个最高、一个最低
        double avg = (double) (sum - max - min) / (scores.length - 2);
        System.out.printf("最终得分：%.2f%n", avg);   // %n 是平台无关换行
    }
}
```

## 7.3 双色球号码生成

**需求**：生成 6 个不重复的红球（1-33）和 1 个蓝球（1-16）。

```java
import java.util.Random;

public class Lottery {
    public static void main(String[] args) {
        int[] red = new int[6];
        Random r = new Random();
        int index = 0;

        while (index < 6) {
            int num = r.nextInt(33) + 1;
            if (!contains(red, index, num)) {   // 去重
                red[index++] = num;
            }
        }

        System.out.print("红球：");
        for (int n : red) System.out.print(n + " ");
        System.out.println("蓝球：" + (r.nextInt(16) + 1));
    }

    // 判断 num 是否已存在于 arr 的前 len 个元素中
    public static boolean contains(int[] arr, int len, int num) {
        for (int i = 0; i < len; i++) {
            if (arr[i] == num) return true;
        }
        return false;
    }
}
```

> 这是「**数组 + 方法抽取 + 循环去重**」的典型综合题。

## 7.4 验证码生成

**需求**：随机生成 5 位验证码，包含大小写字母和数字。

```java
import java.util.Random;

public class Captcha {
    public static void main(String[] args) {
        String chars = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789";
        Random r = new Random();
        StringBuilder sb = new StringBuilder();

        for (int i = 0; i < 5; i++) {
            int index = r.nextInt(chars.length());
            sb.append(chars.charAt(index));
        }
        System.out.println("验证码：" + sb);
    }
}
```

## 7.5 找素数

**需求**：输出 1-100 之间的所有素数。

```java
public class Prime {
    public static void main(String[] args) {
        for (int i = 2; i <= 100; i++) {
            if (isPrime(i)) {
                System.out.print(i + " ");
            }
        }
    }

    public static boolean isPrime(int n) {
        // 只需判断到平方根，提升效率
        for (int i = 2; i <= Math.sqrt(n); i++) {
            if (n % i == 0) return false;
        }
        return true;
    }
}
```

## 7.6 简易学生成绩管理（面向过程版）

**需求**：用数组保存成绩，实现「录入 / 查看 / 求平均 / 求最高」。

```java
import java.util.Scanner;

public class ScoreManager {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("录入几个学生？");
        int n = sc.nextInt();
        int[] scores = new int[n];

        for (int i = 0; i < n; i++) {
            System.out.print("第 " + (i + 1) + " 个成绩：");
            scores[i] = sc.nextInt();
        }

        System.out.println("成绩列表：");
        printArray(scores);
        System.out.println("平均分：" + average(scores));
        System.out.println("最高分：" + max(scores));
        sc.close();
    }

    public static void printArray(int[] arr) {
        for (int v : arr) System.out.print(v + " ");
        System.out.println();
    }

    public static double average(int[] arr) {
        int sum = 0;
        for (int v : arr) sum += v;
        return (double) sum / arr.length;
    }

    public static int max(int[] arr) {
        int max = arr[0];
        for (int v : arr) if (v > max) max = v;
        return max;
    }
}
```

## 小结

综合题通用套路：

1. **拆解需求**：先想清楚步骤（录入 → 计算 → 输出）。
2. **数据用数组存**，重复逻辑抽成**方法**。
3. **循环 + 判断** 处理每个元素。
4. 注意边界：空数组、除零、索引越界。
