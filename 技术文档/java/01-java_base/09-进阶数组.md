## 9.1 Arrays 工具类

```java
import java.util.Arrays;

int[] arr = {5, 2, 8, 1, 9};

// 转字符串打印
System.out.println(Arrays.toString(arr));        // [5, 2, 8, 1, 9]

// 排序（默认升序）
Arrays.sort(arr);
System.out.println(Arrays.toString(arr));        // [1, 2, 5, 8, 9]

// 二分查找（必须先排序，返回索引，找不到返回负数）
int index = Arrays.binarySearch(arr, 8);         // 3

// 拷贝（指定新长度，超出部分补默认值）
int[] copy = Arrays.copyOf(arr, 3);              // [1, 2, 5]
int[] expanded = Arrays.copyOf(arr, 8);          // 扩容，后面补 0

// 区间拷贝 [from, to)
int[] part = Arrays.copyOfRange(arr, 1, 4);      // [2, 5, 8]

// 填充
int[] filled = new int[5];
Arrays.fill(filled, 7);                          // [7,7,7,7,7]

// 判断相等（比较内容，不是地址）
System.out.println(Arrays.equals(arr, copy));    // false
```

> **对比**：`arr.toString()` 打印的是地址（如 `[I@1b6d3586`），要用 `Arrays.toString(arr)`。

## 9.2 冒泡排序

思路：相邻两两比较，大的往后换；每轮确定一个最大值。

```java
public static void bubbleSort(int[] arr) {
    for (int i = 0; i < arr.length - 1; i++) {          // 轮数
        for (int j = 0; j < arr.length - 1 - i; j++) {  // 已排好的不用再比
            if (arr[j] > arr[j + 1]) {
                int tmp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = tmp;
            }
        }
    }
}
```

```text
原始：[5, 2, 8, 1]
第1轮：[2, 5, 1, 8]   ← 8 归位
第2轮：[2, 1, 5, 8]   ← 5 归位
第3轮：[1, 2, 5, 8]   ← 完成
```

> 时间复杂度 O(n²)，稳定排序。加个 `swapped` 标记可在已有序时提前结束。

## 9.3 选择排序

思路：每轮从未排序区间选出最小值，放到已排序区间末尾。

```java
public static void selectionSort(int[] arr) {
    for (int i = 0; i < arr.length - 1; i++) {
        int minIndex = i;
        for (int j = i + 1; j < arr.length; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j;
            }
        }
        // 交换
        int tmp = arr[i];
        arr[i] = arr[minIndex];
        arr[minIndex] = tmp;
    }
}
```

| 排序 | 思路 | 时间复杂度 | 稳定性 |
|------|------|-----------|--------|
| 冒泡 | 相邻交换，大的后移 | O(n²) | 稳定 |
| 选择 | 每轮选最小 | O(n²) | 不稳定 |

## 9.4 二分查找

前提：数组**必须有序**。每次取中间值与目标比较，缩小一半范围。

```java
public static int binarySearch(int[] arr, int target) {
    int left = 0;
    int right = arr.length - 1;

    while (left <= right) {
        int mid = (left + right) / 2;
        if (arr[mid] == target) {
            return mid;
        } else if (arr[mid] < target) {
            left = mid + 1;      // 目标在右半区
        } else {
            right = mid - 1;     // 目标在左半区
        }
    }
    return -1;                   // 没找到
}
```

```text
有序：[1, 3, 5, 7, 9, 11, 13]  找 9
mid=3(值7) → 9>7 → left=4
mid=5(值11) → 9<11 → right=4
mid=4(值9) → 命中，返回 4
```

> 时间复杂度 O(log n)，比线性查找快得多，但**必须有序**。

## 9.5 数组拷贝与扩容

数组长度固定，所谓「扩容」是**创建更大的新数组并拷贝**：

```java
public static int[] grow(int[] arr, int newLength) {
    int[] newArr = new int[newLength];
    // 逐元素拷贝
    for (int i = 0; i < arr.length; i++) {
        newArr[i] = arr[i];
    }
    return newArr;
}

// 或直接用系统方法（效率更高）
int[] bigger = Arrays.copyOf(arr, arr.length * 2);
```

> `System.arraycopy(src, srcPos, dest, destPos, length)` 是底层高效拷贝方法。

## 9.6 二维数组进阶

```java
// 矩阵转置
int[][] m = {
    {1, 2, 3},
    {4, 5, 6}
};
int rows = m.length, cols = m[0].length;
int[][] t = new int[cols][rows];
for (int i = 0; i < rows; i++) {
    for (int j = 0; j < cols; j++) {
        t[j][i] = m[i][j];
    }
}

// 杨辉三角
int n = 5;
int[][] pascal = new int[n][];
for (int i = 0; i < n; i++) {
    pascal[i] = new int[i + 1];
    pascal[i][0] = pascal[i][i] = 1;
    for (int j = 1; j < i; j++) {
        pascal[i][j] = pascal[i - 1][j - 1] + pascal[i - 1][j];
    }
}
```

## 9.7 综合案例：数组去重 + 排序

```java
import java.util.Arrays;

public class Dedup {
    public static void main(String[] args) {
        int[] arr = {5, 2, 5, 8, 2, 1};
        int[] temp = new int[arr.length];
        int size = 0;

        for (int v : arr) {
            if (!contains(temp, size, v)) {
                temp[size++] = v;
            }
        }
        int[] result = Arrays.copyOf(temp, size);
        Arrays.sort(result);
        System.out.println(Arrays.toString(result));// [1, 2, 5, 8]
    }

    public static boolean contains(int[] arr, int len, int value) {
        for (int i = 0; i < len; i++) {
            if (arr[i] == value) return true;
        }
        return false;
    }
}
```

## 小结

- `Arrays` 提供排序、查找、拷贝、填充、比较等工具。
- 冒泡：相邻交换；选择：每轮选最小，均 O(n²)。
- 二分查找 O(log n)，**前提是有序**。
- 数组「扩容」= 新建更大数组 + 拷贝。
- 打印数组用 `Arrays.toString()`，不要直接打印。
