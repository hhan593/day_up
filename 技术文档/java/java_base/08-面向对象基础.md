# 08 - 面向对象基础

> 目标：理解类与对象，掌握构造方法、this、封装、JavaBean，建立面向对象思维。

---

## 8.1 为什么需要面向对象

面向过程：**以步骤为中心**，数据和方法分离。

```java
// 面向过程：用数组存学生信息，散落一堆变量
String name1 = "张三";
int age1 = 18;
```

面向对象：**以对象为中心**，把数据和行为封装在一起。

```java
// 面向对象：一个 Student 对象包含姓名和年龄
Student s = new Student("张三", 18);
s.introduce();
```

> 面向对象（OOP）三大特性：**封装、继承、多态**。本篇讲封装，继承/多态见进阶。

---

## 8.2 类与对象

- **类（class）**：模板 / 图纸，描述一类事物。
- **对象（object）**：类的具体实例。

```java
// 定义类
public class Student {
    // 成员变量（属性）
    String name;
    int age;

    // 成员方法（行为）
    public void study() {
        System.out.println(name + " 正在学习");
    }
}

// 创建对象并使用
public class Test {
    public static void main(String[] args) {
        Student s = new Student();   // new 创建对象
        s.name = "张三";              // 访问属性
        s.age = 18;
        s.study();                   // 调用方法
    }
}
```

内存：`s` 是栈中的引用，`new Student()` 在堆中创建对象。

## 8.3 成员变量 vs 局部变量

```java
public class Student {
    String name;                 // 成员变量：类中、方法外
    int age;

    public void study() {
        int count = 1;           // 局部变量：方法内
        System.out.println(name + " 学了 " + count + " 小时");
    }
}
```

| 对比 | 成员变量 | 局部变量 |
|------|---------|---------|
| 位置 | 类中、方法外 | 方法 / 代码块内 |
| 默认值 | 有（0 / false / null） | **无，必须初始化** |
| 内存 | 堆（随对象） | 栈 |
| 生命周期 | 随对象 | 随方法调用 |

> **就近原则**：局部变量与成员变量同名时，方法内优先使用局部变量。

## 8.4 构造方法

**方法名与类名相同、无返回值类型**，创建对象时自动调用。

```java
public class Student {
    String name;
    int age;

    // 无参构造
    public Student() {
        System.out.println("对象被创建");
    }

    // 有参构造（重载）
    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```

要点：
- 不写构造方法时，Java 会**自动生成无参构造**。
- **一旦手动写了有参构造，无参构造就没了**，需要就手动补上。
- 构造方法可以重载。

---

## 8.5 this 关键字

`this` 指向**当前对象**，用于区分成员变量和局部变量。

```java
public Student(String name, int age) {
    this.name = name;    // this.name 是成员变量，name 是参数
    this.age = age;
}
```

其他用法：`this()` 调用本类其他构造方法（必须放第一行）。

```java
public Student() {
    this("未知", 0);     // 调用有参构造
}
```

## 8.6 封装

**把属性私有化（private），通过 public 方法访问**，保护数据。

```java
public class Student {
    private String name;    // 私有：外部不能直接访问
    private int age;

    public String getName() { return name; }
    public void setName(String name) { this.name = name; }

    public int getAge() { return age; }
    public void setAge(int age) {
        if (age >= 0) {          // 可以加校验，保护数据合法性
            this.age = age;
        } else {
            System.out.println("年龄不能为负");
        }
    }
}
```

| 修饰符 | 本类 | 同包 | 子类 | 其他 |
|--------|------|------|------|------|
| `private` | ✅ | ❌ | ❌ | ❌ |
| 默认（不写） | ✅ | ✅ | ❌ | ❌ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| `public` | ✅ | ✅ | ✅ | ✅ |

> 封装的好处：可以加**校验逻辑**，外部不能随意破坏对象状态。

## 8.7 JavaBean

符合以下规范的类叫 JavaBean（企业开发的标准写法）：

1. 类是 `public` 的。
2. 成员变量全部 `private`。
3. 提供无参构造 + 有参构造。
4. 提供 `getXxx` / `setXxx` 方法。

```java
public class User {
    private String username;
    private String password;

    public User() {}
    public User(String username, String password) {
        this.username = username;
        this.password = password;
    }

    public String getUsername() { return username; }
    public void setUsername(String username) { this.username = username; }
    public String getPassword() { return password; }
    public void setPassword(String password) { this.password = password; }
}
```

## 8.8 对象内存图

```java
Student s1 = new Student("张三", 18);
Student s2 = s1;         // 复制地址，s1、s2 指向同一对象
s2.setName("李四");
System.out.println(s1.getName());   // 李四
```

```text
栈            堆
s1 ──┐
     ├──►  Student 对象 { name="李四", age=18 }
s2 ──┘
```

> 引用赋值复制的是**地址**，两个引用指向同一对象。

## 8.9 综合案例：学生管理

```java
public class Student {
    private String name;
    private int score;

    public Student() {}
    public Student(String name, int score) {
        this.name = name;
        this.score = score;
    }

    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public int getScore() { return score; }
    public void setScore(int score) { this.score = score; }

    public String toString() {
        return "Student{name='" + name + "', score=" + score + "}";
    }
}

public class Test {
    public static void main(String[] args) {
        Student[] students = {
            new Student("张三", 88),
            new Student("李四", 95),
            new Student("王五", 76)
        };

        Student top = students[0];
        for (Student s : students) {
            if (s.getScore() > top.getScore()) top = s;
        }
        System.out.println("最高分：" + top);   // 自动调用 toString()
    }
}
```

## 小结

- 类是模板，对象是实例；`new` 创建对象。
- 成员变量有默认值，局部变量没有。
- 构造方法名同类名、无返回值；写了有参构造要记得补无参。
- `this` 区分成员与局部变量；`this()` 调用本类构造。
- 封装 = `private` 属性 + `public` getter/setter。
- JavaBean 是企业标准写法。
- 引用赋值复制地址，多引用指向同一对象。
