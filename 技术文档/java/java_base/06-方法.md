# 06 - 方法

> 目标：掌握方法的定义、调用、重载、可变参数、值传递与递归。

---

## 6.1 方法是什么

方法（method）= 一段**可复用的代码块**，用于完成特定功能。

好处：**复用、模块化、易维护**。

```java
修饰符 返回值类型 方法名(参数列表) {
    方法体;
    return 返回值;   // 无返回值（void）可省略
}
```

```java
public static int add(int a, int b) {
    return a + b;
}
```

| 部分 | 说明 |
|------|------|
| `public static` | 修饰符（先照写，进阶篇讲含义） |
| `int` | 返回值类型，无返回写 `void` |
| `add` | 方法名（小驼峰） |
| `(int a, int b)` | 形参列表 |
| `return` | 返回结果并结束方法 |

---

## 6.2 调用与执行流程

```java
public class Demo {
    public static void main(String[] args) {
        int sum = add(3, 5);        // 调用，实参 3、5
        System.out.println(sum);    // 8
        printHello();                // 调用无返回值方法
    }

    public static int add(int a, int b) {
        return a + b;
    }

    public static void printHello() {
        System.out.println("Hello");
        // void 方法可以写 return; 用于提前结束，但不返回值
    }
}
```

流程：调用方法 → 实参传给形参 → 执行方法体 → `return` 返回结果 → 回到调用处继续。

---

## 6.3 形参与实参、返回值

```java
// 形参：方法定义时的参数
public static int max(int a, int b) {   // a、b 是形参
    return a > b ? a : b;               // 有返回值
}

// 实参：调用时传入的值
int m = max(10, 20);                    // 10、20 是实参
```

- 方法可以无参、无返回值（`void`）。
- 有返回值的方法**所有分支都要 return**，否则编译报错。

## 6.4 方法重载（Overload）

**同一个类中，方法名相同、参数列表不同**（类型/个数/顺序不同），与返回值无关。

```java
public static int add(int a, int b) { return a + b; }
public static int add(int a, int b, int c) { return a + b + c; }       // 参数个数不同
public static double add(double a, double b) { return a + b; }          // 参数类型不同

// 调用时根据实参自动匹配
add(1, 2);        // 第一个
add(1, 2, 3);     // 第二个
add(1.5, 2.5);    // 第三个
```

> **易错**：只有返回值不同**不构成重载**（编译报错）。参数列表必须不同。

---

## 6.5 可变参数

参数个数不定时使用，语法 `类型... 名称`：

```java
public static int sum(int... nums) {     // nums 本质是 int[] 数组
    int total = 0;
    for (int n : nums) total += n;
    return total;
}

sum();              // 0
sum(1, 2);          // 3
sum(1, 2, 3, 4);    // 10
```

> 可变参数必须放在参数列表**最后**，且一个方法只能有一个。

## 6.6 值传递（重点）

Java **只有值传递**：

- 基本类型：传的是**值的副本**，方法内修改不影响外部。
- 引用类型：传的是**地址的副本**，方法内通过地址修改对象**会影响外部**，但重新赋值不影响。

```java
public static void main(String[] args) {
    int a = 10;
    change(a);
    System.out.println(a);      // 10，不受影响

    int[] arr = {1, 2, 3};
    changeArr(arr);
    System.out.println(arr[0]); // 100，被修改
}

public static void change(int x) {
    x = 20;                     // 改的是副本
}

public static void changeArr(int[] arr) {
    arr[0] = 100;               // 通过地址改堆中数据
}
```

> 经典面试题：Java 是值传递还是引用传递？答：**值传递**，引用类型传的是引用（地址）的副本。

## 6.7 递归

方法**自己调用自己**，必须有**出口**（终止条件），否则栈溢出。

```java
// 求阶乘 n!
public static int factorial(int n) {
    if (n == 1) return 1;           // 出口
    return n * factorial(n - 1);    // 递归
}
// factorial(5) = 5*4*3*2*1 = 120

// 斐波那契
public static int fib(int n) {
    if (n <= 2) return 1;
    return fib(n - 1) + fib(n - 2);
}
```

> 递归代码简洁但有性能开销（重复计算、栈深度限制），能用循环替代时优先循环。

---

## 小结

- 方法 = 复用代码块，格式 `修饰符 返回值 方法名(参数) { ... }`。
- 重载 = 同名不同参（与返回值无关）。
- 可变参数 `int... nums` 本质是数组，必须在最后。
- Java 只有值传递：基本类型传副本，引用类型传地址副本。
- 递归必须有出口。
