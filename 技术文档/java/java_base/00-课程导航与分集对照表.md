# 00 - 课程导航与分集对照表

> 本文是 `java_base` 基础篇的总导航，说明文档结构、学习路线与章节对照。
> 基础篇学完后，进入 `../java-middle/` 进阶篇（集合深入、泛型、Stream、并发、Spring、JVM 等）。

---

## 0.1 文档定位

`java_base` = **Java 基础篇**，面向零基础到能写小项目的阶段，风格为「课程笔记 + 可运行代码 + 表格对比 + 易错点」。

| 对比项 | `java_base`（本目录） | `../java-middle`（进阶篇） |
|--------|----------------------|---------------------------|
| 定位 | 语言基础入门 | 框架与原理进阶 |
| 内容 | 语法、数组、方法、面向对象、常用 API | 集合原理、泛型、Stream、并发、JVM、Spring、数据库 |
| 目标 | 能独立写控制台小项目 | 能写企业级后端应用 |

## 0.4 如何使用本套文档

1. **按 00 → 09 顺序学**，每篇都先读「概念」，再动手敲「代码」，最后做「练习」。
2. **代码必须自己敲一遍**，不要只看。看会 ≠ 会写。
3. 遇到报错先看文档的「常见问题」小节，再搜索引擎。
4. 每篇末尾的「小结」用来复习，能口述出来才算掌握。
5. 学完 07 和 09 的综合题，基本具备写控制台小项目的能力。
