# 04 - 判断和循环

> 目标：掌握 if、switch、for、while 三大流程控制，会用 break/continue 控制循环。

---

## 4.1 if 分支

```java
// 单分支
if (age >= 18) {
    System.out.println("成年");
}

// 双分支
if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}

// 多分支（从上到下判断，命中即停）
if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 80) {
    System.out.println("良好");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```

> **易错点**：
> - 条件必须是 `boolean`，不能写 `if (1)`（区别于 C）。
> - `if (a = 10)` 是赋值不是比较，应写 `a == 10`。
> - 多分支顺序重要：条件范围应从大到小（或从小到大）排列。

## 4.2 switch

```java
int day = 3;
switch (day) {
    case 1:
        System.out.println("周一");
        break;              // 不写 break 会「穿透」到下一个 case
    case 2:
        System.out.println("周二");
        break;
    case 3:
        System.out.println("周三");
        break;
    default:                // 都不匹配时执行
        System.out.println("其他");
}
```

**利用穿透**（多个 case 共用逻辑）：

```java
switch (month) {
    case 3: case 4: case 5:
        System.out.println("春季");
        break;
    case 6: case 7: case 8:
        System.out.println("夏季");
        break;
    default:
        System.out.println("其他季节");
}
```

**switch 表达式（JDK 14+，新写法）**：

```java
int day = 3;
String name = switch (day) {
    case 1, 2, 3, 4, 5 -> "工作日";
    case 6, 7 -> "周末";
    default -> "非法";
};
System.out.println(name);   // 工作日
```

> switch 支持的类型：`byte/short/char/int`、`String`（JDK 7+）、枚举。

## 4.3 for 循环

```java
// 标准格式：初始化; 条件; 迭代
for (int i = 1; i <= 5; i++) {
    System.out.println("第 " + i + " 次");
}

// 遍历数组（推荐增强 for）
int[] arr = {10, 20, 30};
for (int value : arr) {
    System.out.println(value);
}
```

执行顺序：`初始化 → 判断条件 → 循环体 → 迭代 → 判断条件 → ...`

### 案例：九九乘法表

```java
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print(j + "*" + i + "=" + (i * j) + "\t");
    }
    System.out.println();   // 每行结束换行
}
```

### 案例：打印直角三角形

```java
int n = 5;
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print("*");
    }
    System.out.println();
}
```

## 4.4 while 与 do-while

```java
// while：先判断，后执行（可能一次都不执行）
int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;
}

// do-while：先执行一次，再判断（至少执行一次）
int j = 1;
do {
    System.out.println(j);
    j++;
} while (j <= 5);
```

| 循环 | 特点 | 适用 |
|------|------|------|
| `for` | 次数明确 | 已知循环次数 |
| `while` | 先判断 | 次数不确定，条件驱动 |
| `do-while` | 至少执行一次 | 先做后判（如菜单） |

## 4.5 break、continue 与标签

```java
// break：立即结束整个循环
for (int i = 1; i <= 10; i++) {
    if (i == 5) break;
    System.out.println(i);   // 1 2 3 4
}

// continue：跳过本次，进入下一次
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;
    System.out.println(i);   // 1 2 4 5
}

// 标签：跳出多层循环
outer:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (i == 2 && j == 2) break outer;
        System.out.println(i + "," + j);
    }
}
```

## 4.6 随机数 Random

```java
import java.util.Random;

Random r = new Random();
int num = r.nextInt(100);        // 0 ~ 99
int num2 = r.nextInt(100) + 1;   // 1 ~ 100
```

### 案例：猜数字游戏

```java
import java.util.Random;
import java.util.Scanner;

public class GuessNumber {
    public static void main(String[] args) {
        int target = new Random().nextInt(100) + 1;
        Scanner sc = new Scanner(System.in);
        while (true) {
            System.out.print("猜一个 1-100 的数：");
            int guess = sc.nextInt();
            if (guess > target) {
                System.out.println("大了");
            } else if (guess < target) {
                System.out.println("小了");
            } else {
                System.out.println("猜对了！答案就是 " + target);
                break;
            }
        }
        sc.close();
    }
}
```

## 小结

- `if/else if/else` 多分支从上到下命中即停。
- `switch` 不写 `break` 会穿透；JDK 14+ 可用箭头表达式。
- 次数明确用 `for`，条件驱动用 `while`，至少一次用 `do-while`。
- `break` 结束循环，`continue` 跳过本次，标签可跳多层。
