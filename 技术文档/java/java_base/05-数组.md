# 05 - 数组

> 目标：掌握数组的定义、初始化、遍历、内存模型与常见操作。

---

## 5.1 数组是什么

数组是**存储同一种数据类型、长度固定**的容器。

特点：
- 元素**类型相同**。
- **长度固定**，创建后不能改变。
- 元素有**索引**，从 `0` 开始，最大索引 = `长度 - 1`。
- 数组本身是**引用类型**，存于堆中。

```text
int[] arr = {10, 20, 30, 40};
索引：        0   1   2   3
arr[0]=10  arr[3]=40  arr.length=4
```

---

## 5.2 定义与初始化

```java
// 方式一：静态初始化（已知元素）
int[] arr1 = {1, 2, 3};
int[] arr2 = new int[]{1, 2, 3};
String[] names = {"张三", "李四"};

// 方式二：动态初始化（已知长度）
int[] arr3 = new int[5];        // 元素默认值全为 0
String[] arr4 = new String[3];  // 引用类型默认值为 null

// 推荐写法：类型[] 变量名
int[] a;        // ✅ 推荐
int b[];        // 可以但不推荐
```

默认值规则：

| 元素类型 | 默认值 |
|---------|--------|
| 整数（`byte/short/int/long`） | 0 |
| 浮点（`float/double`） | 0.0 |
| `char` | '\u0000' |
| `boolean` | false |
| 引用类型 | null |

---

## 5.3 访问与遍历

```java
int[] arr = {10, 20, 30, 40};

// 访问
System.out.println(arr[0]);      // 10
System.out.println(arr.length);  // 4（注意 length 没有括号）

// 普通 for（需要索引时用）
for (int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}

// 增强 for（只读遍历，更简洁）
for (int value : arr) {
    System.out.println(value);
}
```

> **易错点**：`arr.length` 是属性（无括号），`String.length()` 是方法（有括号），别混。

---

## 5.4 内存模型（理解引用）

```java
int[] arr = new int[3];
arr[0] = 100;
```

```text
栈内存            堆内存
arr  ───────►   [0, 0, 0]   （数组对象）
                 ↑
              arr 存的是堆中数组的地址
```

**两个变量指向同一数组**：

```java
int[] a = {1, 2, 3};
int[] b = a;            // 复制的是地址，a、b 指向同一数组
b[0] = 100;
System.out.println(a[0]);   // 100（a 也受影响！）
```

> 想真正复制数组，用 `Arrays.copyOf()` 或 `clone()`（见 09 篇）。

## 5.5 常见异常

```java
int[] arr = {1, 2, 3};
// 1. 索引越界
System.out.println(arr[5]);
// ❌ ArrayIndexOutOfBoundsException: Index 5 out of bounds for length 3

// 2. 空指针
int[] arr2 = null;
System.out.println(arr2[0]);
// ❌ NullPointerException
```

| 异常 | 原因 | 解决 |
|------|------|------|
| `ArrayIndexOutOfBoundsException` | 索引 < 0 或 ≥ length | 检查边界 `0 <= i < length` |
| `NullPointerException` | 数组变量为 null | 使用前判空 |

## 5.6 常见操作

```java
int[] arr = {5, 2, 8, 1, 9};

// 求最大值
int max = arr[0];
for (int i = 1; i < arr.length; i++) {
    if (arr[i] > max) max = arr[i];
}

// 求和
int sum = 0;
for (int v : arr) sum += v;

// 求平均
double avg = (double) sum / arr.length;   // 注意强转，否则整数除法

// 查找元素（返回索引，找不到返回 -1）
int index = -1;
for (int i = 0; i < arr.length; i++) {
    if (arr[i] == 8) { index = i; break; }
}

// 反转数组
for (int i = 0, j = arr.length - 1; i < j; i++, j--) {
    int tmp = arr[i];
    arr[i] = arr[j];
    arr[j] = tmp;
}
```

## 5.7 数组作为方法参数和返回值

```java
public class Demo {
    public static void main(String[] args) {
        int[] data = {1, 2, 3};
        printArray(data);              // 数组作参数（传的是地址）
        int[] doubled = doubleIt(data); // 数组作返回值
        printArray(doubled);
    }

    public static void printArray(int[] arr) {
        for (int i = 0; i < arr.length; i++) {
            System.out.print(arr[i] + (i < arr.length - 1 ? ", " : ""));
        }
        System.out.println();
    }

    public static int[] doubleIt(int[] arr) {
        int[] result = new int[arr.length];
        for (int i = 0; i < arr.length; i++) {
            result[i] = arr[i] * 2;
        }
        return result;
    }
}
```

> **重点**：数组作参数传的是**地址**，方法内修改会影响原数组（引用传递的效果）。

## 5.8 二维数组

```java
// 静态初始化
int[][] grid = {
    {1, 2, 3},
    {4, 5, 6}
};

// 动态初始化
int[][] g2 = new int[3][4];      // 3 行 4 列

// 遍历
for (int i = 0; i < grid.length; i++) {
    for (int j = 0; j < grid[i].length; j++) {
        System.out.print(grid[i][j] + " ");
    }
    System.out.println();
}

// 增强 for
for (int[] row : grid) {
    for (int v : row) {
        System.out.print(v + " ");
    }
    System.out.println();
}
```

## 小结

- 数组类型相同、长度固定、索引从 0 开始。
- `arr.length` 是属性，无括号。
- 数组是引用类型，赋值复制的是地址。
- 越界抛 `ArrayIndexOutOfBoundsException`，null 抛 `NullPointerException`。
- 数组作参数传地址，方法内修改影响原数组。
