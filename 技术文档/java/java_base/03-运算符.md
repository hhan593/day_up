# 03 - 运算符

> 目标：掌握算术、自增自减、逻辑、三元、位运算符，理解类型提升与优先级。

---

## 3.1 算术运算符

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `+` | 加 | `5 + 2` | 7 |
| `-` | 减 | `5 - 2` | 3 |
| `*` | 乘 | `5 * 2` | 10 |
| `/` | 除 | `5 / 2` | **2**（整数除法！） |
| `%` | 取模（余数） | `5 % 2` | 1 |

```java
int a = 5, b = 2;
System.out.println(a / b);   // 2  ← 整数除法，舍去小数
System.out.println(5.0 / 2); // 2.5
System.out.println(a % b);   // 1
System.out.println(-5 % 2);  // -1（符号跟被除数）

// 常用技巧：判断奇偶
boolean isEven = (a % 2 == 0);
```

> **重点**：`/` 两边都是整数时结果取整（不是四舍五入，是直接截断）。这是初学者最常见的坑。
> **取模用途**：判断整除、奇偶、循环取值（如 `i % 3` 做周期性分组）。

## 3.2 字符串拼接 `+`

`+` 只要有一边是**字符串**，就变成拼接：

```java
System.out.println("年龄：" + 18);        // 年龄：18
System.out.println(1 + 2 + "abc");       // 3abc ← 先算 1+2
System.out.println("abc" + 1 + 2);       // abc12 ← 从左到右，先拼成 abc1 再拼 2
System.out.println(1 + 2 + "abc" + 1 + 2); // 3abc12
```

> **易错点**：`"1" + 2` 是字符串 `"12"`（拼接），不是 `3`。注意运算顺序从左到右。

## 3.3 自增自减

```java
int i = 5;
i++;            // 后置：先用后加，i 变 6
i--;            // 后置：先用后减

int a = 5;
int b = a++;    // b = 5，a = 6（先赋值再自增）
int c = 5;
int d = ++c;    // d = 6，c = 6（先自增再赋值）

int x = 10;
System.out.println(x++);   // 输出 10，然后 x=11
System.out.println(++x);   // x 先变 12，输出 12
```

| 写法 | 含义 | 记忆 |
|------|------|------|
| `i++` | 后置，先用值再 +1 | 用在表达式里取**旧值** |
| `++i` | 前置，先 +1 再用值 | 用在表达式里取**新值** |

> 单独一行 `i++;` 时两者没区别；**参与运算或打印时**才需区分。

## 3.4 赋值运算符

```java
int a = 10;
a += 5;    // 等价 a = a + 5  → 15
a -= 3;    // a = a - 3      → 12
a *= 2;    // a = a * 2      → 24
a /= 4;    // a = a / 4      → 6
a %= 4;    // a = a % 4      → 2
```

> `+=` 隐含强制类型转换：`byte b = 1; b += 1;` 合法（等价 `b = (byte)(b+1)`），但 `b = b + 1;` 会编译报错。

## 3.5 比较运算符

| 运算符 | 含义 |
|--------|------|
| `==` | 等于 |
| `!=` | 不等于 |
| `>` `<` `>=` `<=` | 大于/小于/... |

```java
System.out.println(3 > 2);    // true
System.out.println(3 == 3);   // true
```

> **重点**：
> - 比较结果是 `boolean`。
> - 基本类型比较值用 `==`；**引用类型（如 String）比较内容要用 `.equals()`**：
> ```java
> String s1 = "abc";
> String s2 = new String("abc");
> System.out.println(s1 == s2);        // false（比较地址）
> System.out.println(s1.equals(s2));   // true（比较内容）
> ```

## 3.6 逻辑运算符

| 运算符 | 含义 | 说明 |
|--------|------|------|
| `&` | 逻辑与 | 两边都 true 才 true（**不短路**） |
| `|` | 逻辑或 | 一边 true 就 true（**不短路**） |
| `^` | 逻辑异或 | 两边不同为 true |
| `!` | 逻辑非 | 取反 |
| `&&` | 短路与 | 左边 false 则右边不算（**推荐**） |
| `||` | 短路或 | 左边 true 则右边不算（**推荐**） |

```java
int a = 10;
// 短路：左边已是 false，右边不执行
boolean r1 = (a > 20) && (a++ > 5);
System.out.println(a);   // 10，a++ 没执行

// 不短路：两边都执行
int b = 10;
boolean r2 = (b > 20) & (b++ > 5);
System.out.println(b);   // 11，b++ 执行了
```

> **实战建议**：几乎总是用 `&&` / `||`（短路更高效，还能防止空指针等副作用）。

---

## 3.7 三元运算符

语法：`条件 ? 值1 : 值2`

```java
int a = 10, b = 20;
int max = a > b ? a : b;              // 20
String result = a > b ? "a大" : "b大"; // b大
```

等价于：

```java
int max;
if (a > b) { max = a; } else { max = b; }
```

> 适合「二选一」的简单判断；复杂逻辑用 `if-else`。

## 3.8 位运算符（了解）

| 运算符 | 含义 | 示例（二进制） |
|--------|------|---------------|
| `&` | 按位与 | `6 & 3 = 2` |
| `|` | 按位或 | `6 | 3 = 7` |
| `^` | 按位异或 | `6 ^ 3 = 5` |
| `~` | 按位取反 | `~6 = -7` |
| `<<` | 左移 | `3 << 1 = 6`（×2） |
| `>>` | 右移 | `6 >> 1 = 3`（÷2） |
| `>>>` | 无符号右移 | 高位补 0 |

```java
System.out.println(3 << 1);   // 6，左移 1 位 = ×2
System.out.println(6 >> 1);   // 3，右移 1 位 = ÷2
// 交换两数（不用临时变量）
int x = 3, y = 5;
x = x ^ y; y = x ^ y; x = x ^ y;   // x=5, y=3
```

> 位运算性能高，但可读性差，业务代码少用；算法题、源码中常见。

## 3.9 运算符优先级与类型提升

优先级（高 → 低，节选）：

```text
()  →  ! ~ ++ --  →  * / %  →  + -  →  << >>  →  比较  →  == !=  →  &  →  ^  →  |  →  &&  →  ||  →  ?:  →  = += ...
```

记忆：**括号最高，赋值最低，不确定就加括号**。

类型提升规则（二元运算）：

```java
byte a = 1, b = 2;
// byte c = a + b;   // ❌ 编译错误
int c = a + b;       // ✅ byte/short/char 参与运算会先提升为 int

long l = 1;
float f = 2.0f;
// 提升顺序：int → long → float → double
```

---

## 小结

- `/` 整数相除取整；`%` 取余（符号跟被除数）。
- `i++` 先用后加，`++i` 先加后用。
- 引用类型比内容用 `.equals()`，不用 `==`。
- 逻辑运算优先用短路的 `&&` `||`。
- `byte`/`short`/`char` 运算会提升为 `int`。
