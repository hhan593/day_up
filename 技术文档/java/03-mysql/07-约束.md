# 07 - 约束

> 目标：掌握六种约束，理解主键、外键、唯一约束的使用与区别。

---

## 7.1 约束概述

**约束（Constraint）**：作用在表字段上，保证数据**正确性、有效性、完整性**的规则。

| 约束 | 关键字 | 作用 |
|------|--------|------|
| 非空 | `NOT NULL` | 字段不能为 NULL |
| 唯一 | `UNIQUE` | 字段值不能重复（允许多个 NULL） |
| 主键 | `PRIMARY KEY` | 唯一标识一行，非空 + 唯一 |
| 默认 | `DEFAULT` | 未赋值时的默认值 |
| 检查 | `CHECK` | 值必须满足条件（8.0.16+ 生效） |
| 外键 | `FOREIGN KEY` | 关联另一张表的主键 |

---

## 7.2 非空约束 NOT NULL

```sql
create table t1 (
    id   int,
    name varchar(20) not null
);
-- insert into t1 (name) values (null);  -- ❌ 报错
```

---

## 7.3 唯一约束 UNIQUE

```sql
create table t2 (
    id    int,
    phone varchar(11) unique
);
```

- 值不能重复。
- **允许多行为 NULL**（NULL ≠ NULL）。
- 可以建**联合唯一**：`unique (a, b)` 表示 a、b 组合不重复。

```sql
create table t3 (
    a int,
    b int,
    unique uk_ab (a, b)     -- a+b 组合唯一
);
```

---

## 7.4 主键约束 PRIMARY KEY

主键 = **非空 + 唯一**，一张表只能有一个主键。

```sql
-- 单列主键
create table t4 (
    id   int primary key auto_increment,
    name varchar(20)
);

-- 联合主键（两列组合唯一）
create table t5 (
    order_id  int,
    goods_id  int,
    primary key (order_id, goods_id)
);
```

### 自增 AUTO_INCREMENT

```sql
create table t6 (
    id   int primary key auto_increment,
    name varchar(20)
);

insert into t6 (name) values ('a'), ('b');   -- id = 1, 2
delete from t6 where id = 2;
insert into t6 (name) values ('c');          -- id = 3（不重用已删除的 id）
```

> **注意**：
> - 自增只用于整数类型，且必须配合主键/唯一约束。
> - `delete` 后自增不重置，`truncate` 后重置为 1。
> - 自增的 id 用完或误删后可能断号，这是正常现象。

## 7.5 默认约束 DEFAULT

```sql
create table t7 (
    status  tinyint default 1,
    create_time datetime default current_timestamp
);
```

---

## 7.6 检查约束 CHECK（MySQL 8.0.16+）

```sql
create table t8 (
    age   int check (age >= 0 and age <= 150),
    gender char(1) check (gender in ('男', '女'))
);
-- insert into t8 (age) values (200);  -- ❌ 违反 CHECK，报错
```

> MySQL 5.7 会解析但**忽略** CHECK，8.0.16 起真正生效。

## 7.7 外键约束 FOREIGN KEY

外键：**子表字段引用主表的主键**，保证引用完整性。

```sql
-- 主表：班级
create table tb_class (
    id   int primary key auto_increment,
    name varchar(20) not null
);

-- 子表：学生，class_id 引用 tb_class.id
create table tb_student (
    id       int primary key auto_increment,
    name     varchar(20) not null,
    class_id int,
    constraint fk_student_class
        foreign key (class_id) references tb_class(id)
);
```

外键的效果：

```sql
insert into tb_student (name, class_id) values ('张三', 999);
-- ❌ 报错：班级 999 不存在，无法插入

delete from tb_class where id = 1;
-- ❌ 报错：有学生引用该班级，不能删
```

### 级联操作

```sql
constraint fk_student_class
    foreign key (class_id) references tb_class(id)
    on update cascade      -- 主表主键更新，子表自动更新
    on delete cascade      -- 主表删除，子表相关行也删除
```

| 级联选项 | 含义 |
|---------|------|
| `restrict`（默认） | 有引用时禁止删除/更新 |
| `cascade` | 级联删除/更新子表 |
| `set null` | 子表外键置为 NULL |
| `no action` | 同 restrict |

> **实战提醒**：互联网公司**大多不用物理外键**（阿里的 Java 规范明确禁止），原因：影响写入性能、级联删除不可控、分库分表后无法维护。改用**应用层保证引用完整性**。但外键概念仍是面试考点。

## 7.8 建表时 vs 建表后添加

```sql
-- 建表时
create table t (
    id int primary key,
    name varchar(20) not null unique
);

-- 建表后添加
alter table t add constraint uk_name unique (name);
alter table t add constraint ck_age check (age >= 0);

-- 删除约束
alter table t drop index uk_name;          -- 删唯一约束（用 index 名）
alter table t drop primary key;            -- 删主键
alter table t drop foreign key fk_name;    -- 删外键
```

---

## 小结

- 六种约束：`NOT NULL` / `UNIQUE` / `PRIMARY KEY` / `DEFAULT` / `CHECK` / `FOREIGN KEY`。
- 主键 = 非空 + 唯一，一张表只能一个；自增只用于主键/唯一整数列。
- 唯一约束允许多个 NULL；联合唯一是组合不重复。
- 外键保证引用完整性，但**互联网项目少用物理外键**。
- `CHECK` 在 8.0.16+ 才真正生效。
