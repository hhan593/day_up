# 13 - 视图

> 目标：理解视图的概念与作用，掌握创建、使用与更新条件。

---

## 13.1 什么是视图

视图（View）是一个**虚拟表**，本身不存数据，只保存**查询定义**。查询视图时会动态执行底层 SQL。

```sql
-- 创建视图
create or replace view v_student_80 as
select id, name, score
from student
where score >= 80;

-- 像表一样查询
select * from v_student_80;
```

> 视图 = **保存下来的 SELECT 语句**，数据仍在原表中。

---

## 13.2 视图的作用

| 作用 | 说明 |
|------|------|
| **简化复杂查询** | 把多表连接、聚合封装成视图，直接查 |
| **数据安全** | 只暴露部分列/行（如隐藏手机号、工资） |
| **逻辑解耦** | 表结构变化时改视图，不改应用 SQL |
| **权限控制** | 只给视图权限，不给原表权限 |

---

## 13.3 创建、修改、删除

```sql
-- 创建
create view v_emp_dept as
select e.name as emp_name, d.name as dept_name, e.salary
from tb_emp e
left join tb_dept d on e.dept_id = d.id;

-- 修改（两种方式）
create or replace view v_emp_dept as select ...;   -- 推荐
alter view v_emp_dept as select ...;

-- 查看
show create view v_emp_dept;
select * from information_schema.views where table_name = 'v_emp_dept';

-- 删除
drop view if exists v_emp_dept;
```

---

## 13.4 视图的更新

对**简单视图**可以执行 `insert` / `update` / `delete`（会作用到原表）：

```sql
update v_student_80 set score = 85 where id = 1;   -- 修改的是 student 表
```

**但以下视图不可更新**：

| 情况 | 原因 |
|------|------|
| 含聚合函数（`sum`/`avg`/`count` 等） | 无法映射到单行 |
| 含 `distinct` | 结果非一一对应 |
| 含 `group by` / `having` | 同上 |
| 含 `union` / `union all` | 多来源 |
| 含子查询 | 部分情况不可 |
| 包含表达式列（如 `score + 10`） | 无对应原列 |

> 一般给视图加 `with check option` 限制插入/更新必须满足视图的 WHERE 条件。

```sql
create view v_student_80 as
select id, name, score from student where score >= 80
with check option;      -- 通过视图插入的 score 必须 >= 80
```

---

## 13.5 视图 vs 表

| 对比 | 表 | 视图 |
|------|----|------|
| 是否存数据 | ✅ 存 | ❌ 不存（虚拟） |
| 占用空间 | 占 | 只存定义 |
| 能否增删改 | ✅ | 受限制 |
| 查询性能 | 快 | 取决于底层 SQL（无额外优化） |

> **注意**：视图**不提升查询性能**，只是简化与安全。要提升性能仍需优化底层 SQL 与索引。

---

## 13.6 案例：脱敏视图

```sql
-- 原表含敏感信息，给只读账号创建脱敏视图
create or replace view v_user_safe as
select
    id,
    name,
    concat(substring(phone,1,3), '****', substring(phone,8,4)) as phone,
    age
from tb_user;

-- 只给视图权限，不给原表
grant select on study.v_user_safe to 'readonly'@'%';

-- 只读账号查询
select * from v_user_safe;
```

---

## 小结

- 视图是虚拟表，只存查询定义，不存数据。
- 作用：简化查询、数据安全、逻辑解耦、权限控制。
- 简单视图可增删改（作用于原表），含聚合/分组/去重/union 的视图不可更新。
- 视图**不提升性能**。
- `with check option` 约束通过视图写入的数据。
