### 1. 基础配置：系统开关测试

- **正向测试：**
    
    - 配置开启后，对应渠道、机构、日期生效新的适当性评估逻辑 。
        
- **反向测试：**
    
    - 配置关闭时，走原有老流程。
        
    - 系统时间跨越配置生效临界点时（如配置明天生效，跨零点测试），流程切换是否正确。
        

### 2. 特殊人群提示：65周岁以上投保人注意义务

- **正向测试：**
    
    - 投保人年龄 ≥ 65岁，且购买 P3、P4、P5 类产品，投保确认页字体变大 。
        
    - 投保人年龄 ≥ 65岁，且购买 P3、P4、P5 类产品，强制阅读时间加长（需明确具体加长多少秒，文档未写明，**可作为疑问点提给产品经理**） 。
        
- **反向/边界测试：**
    
    - **边界值**：刚好等于65周岁当天，是否触发新逻辑。
        
    - **条件不满足**：年龄 ≥ 65岁，但购买 P1 或 P2 产品，不触发加长/加大提示 。
        
    - **条件不满足**：年龄 < 65岁，购买 P3-P5 产品，不触发。
        

### 3. 高风险产品提示：P4-P5类产品风险告知

- **正向测试：**
    
    - 购买 P4、P5 类产品时，提示文档展示新增的风险提示语句（亏损可能、风险等级等） 。
        
    - 提示内容在核心后台成功保存为“单证UAXXX” 。
        
- **反向测试：**
    
    - **渠道排除**：银保通、纸质投保单渠道，不展示该明确提示相关内容 。
        
    - 购买 P1、P2、P3 产品，不展示该风险提示语句。
        
    - 查看生成的电子合同，确认该“单证UAXXX”**没有**被打印在合同中 。
        

### 4. 核心逻辑：问卷评估有效期与频次限制

- **正向测试：**
    
    - 完成评估后，有效期精确计算为12个月（含） 。
        
    - 在有效期内重新评估，系统以最新的评估结果为准 。
        
    - 风险评估等级变化：本次评估等级与最近一次不一致，弹出二次确认提示框 。
        
    - 弹框确认后，正常提交。
        
- **反向/边界测试：**
    
    - **边界值**：评估完成后的第12个月最后一天（有效），第12个月后的一天（失效，需重测）。
        
    - **频次超限（日）**：单日评估达到第3次时，系统拦截并提示（单日不超过2次） 。
        
    - **频次超限（年）**：12个月内评估达到第9次时，系统拦截并提示（12个月内不超过8次） 。
        
    - **异常操作**：风险评估等级变化弹出提示框时，点击“取消”或不确认，无法提交。
        

### 5. 核心逻辑：短期疑似风险行为拦截（需重点测）

这里需要校验三类风险行为，每一种都要覆盖正反向 ：

- **场景A：退保后重新投保**
    
    - **正向（命中拦截）**：退保30天内 + 同类型险种 + 险期>1年 + 退保金>新单保费50% -> 弹出风险提示并要求确认 。
        
    - **反向（未命中）**：退保第31天 / 不同类型险种 / 险期≤1年 / 退保金=新单保费50%（边界值） -> 正常通过。
        
- **场景B：保单贷款后新投保**
    
    - **正向（命中拦截）**：贷款30天内 + 险期>1年 + 贷款未还清 + 贷款金额>新单保费50% -> 弹出提示确认 。
        
    - **反向（未命中）**：贷款前已结清 / 贷款金额=新单保费50% / 险期≤1年 -> 正常通过。
        
- **场景C：效力中止后新投保**
    
    - **正向（命中拦截）**：存在中止保单 + 同类型险种 + 险期>1年 -> 弹出提示确认 。
        
    - **反向（未命中）**：中止保单已复效 / 不同类型险种 / 险期≤1年 -> 正常通过。
        

### 6. 核心逻辑：投保评估流程分发（路由逻辑）

当客户同时投保多个产品时，按**最高产品等级**判断 ：

- **最高 P1 类**：
    
    - 正向：跳过评估，无需填写需求/财务/风险问卷 。
        
- **最高 P2-P3 类**：
    
    - 正向（无有效问卷）：进入完整流程，展示/填写附件1+附件2+附件3 。
        
    - 正向（有12个月内有效问卷）：简化流程，仅展示/填写附件3（匹配结果确认） 。
        
- **最高 P4-P5 类**：
    
    - 正向（无有效问卷）：完整流程（附件1+2+3） 。
        
    - 正向（有12个月内三项全量有效问卷）：简化流程（仅附件3） 。
        
    - **反向（部分缺失）**：名下有需求/财务问卷，但**无风险承受能力评估**，系统视作“不存在有效问卷”，强制走完整流程（附件1+2+3） 。
        

### 7. 独立入口：官微事前评估

- **正向测试：**
    
    - 已绑定官微用户：系统自动带入投保人信息且不可修改 。
        
    - 未绑定官微用户：手动填写投保人信息 。
        
    - 证件类型选择“身份证”：系统自动根据证件号回显性别、出生日期，并置灰不可改 。
        
    - 险种信息下拉框：仅展示银保渠道在售产品 。
        
- **反向测试：**
    
    - 选择非身份证（如护照）：性别、出生日期可手动填写。
        
    - 未绑定用户输入错误格式的身份证号、手机号，系统应有报错提示。
