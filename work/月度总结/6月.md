1.  ETC 助缴模块建设与优化

- 完善 ETC 助缴数据看板，将占位页面替换为真实数据展示。
- 修复助缴模块接口请求、页面跳转逻辑。

2. 智慧停车模块优化

- 优化日报、周报、月报标签显示和日期格式化。

3. 登录、权限与首页体验修复

- 优化微信登录逻辑，减少不必要的登录请求。
- 权限接口切换为 getMenuPerms。
- 新增 token 七日滑动续签逻辑。
- 权限检查改为响应式实时获取。
- 首页增加无权限空状态和 token 缺失提示。
- 优化登录页提示消息。

4. 客户服务部相关修复

- 修复赔付订单总数字段显示错误。

- 为线下订单审核接口增加 30 秒超时。
- 移除客户服务部多个页面未使用的明细表格，精简页面结构。

5. ETC 客车 / 货车 / 发行通行数据展示优化

- ETC 客车图表单位修复。
- 发行量、办理量、通行笔数增加千分位格式化。
- 调整 ETC Bus 推广卡片高度和条件判断格式。
- 修复相关页面权限判断逻辑。

6. 通用组件与工具函数改进

- 表格组件统一空值保底显示。
- 修复 mixBar 空数据时不注册图表实例的问题。
- DualStatCardPlus 数值字号支持按长度动态调整，避免长数字截断。
- 修复 InfoCardRow 样式类名、ReimbursementTable 变量引用、lineChart 轴标签对齐问题。
- 简化 padZero，移除重复工具函数，修正日期范围限制类型。

7. 代码整理

- 清理未使用样式、未使用导入和无效表格结构。
- 调整部分 Tailwind 样式配置。
- 做了一些格式整理和小范围代码微调。

工单系统
一、首页数据看板建设与优化

完成首页报表模块重构，拆分 Home 相关组件，集中管理数据结构与展示逻辑。
对接首页数据接口，将组件由 mock 数据改为 props 驱动，并补充无数据空状态展示。
新增时间范围筛选、业务子页面路由，以及多个业务看板页面，如北分平安、洗车、充电、代驾投诉、惠生活、出租车、微信券等。
调整每日投诉柱状图展示方式，由堆叠图改为按完结状态分组并排展示。
整理并迁移首页数据格式文档到 doc 目录。

二、工单处理流程优化

优化工单详情、处理表单、批量处理、选择处理人等核心流程。
新增转发理由必填校验，完善打回确认弹窗和表单 loading 状态。
工单详情支持展示退费信息，ETC2.0 退费逻辑完成调整。
工单表单迁移到 BusinessFieldsRenderer 渲染体系，支持直接完结等处理场景。
修复业务详细信息展示不全、costBelong 输入形式不合适等问题。

三、业务类型表单扩展

新增或完善多个业务类型表单组件，包括平安、微信券、出租车、驾考、车客、充电、洗车、12580、税务局等。
调整投诉来源、渠道、供应商单号、归属省份等业务字段配置。
修正微信券渠道值、投诉来源选择方式、12580 文案和字段展示。

四、外呼与建单模块改造

重构外呼/建单相关模块，优化来电信息、建单弹窗和动态标签展示。
增强 businessFieldsRenderer 组件，支持 noCol、pathPrefix 和更多字段类型。
级联选择器支持任意层级选择，并增加可清除、宽度调整等交互优化。
外呼渠道字段从输入框改为动态下拉选择。

五、任务单与拉单流程优化

重构任务单列表、回访相关页面和 ETC 拉单列表。
拉单按钮取消强制手机号限制。
ETC 拉单关键字为空时不再传参，并增加输入后 500ms 防抖查询。
统一调整“是否回访 / 是否返回二级待办”等标签文案。

六、系统与公共能力维护

优化系统管理模块中部门、字典、岗位、角色、用户等页面的表单与表格结构。
优化头部搜索和操作日志组件。
新增 usePolling 轮询 Hook，扩展音频格式支持。
配置开发环境代理，多次切换本地 nginx、远程服务等开发 API 地址。
清理 message、receive 等模块代码格式，并接入 patched video player 包。
